# docs/plan — индекс каталога

Планирование реализации «Ортус CRM» и сайта документации по прототипу Claude Design (`design/`, эталон неприкосновенен). Начинать чтение с `00-master-plan.md` §0.

> **С 14.10.2026 действует `v2/00-parallel-plan.md`.** Он построен по плану реализации 27 и новой итерации прототипа. Реестр волн, WS и `status.md` ниже заменены. Протоколы TDD, верификации и оркестрации остаются в силе с правками из `v2/00-parallel-plan.md` §6.

## Основные документы

| Файл | Что это | Кто правит |
|---|---|---|
| `00-master-plan.md` | мастер-план: цель и границы, эталон и рецепты его воспроизведения, архитектура и дерево репозитория с владельцами, контракты волны 0, реестр WS (55 потоков), DAG и волны, протокол запуска волн (`args` для `workflow.template.js`), TDD и верификация по видам WS, требования/AC → WS, риски, новые решения D-25…D-52, критерии готовности фаз | планировщик; интегратор на барьере волны |

## Черновики плана (`drafts/`)

`draft-A.md` (UI-first, победитель), `draft-B.md` (contract-first), `draft-C.md` (вертикальные срезы) — исходные варианты; мастер-план основан на A с вплетёнными решениями B и C (`00-master-plan.md` §0.3) и закрытыми пробелами (§0.4). Черновики не являются источником для брифов.
