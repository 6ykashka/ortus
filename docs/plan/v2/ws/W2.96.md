# W2.96 · Предел воркеров e2e (E2E_WORKERS)

Этап 2 · вид frontend · слот 6. Карточки в §4 нет — постановка интегратора.

## 1. Цель

`workers: h.ci ? 1 : undefined` в `defineHarnessConfig` даёт 11 воркеров на ПК проверяющего. Полный mock (3952 теста) шёл 3,6 ч с 801 тайм-аутом при 7 МБ свободной памяти. Нужен явный предел.

## 2. Границы файлов

`frontend/packages/e2e-kit/src/config.ts`, `src/env.ts`, их тесты в `test/`; строка в `docs/plan/verification-protocol.md` (только добавление); свои бриф и отчёт. Playwright-конфиги страниц не меняются.

## 3. Поведение

- `E2E_WORKERS` — целое 1…16; пустое значение равно «не задано»; иное — ошибка `E2E_WORKERS=<значение>: ожидается целое 1…16`.
- Не задано: локально 4, в CI 1. Явное значение действует и в CI.
- `HarnessEnv.workers` → `workers` конфига.

## 4. Контракты, страницы

Контракт не меняется, страниц нет (`pagesDelivered` пуст, проходка MCP не применима).

## 5. Проверки

Тесты e2e-kit (red-коммит отдельно), lint, typecheck, test; `pipeline --job e2e` на ПК проверяющего при `E2E_WORKERS=3` — без тайм-аутов 30 с (замер на ПК проверяющего, у исполнителя не воспроизводится).
