# Экраны, которые нужно дорисовать (блокер B-6)

Составил W0.02 15.10.2026 по снимку эталона 14.10 (`design-stage-1`, `design/MANIFEST.md`). Это экраны пилота (этапы 1–2), для которых в прототипе нет макета. Пока экрана нет, его ключ проверяется e2e и проходкой через Playwright MCP без пиксельной сверки: в allowlist — вид `no-reference` со ссылкой на PD-48 (истории без UI в прототипе; вердикт «пересмотреть» — до дорисовки `no-reference`) и PD-26 (вид `no-reference`). Когда дизайн дорисует экран, DoR-сверщик кладёт его в `design/` новым снимком, и запись allowlist снимается.

Отдельно от B-6: модульные `.dc.html` этапов 4–7 (7 модулей, свежий «Ремонт и стройка», шесть «… - варианты») — это блокер B-1, список в `design/MANIFEST.md`, раздел «Не хватает».
