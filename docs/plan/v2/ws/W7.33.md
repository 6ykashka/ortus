# W7.33 Портал клиента (страницы клиента без входа)

Этап 7 · шаг 7.3 · дорожка Ф · размер M · слот 3 · вид `frontend`, режим mock (MSW, контракт 0.12.0-stage7).
Зависит от: W7.00 (контракт `PublicService`, сценарный сервер `msw/service`). Backend портала — W7.31 (в `main` его нет: режим stand — `@stand-spec` с `test.fixme`).

## 1. Цель

Публичный портал клиента без сессии и оболочки по `design/Обращения - варианты.dc.html` 1a (тег `design-2026-10-19`, `L:285–451`), разбор — `docs/plan/v2/analysis/dor/service.md` §1.2, §2.3, Q-W4.00-service-3, -8, -9, -15. Мобильный 390 — в первую очередь. Вход — только личная ссылка (Q-W4.00-service-9); «телефон + код» и бот — после SMS-провайдера (W7.37), в M-объём не входят.

- `public-service-page` — `/s/:slug`: шапка направления, «Чем помочь?», группы типов «Оценить и поблагодарить», «Если что-то не так», «Другое», форма обращения с согласием на ПДн и вложениями, квитанция с личной ссылкой, «Мои обращения · N» (токены хранятся в браузере клиента); с `?w=<токен работы>` — карточка «Ваш визит» и шаг «Оценка визита» (экран 2 макета: 1–5, причины, комментарий, «Свяжитесь со мной»).
- `public-service-request` — `/r/:token`: номер и статус («Получили», «Отвечаем», «Ждём вашего ответа», «Решено»), лента «Получили · Ответили · Решено», переписка, «Довольны ли решением?» (одна оценка), «Вопрос не решён — вернуть в работу» (окно 5 дней), «Написать» с вложением, «СТОП» опросов.
- Состояния: загрузка, ошибка с повтором, не найдено (404), ссылка устарела (410), частые попытки (429), нет связи.

## 2. Границы файлов

Пишу только в `frontend/apps/web/src/routes/service-portal/**` (код, CSS, тексты `texts.ts`, Vitest), `frontend/apps/web/e2e/service-portal*.spec.ts`, `frontend/apps/web/e2e/visual/allowlist/service-portal*.md` (если понадобятся), этот бриф, отчёт `docs/plan/v2/reports/W7.33.md`, `docs/plan/evidence/service-portal-*/`.
Маршруты `/s/$slug` и `/r/$token` — две строки в `frontend/apps/web/src/app/router.tsx` (общий файл маршрутов, как у W4.70 для `/f/$token`; по сути баррель интегратора — отмечено в integratorNotes). Не трогаю: `api/**`, `packages/adapter` (сценарный сервер W7.00), `packages/domain`, `packages/texts`, `package.json`, меню, `design/`.

## 3. Правила и решения

- Страница без `/me/context` и оболочки; сеть — только операции тега `PublicService`; `Cache-Control: private, no-store` — на стороне сервера.
- Подписи — дословно из макета; статусы — из ответа (`statusLabel`).
- Оценка визита (экран 2) в контракте не имеет своей операции: уходит обращением `submitPublicServiceRequest` с `workToken` (Q-W7.33-1). Тип — «Спасибо» при оценке 4–5, иначе «Жалоба»; просьба связаться — телефон и пометка в тексте.
- Один тап — один запрос; кнопки блокируются на время запроса; `Idempotency-Key` на изменяющих операциях.
- Цели касания ≥ 44 px, фокус видим, без горизонтальной прокрутки на 390.
