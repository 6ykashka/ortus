## Осталось fixme / открытые вопросы

`fixme` нет. Вопросы (значения по умолчанию сделаны так, в decisionsNeeded):

1. **Q-W4.70-1** — организация страницы `/forms/{id}`: последняя выбранная (`lastTenantId`), затем другие активные; форма ищется по id. Альтернатива — `/t/{tenantId}/forms/{id}/fill` (тогда менять `shareLinks`).
2. **Q-W4.70-2** — `PublicForm` не отдаёт названия формы: заголовок страницы гостя — название первой страницы версии. Стюарду: добавить `PublicFormPresentation.title`.
3. **Q-W4.70-3** — причину `Form.my.respond = false` контракт не различает: открытая форма с «Один ответ от сотрудника» — «Вы уже отвечали на эту форму», иначе «Приём ответов закрыт» (при лимите и «один ответ» одновременно покажется первое).
4. **Q-W4.70-4** — правка `routes/core/forms/preview.tsx` (W4.22) вне списка задачи: аддитивные необязательные свойства `FormRender` — комментарий W4.22 сам оставлял `onSubmit (W4.28)`; без них общий рендер нельзя использовать для отправки. На приёмку интегратору / W4.22.
5. **Q-W4.70-5** — `screens.yaml`: поле `ws` у `form-fill`, `public-form` — W4.23 «кандидат W4.28»; поправить на W4.70 (стюард).
