# W7.13 Страница «Чаты»

Этап 7 · дорожка Ф · шаг 7.1 · размер L · слот 8 (Vite 5208, Storybook 7208, API 8108, эталон 4108, `ortus-s8`) · вид `frontend`.
Зависит от: W7.00 (контракт `0.12.0-stage7`, тег Chats, MSW `adapter/src/msw/chats`), W7.10 (домен `modules/chats`). Backend чатов — W7.11 (не в main), поэтому страница живёт на MSW; режим stand — `test.fixme` с причиной.

## 1. Цель

Страница `chat` (`/t/:tenantId/chat`, пункт меню «Чаты» с бейджем Σ непрочитанных) из эталона `Чаты.dc.html` (тег design-2026-10-19) по разбору `docs/plan/v2/analysis/dor/chats.md`:

- список чатов (C-3): поиск, папки «Все · Личные · Рабочие · Записи · Объявления» со счётчиками, строка (аватар, название, последнее, время, «Подтвердить», непрочитанные);
- шапка чата, темы, закреплённое, лента (C-5…C-8): день, служебные сообщения, сообщения, удалённое, важное с «Ознакомлен», файлы и одноразовые, карточка документа, маска ПДн, спойлер, опрос, история правок, отметки прочтения, меню действий;
- поле ввода (C-9): правка, файл, документ, опрос, важное, временное, спойлер, одноразовый файл; режим «только чтение»;
- панель «Сведения» (C-10): вкладки «Участники · Сообщение · Права · Хранение», `?side=info|msg|rights|store`;
- диалог «Новый чат» (D-1, `modal-chat-new`) с предпросмотром «Кто войдёт»;
- вкладка «Политики» (C-11, `chats-policies`) только для владельца бизнеса.

Ширина — по контейнеру (390: одна колонка; ≥ 760: список + чат, «Сведения» заменяют чат; ≥ 1100: три колонки).

## 2. Границы файлов

Пишу: `frontend/apps/web/src/routes/chats/**`, `frontend/apps/web/e2e/chat*.spec.ts`, этот бриф и `docs/plan/v2/reports/W7.13.md`, вопросы — в отчёт (`decisionsNeeded`). Не трогаю `api/**`, `domain`, MSW (W7.00), `design/`, `decisions.md`, `status.md`, корневые конфиги.

## 3. Решения по умолчанию

По DoR §7: папки как в эталоне (Q-chats-15); режим прочтения — из политики (по умолчанию `ticks`), «последняя активность» не показывается (Q-3); «Важное» — +3 дня (Q-11); метка «ПДн» в «Новом чате» не предлагается (Q-14); «Переносить в архив» скрыт (Q-16); «Удалённые в журнале» — 30 дней без выбора (Q-17); ответ, цитата, пересылка, реакции, треды, голосовые «с нуля» — вне W7.13 (Q-6). Личный чат «с нуля» — вид «Личный» в «Новом чате» (`createDirectChat`, no-reference, Q-5).
Демо-инструменты эталона («Демо-файлы», «Демо: прошло 24 часа») в продукт не идут; файл прикрепляется через `files` (`initiateUpload`/`completeUpload`).
