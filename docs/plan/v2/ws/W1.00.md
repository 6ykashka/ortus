Расширение при исполнении (8 → 13 операций). Пять операций тега Access и `tenantState` добавлены по карточкам W1.05, W1.23 (S1-08, S1-09) и W1.08, W1.20 (S1-19): без них экраны «Сотрудники» и «Структура» этапа 1 остались бы без контракта. **W1.05 и W1.23** реализуют эти операции в Go: после rebase на W1.00 их `StrictServerInterface` тега Access требует методы `CreateMember`, `ListWorkProfiles`, `CreateWorkProfile`, `UpdateWorkProfile`, `PreviewOrgUnitMove` (до своего шага — 501). **Интегратор**: сливать W1.00 до W1.05/W1.23; `tenantState` собирает `mehttp.Server` (W1.03/W1.10) — поле необязательное, компиляцию не ломает.

Решения по умолчанию в контракте:

- Команды оператора — отдельные операции с обязательной `reason` (5–500), `If-Match` по ревизии организации (подписки — у продления), `Idempotency-Key`; каждая пишет строку `platform_audit`. `updatePlatformTenant` 0.1 остаётся (переименование). «Ограничить новые операции» эталона = `suspendPlatformTenant` (PLAT-02 `suspended`), «Снять ограничение» = `resumePlatformTenant` (в `active` или в состояние подписки).
- Продление: `days` 1…30 (эталон — 14), допустимо из `trialing` и из `read_only`/`grace` после пробного периода; из оплаченной подписки — 409 `invalid_transition` (эталон показывает кнопку всегда — 04 §6 п. 4; по умолчанию кнопка скрыта для `active`).
- Журнал платформы — структурные поля (`action`, `target`, `reason`, `actor`, `details`); текст строки собирает клиент из словаря.
- `listFiles` фильтрует до пагинации по доступу к родительскому объекту; родитель без доступа не раскрывается (файл не попадает в список).
- Разбивка места — группы эталона «Фото осмотров и отчётов», «Документы», «Вложения задач и форм», «Прочее» (`photos`, `documents`, `attachments`, `other`) и модули-источники; отдельная операция, `StorageUsage` 0.1 не меняется.
- Канал реального времени — только «подсказки» без данных: клиент перечитывает `/me/context` и сводку входящих обычными операциями с проверкой прав. Билет одноразовый, 60 с, передаётся первым кадром после подключения (не в URL). Сам WebSocket `GET /api/v1/realtime` описан в ADR-0015 и расширением `x-realtime` операции билета (OpenAPI не описывает 101).
