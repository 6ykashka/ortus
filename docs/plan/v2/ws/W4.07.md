## 2. Цель — контракт `0.7.x-stage4` (только добавление)

**Billing (владелец организации, `/tenants/{tenantId}/…`):**

1. `Subscription` + тариф, срок, версия цен, сумма периода, места (`seats`: лимит, занято, активны, приглашены, свободно) — у `getTenantSubscription` и `getPlatformSubscription`.
2. `getTenantPriceBook` — действующая сетка (ступени, сроки, скидки), запланированная версия и версия подписки.
3. Заявки на тариф: `listSubscriptionChangeRequests`, `createSubscriptionChangeRequest` (одна открытая — 409 `request_pending`; мест в тарифе меньше занятых — 422 `tier_below_usage`), `cancelSubscriptionChangeRequest`.

**Platform (оператор):**

4. Очередь заявок `listPlatformSubscriptionRequests`, решение `decidePlatformSubscriptionRequest` (отказ — причина обязательна; повышение — сразу, понижение — с начала следующего периода).
5. Тарифная сетка: `listPriceBookVersions`, `publishPriceBookVersion` (проверки ступеней и скидок, одна запланированная версия), `cancelPriceBookVersion` (только запланированную).
6. «Использование»: `getPlatformUsage` — сводка, сигналы, отраслевые модули, строки организаций (только метаданные control DB).
7. Каталог аккаунтов: фильтры `listPlatformUsers`, `getPlatformUser` с участиями, `lockPlatformUser` (причина обязательна), `unlockPlatformUser`, `resetPlatformUserMfa`; `Tenant` — места, участники, тариф, знак для списка организаций.
8. Организация платформы (раздел «Ортус · Платформа» экрана «Пользователи»): `listPlatformOperators`, `invitePlatformOperator`, `updatePlatformOperator` (≥ 2 активных владельца, себя не менять).

**Branding (новый тег, владелец организации):**

9. `getTenantBranding`, `updateTenantBranding` (новая версия, `If-Match`, автокоррекция контраста, термины из каталога, меню, «Работает на Ортус»), `uploadBrandingAsset` (логотип и знак: PNG, SVG, JPEG, WebP до 1 МБ).
10. `TenantContext.branding` в `getMyContext` — действующее оформление для всех участников.

Права: новый ключ `branding.manage` (`owner_only`, модуль `core.modules`); остальное — существующие `billing.*`, `platform.*`. Коды ошибок — существующие (`request_pending`, `tier_below_usage`, `seats_exhausted`).

## 3. Миграции control (блок 0007+)

- `0007_billing_requests_price_book.sql` — отмена запланированной версии (`cancelled_at`/`cancelled_by`, EXCLUDE только по действующим), уникальность названия ступени в версии, у заявки — отмена владельцем, срок применения (понижение), сумма, последовательность номеров `SR-N`; `tenant_usage_daily` — снимки использования для «Использования».
