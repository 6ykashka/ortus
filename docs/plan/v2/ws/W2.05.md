## 1. Цель

1. **`modules/fleet/trips`** — рейс водителя:
   - `startTrip` (S2-06, AC-03 для старта): одна онлайн-транзакция (D-09: выезд только онлайн, офлайн-старта нет). Блокировки в порядке Q-W2.04-18: осмотр → рейс → бронь (`sched.Consume`). Бронь рейса живая (иначе 409 `reservation_expired` / `invalid_transition`), осмотр — последний осмотр выезда этого рейса (иначе 422), блокирующего дефекта на проверке нет (409 `blocking_defect_open`), рейс в `inspection`, стартует водитель рейса (владелец — любой). Рейс → `on_route`, `started_at`, юрлицо рейса — юрлицо фирмы по умолчанию (ближайшее подразделение вверх с юрлицом), аудит, событие `fleet.trip.started.v1`. Два старта одной брони → один успех.
   - рабочий экран (S2-07): `getTripPlan`, `listTripPlans` (проекция `TripPlan`; участник с функцией «Водитель» видит только свои рейсы), `getTrip`, `listTrips` (Trip 0.1 начатых рейсов), `finishTripRoute` (`on_route → returning`, If-Match, только водитель).
   - сдача (S2-09): `returnTrip` (`returning|rework → submitted`, If-Match): осмотр — последний осмотр сдачи рейса, после доработки — новый; пробег ≥ пробега выезда (422 `odometer_decrease`); новые дефекты фиксирует осмотр сдачи W2.04. Аудит, событие `fleet.trip.submitted.v1`.
2. **`modules/fleet/expenses`** (S2-08): `createTripExpense`, `listTripExpenses`, `getTripExpense`. Категории D-12 (ответ 17.10): `fuel, wash, parking, toll, tire_service, other`; у `other` комментарий обязателен (422, поле `comment`, «Для категории «Прочее» добавьте комментарий»); штрафы — не расход. Сумма 0 < a ≤ 200 000 ₽ (`amount_invalid`), чек — готовый файл рейса с назначением `expense_receipt`, рейс `on_route|returning|rework`, пишет водитель рейса. `reviewTripExpense` — W2.06.
3. **Подключение** — `cmd/api/fleet_trips.go` (наложение, как W2.04); одна строка в `newFleet` (`cmd/api/fleet.go`).
4. **Изоляция** — `backend/test/isolation/fleet_trips.yaml` (`pending: W2.05` до хендлера) и `fleet_trips_gate.yaml` (отказы шлюза).
5. **Сид показа** — `cmd/seed/fleet_trips.go`: рейсы «Альты» Р-208 (Илья Васильев) и Р-211 как MSW (`seedID`, груз, остановки), на день сида; одна строка в `cmd/seed/tenant.go`.

## 10. Риски и решения по умолчанию

- `listTripPlans` по DoR — S2-13 (W2.03); экрану водителя он нужен, поэтому проекция `TripPlan` и оба чтения — в `trips`. Если W2.03 сделает свой `listTripPlans`, интегратор выбирает один.
- Чек: в схеме одна колонка `receipt_file_id` → в пилоте ровно один чек (больше — 422). Литры топлива: CHECK 0002 требует `liters` у `fuel` → 422 «Укажите литры» (UI считает необязательными; правка CHECK — стюард).
- Остановки сида: `time_window = [plannedAt, plannedAt]`.
- Окна рейсов сида — от часа запуска сида (Р-208 начался час назад, 4 ч; Р-211 — через 5 ч от начала Р-208), чтобы бронь на рейс работала в день показа.
