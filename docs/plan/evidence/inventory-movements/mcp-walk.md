## Итог проходки

- Ширины: 1440×900, 768×1024, 390×844 — снимки и деревья доступности (snapshot-*.txt, *.png) рядом.
- Эталона нет (no-reference, B-6): сверка с design-2026-10-19 не выполняется; ближайшее в эталоне — блоки «Остатки кабинета» и «Движения склада» на странице «Салон и SPA» (:1890–1891), их слова («Движения склада», партии, срок годности) использованы.
- Негативные проверки: расход больше остатка — отказ в окне (в консоли один ожидаемый ответ 409, это отказ сервера по сценарию, не ошибка страницы); нет права — гейт «Нет доступа к разделу «Склад и материалы»» (водитель). «Только чтение», «нет связи», сбой загрузки и «Повторить» проходят в e2e (e2e/inventory.spec.ts, e2e/inventory-movements.spec.ts) через X-Test-Scenario и пресет trial-ended; в проходке не повторялись.
- Консоль: ошибок страницы и предупреждений React нет. network.txt — запросы к /api/v1/… приложения (сценарный сервер MSW); два запроса к gc.kis.v2.scr.kaspersky-labs.com вставляет антивирус этого ПК в страницу (не приложение), других чужих хостов нет.
- Наблюдение: кнопка с иконкой в ARIA-снимке @playwright/mcp печатается без имени (имя равно тексту потомков) — элемент ищется по следующей строке текста; на страницах это обычный Button @ortus/ui, имя доступно (getByRole('button', { name }) в e2e).
- Расхождений с протоколом нет; замечание по вёрстке (дубль «Позиция 1» заголовком и подписью поля в окне «Новое движение») исправлено до коммита.
