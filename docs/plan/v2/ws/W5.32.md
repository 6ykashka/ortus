# W5.32 Страница «Касса» (кассы, входящие, смены, настройки)

Этап 5 · шаг 5.3 · дорожка Ф · размер L · слот 5 · вид `frontend`, режим mock (MSW, контракт 0.12.0-stage5).
Зависит от: W5.00 (контракт кассы и сценарный сервер `msw/cash`), W5.30 (домен, только как источник правил). Параллельно: W5.31 (backend), W5.33 («Подотчёт» и «Мой подотчёт»).

## 1. Цель

Страница «Касса» (`/t/:tenantId/cash`, ключ `cash`) по `design/Касса.dc.html` (тег `design-2026-10-19`), разбор — `docs/plan/v2/analysis/dor/cash.md` §1.4–1.6:

- вкладки «Кассы» (`K:42–105`), «Входящие» с панелями предложения, заявки и перемещения (`K:107–193`), «Смены» (`K:195–251`), «Настройки» (`K:319–342`); вкладку «Подотчёт» выдающего делает W5.33 (слот, см. §4);
- диалоги: «Новая операция», «Открыть смену», «Закрыть смену», «Перемещение», «Причина» (пять действий), «Новая касса» (мастер с «Кто получит доступ»);
- состояния: загрузка, ошибка, нет доступа (`isNone`), баннер ККТ, офлайн-блокировка кнопок (Q-W4.00-cash-18), диплинки `?open=inbox|pr:<key>|rq:<id>|tr:<id>|sh:<id>|acc:<id>`.

## 2. Границы файлов

Пишу только в `frontend/apps/web/src/routes/cash/**` (код, CSS, тексты, Vitest), `frontend/apps/web/e2e/cash*.spec.ts` и `cash.helpers.ts`, `frontend/apps/web/e2e/visual/allowlist/cash*.md`, этот бриф, отчёт `docs/plan/v2/reports/W5.32.md`, `docs/plan/evidence/cash-*/`.
Не трогаю: `api/**`, контракт и сценарный сервер (`packages/adapter/src/msw/cash`), домен (`packages/domain`), `packages/texts` (тексты страницы — локальный `routes/cash/texts.ts`, как у W2.21), `package.json`, меню (`nav/modules/cash.ts`), `design/`.

## 3. Правила и решения

- Деньги — копейки (`amountMinor`), в интерфейсе рубли «1 200 ₽» с неразрывным пробелом; ввод суммы — «1200», «1 200,50».
- Кнопки по `account.my.rights` и `my.limits` (PD-53): «Принять оплату/Новая операция» — `cash.post` (нужна открытая смена при `shiftMode ≠ none`), смены — `cash.shift.operate`, «Переместить» — `cash.transfer`, «Сторно» — `cash.reverse`, «Вернуть на пересчёт»/«Принять расхождение» — `cash.reconcile`, заявки — `cash.approve`; автора чужие права не обходят — сервер отвечает `self_approval`, страница показывает ответ.
- Сверх лимита роли ответ 202 с заявкой (Q-W4.00-cash-2): «Заявка отправлена на согласование».
- Остаток `null` — «скрыт»; сверка и ожидаемая сумма смены `null` — закрытие вслепую.
- Статьи — `listCashCategories` (сидовый справочник, Q-W4.00-cash-9). Срок отчёта — ISO-дата (Q-W4.00-cash-16, W5.33).
- Тексты и подписи — дословно из эталона; расхождения эталона с контрактом — Q-W5.32-N в `decisions.md` (через `decisionsNeeded`).
