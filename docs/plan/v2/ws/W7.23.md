## 1. Цель

Сервер тега `Docs` (45 операций) и `PublicDocs` (2 операции) поверх схемы `docs` (tenant 0061):

- **Доступ** — цепочка `docAccess` прототипа на снимке документов организации: организация → функция «Водитель» (финансы) → владелец бизнеса → папки пути («Только выбранные» обрывает наследование; роль области — на корневой папке; назначения ролей папок `docs_folder_*`; записи списка) → документ (режим, назначения, список, владелец документа, временные доступы маршрута). Права `docRights` (view/comment/suggest/edit/manage/share/export/sign/route/convert/shareExternal). Недоступный документ — 404 как несуществующий (AC-01).
- **Папки, документы, версии**: создание (v1), переименование, перенос с `dryRun` (кто получит и потеряет доступ), архив и возврат, версии (срез, имя, восстановление как v+1), комментарии, ответы, закрытие обсуждения, упоминание без доступа (`wait.mention`, выдача `grants`), внешние ссылки (токен и PIN показываются один раз, в базе дайджест и хэш; срок до 30 дней), журнал документа, шаблоны.
- **Адаптер сервера документов (D-32, ADR-0016)**: порт `Engine` с реализацией ONLYOFFICE-совместимого протокола (HS256 JWT, ключ версии `t<tenant>.d<document>.v<n>`); без сервера — `editorAvailable=false`, документ открывается на просмотр (Q-W4.00-documents-1). Callback `docServerCallback`: подпись JWT, тенант из ключа, повтор того же ключа новую версию не создаёт, устаревшая версия — 409.
- **Задания** `convert, ocr, merge, split, compress, pdfa`: очередь `docs.jobs`, порт `Processor` (OCRmyPDF + Tesseract, qpdf — внешние программы без оболочки), воркер, результат — новая версия или документ рядом, квота; слова OCR на проверку; скан с меткой `pdn` не распознаётся (DOC-07).
- Шлюз `cmd/api`: `/api/v1/internal/docs/callback` проходит без сессии (проверка JWT в обработчике).

Маршрут, подпись, ознакомление, синхронизация набора данных (`getDocRoute`, `startDocRoute`, `decideDocRoute`, `requestDocSignCode`, `confirmDocSign`, `ackDocument`, `closeDocAck`, `resumeDocRoute`, `cancelDocRoute`, `syncDocDataset`) — W7.24 и W7.20: до них 501 `not_implemented`, строки изоляции остаются `pending: W7.24`. Публичное открытие ссылки (`openDocLink`) — W7.23 (вместе с индексом control 0011).
