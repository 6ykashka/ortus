## 1. Цель

Экраны логиста фирмы рейса и менеджера фирмы водителя по макетам «Временный водитель - варианты.dc.html» (тег `design-2026-10-19b`), подписи дословно:

- **1a** — диалог `modal-driver-request` («Ресурсный пул», W2.23): строки «Рейс», «Груз», «Доступ», «Согласует»; блок «Машина» — «Едет на своей обычной» / «Ставим нашу машину» с выбором из подходящих свободных машин фирмы рейса, галочка «Можно взять свою обычную», недоступный вариант с причиной (`homeCarFits`), «Что произойдёт после одобрения»; запрос с `vehicle` (`home` | `host` | `host_or_home`).
- **1b** — «Входящие запросы» фирмы водителя: «Ждёт решения», «Когда», «Машина», «Ваша машина», «Что откроется …», «Одобрить с машиной» / «Только водителя» / «Отклонить» (или «Одобрить» / «Отклонить»), «Отклонить» — только с причиной (Q-W2.70-8).
- **1f** — карточка перевода у логиста в «Ресурсном пуле»: «Рейс», «Доступ», «Машины рейса» (выбрана, освобождена), «Машины нет …» + «Поставить машину», «Журнал», сноска о сроке выбора; до выбора — «Оставить {машина}» (`chooseReservation` логиста).
- **1g** — два пункта «Требует решения» на «Главной» логиста: `fleet.vehicle_choice_pending` («Р-211: водитель ещё не выбрал машину», «до 13:30», «Оставить Ford Transit»), `fleet.trip_without_vehicle` («Р-211: нет машины», «рейс в 14:00», «Поставить машину»).

## 5. Экраны и состояния

- Диалог 1a: режимы «Наша + можно свою» (по умолчанию, если обычная подходит), «Только наша», «Своя машина водителя»; обычная не подходит — красная рамка, «Отправить запрос» недоступна в режиме «своя», галочка `aria-disabled`; нет обычной машины — вариант 1 и галочка скрыты (правило 1); нет подходящей свободной машины фирмы рейса — вариант 2 без выбора, запрос уходит без машины (no-reference, Q-W2.73-1).
- Входящие 1b: с обычной машиной / без неё; причина отказа — поле «Причина» под кнопками, пустая — `role=alert` без запроса.
- Карточка 1f: до выбора (брони до выбора, «Оставить …»), выбрана / освобождена, одна машина, «Машины нет» + «Поставить машину» → «Рабочее место логиста» `?trip=`.
- «Главная» 1g: пункт выбора за 15 минут до срока; пункт «нет машины»; кнопки ведут в «Ресурсный пул» `?trip=` и на «Рабочее место логиста» `?trip=` (карточка «Главной» — переход, команды нет; Q-W2.73-2).
