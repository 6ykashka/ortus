# Сверка public-service-request с эталоном 1a (design-2026-10-19)

Эталон: Обращения - варианты.dc.html 1a, экран 4 «Ответ и оценка решения» (eference-1a-1440.png в ../public-service-page/). Реализация: impl-new-390.png, impl-resolved-390.png, impl-rated-390.png, impl-resolved-1440.png, impl-not-found-390.png.

Совпадает: номер моноширинным шрифтом и чип статуса («Решено» — зелёный), заголовок обращения, лента «Получили · Ответили · Решено» со временем, ответ команды слева, блок «Довольны ли решением?» с пятью значками и ссылкой «Вопрос не решён — вернуть в работу», поле «Написать» со значком камеры.

Отличия (намеренные):
- без стрелки «назад» в шапке: ссылка из SMS не знает страницы направления (в PublicServiceRequest нет slug);
- сообщения клиента показаны справа («Вы»), команды — слева («Команда»): в макете одна реплика команды;
- «Можно вернуть до {дата}» (eopenUntil) и «Не присылать опросы» («СТОП», Q-W4.00-service-15) добавлены по контракту;
- у закрытого обращения поле «Написать» заменено пояснением.
