## 1. Цель

После W2.26 владелец «Альты» и логист с ролью «Менеджер логистики» (пресет `logistics-ready`) в режимах `mock` и `stand`:

1. Открывают **«Данные»** из меню (группа ядра, на телефоне — «Ещё») и по URL `/t/:tenantId/data` (`?set=` — набор, ADR-0001). Заголовок «Данные», абзац эталона.
2. Видят вкладки `tablist «Наборы данных»` — наборы `listDatasets` в порядке сервера: «Автомобили», «Поездки», «Расходы» с иконками эталона и счётчиком строк области (`queryDataset` `includeCount`, «10 000+» при `visibleCountCapped`); по умолчанию «Поездки» (как `dtSet || 'trips'`).
3. Таблица: колонки — `Dataset.fields[].label`, ячейки — по типу значения (текст, число `ru-RU`, деньги «4 500 ₽», дата `дд.мм.гггг`, выбор — подпись `FieldDescriptor.options`, пусто — «—»); сортировка по заголовку (`unfold_more` → `arrow_upward` → `arrow_downward`) — `sort` запроса; строки — страницами по курсору, «Показать ещё».
4. **Фильтр** «По любому видимому полю» — `DatasetQuery.search` (с задержкой ввода); «По фильтру ничего не найдено» / «В вашей области записей нет».
5. **Вид**: «Без сохранённого вида» и личные виды набора («{набор}: «{фильтр}»»), «Сохранить вид» (недоступна без фильтра) — тост «Вид сохранён · личный»; хранится в браузере участника (Q-W2.51-7).
6. **Выгрузить** — только при `exportAllowed`; тост эталона «Выгрузка «{набор}»: {N} строк, фильтр и права зафиксированы. В демо файл не создаётся» (операции выгрузки нет, Q-W2.51-7; CSV — W2.50).
7. Подвал: «Источник: {модуль} · {набор}», «Обновлено: только что», `hiddenFieldLabels` → «Поле «Начисление» скрыто правами и не участвует в фильтре, сортировке и выгрузке», иначе «Строки ограничены вашей областью доступа».
8. Строка открывает карточку модуля («Изменения — в карточке модуля»): машина → «Рабочее место логиста», рейс → «Приёмка смен» (`submitted`, `accepted`, `rework`, `defect_review`) или «Рабочее место логиста» с `?trip=`, расход → «Приёмка смен» рейса.
9. Права: без `data.*` — гейт оболочки «Нет доступа к разделу «Данные»» (водитель, логист без роли); набор без права не приходит; «Начисление» — только с `fleet.earnings.read` (AC-05).
10. Состояния: загрузка (скелетон), ошибка и «Повторить», нет связи, наборов нет, раскладка 390 / 1440 (таблица прокручивается в своей карточке, `min-width: 560px` эталона).

5. «Показать ещё» — при `nextCursor` (в эталоне пагинации нет) — `no-reference`.
6. Переход из машины — «Рабочее место логиста» без выбора машины (в маршруте `fleet` параметра машины нет).
7. «Обновлено: только что» — как в эталоне (данные читаются при открытии и смене набора).
