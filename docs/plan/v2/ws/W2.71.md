## 4. Контракт `0.6.3-stage2`

1. `permissions.yaml`: `fleet.reservations.choose` (`level: create`, `scopes: [self]`, «Выбирать машину из предложенных», note docs/29); подпись `fleet.reservations.manage` — «Ставить и снимать брони»; `choose` — в шаблоне «Водитель» и в системной роли `temporary_driver`. `fleet.reservations.create` временному водителю не даётся (вариант (a) отклонён).
2. `errors.yaml`: `offer_closed` (409); `vehicle_incompatible`, `reservation_overlap` уже есть.
3. OpenAPI:
   - `DriverPoolPublicationCreate.usualVehicleId`, `DriverPoolPublication.usualVehicleId` (правило 1, TD-01);
   - `DriverAvailability.usualVehicle` — обычная машина в каталоге, совместимость с рейсом `?tripId=` (правило 2);
   - `DriverTransferCreate.vehicle` `{ mode: home | host | host_or_home, hostVehicleId }`, 409 `vehicle_incompatible` / `reservation_overlap`, 422 без обычной машины;
   - `DriverTransfer.vehicle` — режим, машины, решение по обычной, группа предложений, срок выбора, судьба каждой машины (1b, 1f);
   - `DriverTransferDecision.decision` + `approve_driver_only`; `reject` — причина обязательна (поле `comment`, Q-W2.70-8; в docs/29 — `reason`);
   - `Reservation` — `offerGroupId`, `offeredToMemberId`, `offerKind`, `chooseUntil`, `chosenAt`, `releasedAt`, `releaseReason`, `state` + `confirmed` (Q-W2.70-1);
   - `POST /fleet/reservations/{reservationId}/choose` (`chooseReservation`) → `{ chosen, released[] }`, идемпотентна, 409 `offer_closed`, 404 — не предложена; права `fleet.reservations.choose` (self) или `fleet.reservations.manage` («Оставить …»);
   - `TripVehicleAssignment.alternativeVehicleId` — свой водитель выбирает из двух (Q-W2.70-6);
   - события `fleet.reservation.held/confirmed/released.v1` с `offerGroupId` и причиной, уведомления, виды «Требует решения» `fleet.vehicle_choice_pending`, `fleet.trip_without_vehicle`;
   - `screens.yaml`: S2-20 на экранах пула, запроса, «Сегодня», «Автомобили», «Главной».
4. Миграция tenant `0019`: `fleet.pool_publications.usual_vehicle_id`; `fleet.driver_transfers` — `vehicle_mode`, `home_vehicle_id`, `host_vehicle_id`, `vehicle_decision`, `offer_group_id`; `sched.reservations` — `offer_group_id`, `offered_to`, `choose_until`, `chosen_at`, `released_at`, `release_reason`; бронь предложения — `hold` с `hold_expires_at = choose_until`; одна подтверждённая на группу; exclusion constraint не меняется; Down без cascade.

## 5. Изоляция (красные до W2.72)

Временный водитель: `POST /fleet/reservations` — 403; `choose` брони другого рейса или не предложенной ему — 404; `choose` после срока или второй раз — 409 `offer_closed`; `listVehicles` — только предложенные. Строки `pending: W2.72`: проходят на 501 и шлюзе, в строгом режиме (`isolation_pending`) — красные до хендлера.
