# W2.97 — Isolation AC-01: время ответа по медиане серии

Вид: backend. Владеет: `backend/test/isolation/**` (матрица `matrix/run.go`, тесты).

## Постановка
AC-01 («время ответа чужого и несуществующего id неотличимо») краснел под нагрузкой ПК (259–367 мс против 3–22 мс) на строках forms_w482, calendar_w482, fleet_vehicle_assignments, knowledge_w482.

## Решение
- Серия 7 пар замеров, перед ней одна пара прогрева отбрасывается; сравнение медиан.
- Нарушение, если разность медиан больше Abs (250 мс) и в Ratio (3) раза больше быстрой медианы И разность минимумов тоже больше Abs: постоянная утечка замедляет каждый ответ, всплеск нагрузки оставляет быстрые.
- TDD: red `db6767f8a` (пачка медленных ответов не должна краснить), green `5c2cc25a9`; существующий `TestCheckNotFoundTiming` (искусственно медленный чужой путь) остаётся красным при утечке.

## Критерии
`test:isolation` три прогона подряд при `GOFLAGS=-p=2` — зелёные; тест утечки ловит постоянное замедление.
