## 1. Цель

После W4.20 в `frontend/packages/domain/src/modules/forms/` лежит домен форм итерации 14.10 с тестами паритета против `design/ortus/{models,api}.js`:

- **шаблоны**: `FORM_SETTINGS` (13 ключей), `FORM_TEMPLATES` (15 шаблонов, 19 типов вопросов, `showIf {mode, conds}`, баллы `score`), `templateDef(T)` → `{pages, fields}`, `FORM_VARS` (6 служебных переменных);
- **`formVal(f, r, src, fields)`** — значение ячейки Базы знаний: служебные `$at/$author/$object/$id/$form/$ver`, массив через «, », обрезка до 500, фото — «N · файлы в ответе R-…»;
- **`publishForm(formId, def)`** (новый, api.js:555–573): `{pages, fields}` или массив полей, проверки и тексты 14.10, новая неизменяемая версия, переименование id при смене типа (`-vN`), `by` — актор, событие владельцам;
- **`kbFits(rule, resp)` / `kbRun(env, form, resp, rule)`** (api.js:80–118): действие «Сохранить в Базу знаний» — строка таблицы (`table`) или запись страницы (`entry`), один результат на пару «ответ × правило», ошибки пишутся в `resp.actions` и событие владельцам;
- **`retryFormAction(respId, ruleId)`** (api.js:856–864) и `backfillKbRule(formId, ruleId)` (api.js:846–855, единственный потребитель `kbFits` в командах — без него паритет `kbFits` не проверить);
- `formsSeed` (fm-insp v1–v3, au-1, au-2; fm-foreman; R-0988, R-1012), `formsView` (api.js:206–207), `formsModule: DomainModule` (`key: 'forms'`, три команды, задержки 500/300/450).

Не входит (другие WS): `saveFormDraft`, `discardFormDraft`, `createForm`, `updateForm` — `FormPatch` переделывается в W4.00 (план v2 §4, C п. 13), команды — W4.21; изменение `recordInspection` — W4.24; БЗ v2 (`kbAccess`) — W4.30; UI и backend.

## 4. Контракты (экспорт `modules/forms/index.ts`; меняются только аддитивно)

```ts
FORM_SETTINGS: FormSettings; FORM_TEMPLATES: readonly FormTemplate[]; FORM_VARS: readonly [string, string][]
templateDef(T?: FormTemplate | null): FormDef                 // { pages: [{id:'pN', title}], fields: [{…, page, section}] }
formVal(f: Form | null | undefined, r: FormResponse, src: string, fields?: readonly FormField[]): string
validatePublish(def: FormDef | FormField[] | null | undefined, settings?: Partial<FormSettings>): FormField[]  // throw ApiError('validation', …)
kbFits(x: FormRule, r: FormResponse): boolean
kbRun(env: KbEnv, f: Form, r: FormResponse, x: FormRule): ActionResult
createFormsCommands(ctx: ModuleCtx, opts?: FormsOptions): { publishForm, retryFormAction, backfillKbRule }
formsSeed(tenantId): FormsSeed; formsView(db, actor): FormsView; createFormsModule(opts?), formsModule: DomainModule<FormsView | null>
```

Срез БД: `forms?: Form[]`, `responses?: FormResponse[]` (расширение `ModuleSlices`). Базу знаний модуль читает структурно (`FormsKnowledge`: `pages`, `tables`, `entries`) через `opts.knowledge(db)` (по умолчанию `db.knowledge`) — срез `knowledge` в `ModuleSlices` объявляет W4.30, тип `KbTable` до выноса в `core/types` живёт в `forms/types.ts`.

## 10. Риски и решения по умолчанию

| # | Вопрос | По умолчанию |
|---|---|---|
| 1 | Право автора правила в `kbRun`: эталон `M.can(knowledge, create)` без объекта засчитывает роль пространства любого раздела | PD-53: `can(…, 'knowledge', 'create', null, {type:'space', id: page.space})` — роль пространства действует только в своём пространстве |
| 2 | `kbRun` проверяет старое `page.access === 'owner'`, а не `kbAccess` v2 (B п. 16) | Как в эталоне до W4.30; вопрос в отчёт |
| 3 | `retryFormAction` правила-задачи (`au-1`) даёт «страница удалена из Базы знаний» | Как в эталоне (паритет); вопрос в отчёт |
| 4 | Время действия и дата версии — `new Date()` / литерал `'01.10.2026'` | `Clock` ядра (`hhmm`, `ddmmyyyy`, `ddmm`): на демо-часах совпадает с эталоном |
| 5 | Нет среза БЗ или версии формы — эталон падает `TypeError` | Нет БЗ → «страница удалена из Базы знаний»; нет версии → пустой список полей |
| 6 | `KbTable` по B §5.1 — в `core/types` (каталог W0.11) | Тип в `forms/types.ts`; вынос — интегратор при W4.30 |
| 7 | `docs/20` блокирует публикацию ещё в двух случаях (условие ссылается вниз или на удалённый вопрос; скрытый обязательный вопрос без значения), `api.js` их не проверяет и текстов нет | Как в эталоне (`api.js`); вопрос в отчёт — тексты нужны от владельца продукта |
| 8 | Мелкие дефекты эталона: `formVal` принимает имена свойств объекта (`toString`) за переменные; вариант-объект с пустой подписью (`label: ''`) засчитывается как вариант (`String(o.label \|\| o)`) | Исправлено: переменные — только свои ключи, подпись варианта-объекта — `label`. На данных эталона не проявляется |
