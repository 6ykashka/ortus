## 7. Решения по умолчанию (вопросы — в отчёт)

1. Организация страницы сотрудника — из сессии: последняя выбранная (`lastTenantId`), затем другие активные; форма ищется по id (UUID единственен) — Q-W4.70-1.
2. `PublicForm` не отдаёт названия формы — заголовок страницы гостя — название первой страницы версии — Q-W4.70-2 (стюарду: `PublicFormPresentation.title`).
3. «Вы уже отвечали» до отправки — по `Form.my.respond = false` при открытой форме с «Один ответ от сотрудника»; иначе «Приём ответов закрыт» (контракт не различает причину) — Q-W4.70-3.
4. Файл гостя отправляется только после проверки (`ready`, как требует сервер); до этого — «Файл ещё проверяется — подождите».
5. Тексты без эталона — `forms.fill.*` (no-reference, Q-W4.00-forms-19, Q-W4.05-9).
