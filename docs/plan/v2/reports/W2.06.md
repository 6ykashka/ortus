## Сделано

- **`backend/internal/modules/fleet/review`** — приёмка смены менеджером (наложение на тег Fleet):
  - `reviewTrip` (S2-10): If-Match рейса, Idempotency-Key, одна транзакция; блокировка рейса `for update`. Только из `submitted`, иначе 409 `invalid_transition` «Смена уже обработана». Решения:
    - `approve` — рейс `accepted` (`reviewed_at`, `reviewed_by`); **машина освобождается только здесь**: статус машины W2.02 считается из состояния рейса (`accepted` его не держит), пробег машины берётся из осмотра сдачи (не уменьшается), потреблённая бронь рейса (машина и водитель комплекта) укорачивается до момента приёмки, остаток окна свободен для новой брони; расходы `claimed` подтверждаются (`verified`, Q-W2.21-5);
    - `maintenance_required` — то же, машина «Недоступна · нужен ремонт» (`service_state = maintenance`, Q-W2.00-5);
    - `rework` — рейс `rework`, машина остаётся занятой, расходы ждут; непустой комментарий («Опишите, что нужно исправить») и хотя бы один раздел `photos, odometer, expenses, checklist` («Отметьте хотя бы один раздел для доработки»), неизвестный раздел — 422;
    - `reject` — 422 «В пилоте смену принимают или возвращают на доработку.» (Q-W2.00-5); разделы не у доработки — 422.
  - каждое решение — раунд `fleet.trip_reviews` (попытка = число раундов + 1; `TripPlan.lastReview` W2.05 показывает его), аудит `fleet.trip.review`, событие `fleet.trip.reviewed.v1`, уведомление водителю: «Смена {номер} принята. Машина свободна.» / «… принята. Машина отправлена в ремонт.» / «Смена {номер} возвращена на доработку: {комментарий}» (без сумм, AC-05). Ответ — Trip 0.1 (`approved` / `in_progress`).
  - `reviewTripExpense` (S2-11): If-Match расхода; `approve → verified`, `reject → rejected` у расхода `claimed` (иначе 409 «Расход уже проверен.»), пока смена не принята (иначе 409 «Расходы проверяют до приёмки смены.»); комментарий проверки — в аудите `fleet.expense.review`; событие `fleet.expense.reviewed.v1`. Блокировки: рейс, затем расход (порядок `createTripExpense` и `reviewTrip`).
  - доступ: `fleet.trips.review` / `fleet.expenses.review` над подразделением рейса (владелец — любой); невидимый рейс (и чужой для участника с функцией «Водитель») — 404 «Рейс не найден.», видимый без права — 403; **водитель рейса не принимает свою смену и свои расходы** — 403 «Свою смену принимает другой менеджер.» / «Свой расход проверяет другой менеджер.».
