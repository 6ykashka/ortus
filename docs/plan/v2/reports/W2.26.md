## Сделано

Страница `core-data` «Данные» (`/t/:tenantId/data`, `?set=` — ADR-0001) по эталону `design-stage-2` «Ортус CRM.dc.html» pg.data :1960–1979, dataVM :4179–4208 (06 §7, чек-лист §13 п. 16–22):

- **Наборы** — `listDatasets` в порядке сервера: вкладки `tablist «Наборы данных»` с иконками эталона (`local_shipping`, `route`, `receipt_long`) и счётчиком строк области (`queryDataset` `limit 1`, `includeCount`; «10 000+» при `visibleCountCapped`). По умолчанию — «Поездки» (`dtSet || 'trips'`); `?set=` сохраняет набор.
- **Таблица** — колонки `Dataset.fields[].label`, ячейки по типу `FieldValue` (текст; число `ru-RU` — как `M.num`/`M.int`; деньги `rub`; дата `дд.мм.гггг`; выбор — подпись `FieldDescriptor.options`; пусто — «—»). Сортировка заголовком: `unfold_more` → `arrow_upward` → `arrow_downward`, это `sort` запроса. Строки идут страницами по 50, по курсору, с кнопкой «Показать ещё». Курсор сбрасывается сменой фильтра или сортировки: это новый ключ запроса.
- **Фильтр** «По любому видимому полю» — `DatasetQuery.search` с задержкой ввода 300 мс. Пустые состояния: «По фильтру ничего не найдено» и «В вашей области записей нет».
- **Вид**: «Без сохранённого вида» и личные виды набора «{набор}: «{фильтр}»». «Сохранить вид» недоступна без фильтра, после сохранения — тост «Вид сохранён · личный». Правка фильтра снимает выбранный вид. Виды хранятся в `localStorage`, ключ — организация и участник (Q-W2.51-7). Сбой хранилища не ломает страницу.
- **«Выгрузить»** доступна только при `Dataset.exportAllowed`. По нажатию — тост эталона «Выгрузка «{набор}»: {N} строк, фильтр и права зафиксированы. В демо файл не создаётся», где N — `visibleCount` выборки с фильтром. Операции выгрузки в контракте нет (Q-W2.51-7; CSV — W2.50).
- **Подвал**: «Источник: Логистика · fleet.trips» (модуль из манифеста навигации → имя модуля домена), «Обновлено: только что». Если `hiddenFieldLabels` не пуст — «Поле «Начисление» скрыто правами и не участвует в фильтре, сортировке и выгрузке», иначе «Строки ограничены вашей областью доступа».
- **Переход в карточку модуля**:
  - машина → «Рабочее место логиста»;
  - рейс в `submitted`/`accepted`/`rework`/`defect_review` → «Приёмка смен» `?trip=`, остальные → рабочее место `?trip=`;
  - расход → «Приёмка смен» его рейса (id по номеру через `listTripPlans`).
  Строка открывается мышью и с клавиатуры (`tabindex=0`, Enter или пробел), фокус виден.
- **Права**: без `data.*` — гейт оболочки «Нет доступа к разделу «Данные»» (водитель, логист без роли). Набор без права сервер не отдаёт. «Начисление» видно только с `fleet.earnings.read` (AC-05).
- **Состояния**:
  - загрузка — скелетон `role=status «Загрузка»`;
  - ошибка каталога или выборки — `LoadFailed` страниц ядра «Не удалось загрузить данные: …» и «Повторить» (фокус возвращается на заголовок);
  - нет наборов — карточка «В вашей области записей нет»;
  - 390 px — таблица прокручивается внутри своей карточки (`min-width: 560px` эталона), область нажатия вкладки — 46 px при видимых 40 px.

## Осталось fixme / открытые вопросы

`fixme` нет. Вопросы Q-W2.26-N сделаны по значениям по умолчанию; внести в `docs/plan/decisions.md` — файл интегратора.

1. **Q-W2.26-1 · наборы этапа 4 (продукт).** «Ответы на осмотр» (forms.responses) и «Задачи» эталона — `out-of-stage` до этапа 4. Сервер их не отдаёт, страница показывает те наборы, что пришли из `listDatasets`.
2. **Q-W2.26-2 · личные виды (продукт).** В эталоне вид живёт в памяти страницы. Здесь он хранится в `localStorage` браузера по ключу «организация + участник» и переживает перезагрузку, но не переходит на другое устройство. Альтернатива — серверные виды (`data.views`, контракта нет).
3. **Q-W2.26-3 · переходы строк (продукт).**
   - Машина ведёт на «Рабочее место логиста» без выбора машины: параметра машины у маршрута `fleet` нет, эталон ставит `fleetPick`.

   - Строки открываются и с клавиатуры (в эталоне — только мышью).
4. **Q-W2.26-4 · страницы выборки (технический).** По 50 строк, «Показать ещё» по `nextCursor` — как у «Файлов» (Q-W1.24-12). В эталоне пагинации нет.
5. **Q-W2.26-5 · счётчик и состояния (технический).** Счётчик вкладки — отдельный `queryDataset` (`limit 1`, `includeCount`) на каждый набор, без фильтра (эталон считает строки набора до фильтра); после 10 000 — «10 000+». Загрузка и ошибка — состояния без эталона (allowlist).
6. **Q-W2.26-6 · наборов нет (продукт).** Если «Логистика» не подключена или нет права ни на один набор, показывается карточка «В вашей области записей нет» без вкладок. В эталоне наборы есть всегда.
