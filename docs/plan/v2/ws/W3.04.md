# Бриф W3.04 · ПДн: карта полей, черновики политики, согласий и поручения

Этап 3 · размер S · режим страниц: не применяется (только документация) · контрактный PR: не нужен · строки изоляции: нет. Ветка `ws/W3.04` от `main`.

## Задача

Составить `docs/legal/pdn/*.md`: карта ПДн по схеме БД и контракту `api/` (поле, категория, цель, срок, где хранится), черновики политики, согласий и поручения на обработку; шесть вопросов юристу из `design/docs/15-quality-security.md` как Q-W3.04-1…6 со значением по умолчанию «ждёт юриста». Код не трогать.

## Владеет

`docs/legal/**`, свой бриф и отчёт.

## Исходные решения

Ответы владельца 17.10 (ПДн п. 1–6, `docs/plan/v2/po-answers-2026-10-17.md`), ADR 0006 (D-05), Q-W0.08-5, Q-W1.05-17/20, Q-W2.44-4…6, Q-W4.30-8, Q-W4.00-cash-12.

## Критерии готовности

1. Карта покрывает все таблицы control (0001–0009) и tenant (0001–0027) и поля контракта с ПДн.
2. Для каждого поля есть срок («факт» и «цель») и расхождения собраны отдельно.
3. Черновики политики, согласий, поручения пригодны для передачи юристу, реквизиты в `[…]`.
4. Шесть вопросов с идентификаторами Q-W3.04-N переданы интегратору для `decisions.md`.
5. `lint`, `typecheck`, `test` зелёные.
