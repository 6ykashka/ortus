## 1. Цель

1. **Сквозной путь этапа на стенде** (организация «Лотос»): владелец подключает склад и кассу к салону → заводит склад, материал с приходом партии, услугу с техкартой, кассу и смену → записывает клиента на практика, кабинет и стол с буферами (визит — одна бронь, гонка за кабинет даёт ровно один успех) → отмечает факт выполнения («незавершённый учёт») → завершает визит: расход материалов техкарты один раз по FEFO, цена по факту → касса получает предложение «визит» → кассир проводит оплату в смену → закрытие смены со сверкой Z-отчёта и итогов терминала → остаток кассы и журнал совпадают с суммой визита. Страницы «Салон и SPA», «Склад», «Касса» открываются на настоящем backend и показывают те же числа.
2. **Строки изоляции модулей этапа 5**: чужая организация не видит услуги, визиты, остатки склада, кассы, смены и предложения «Лотоса» (404 как у несуществующих) — положительные строки с установленными модулями; у фикстур матрицы W1.04 модулей этапа 5 нет (Q-W5.20-12, Q-W5.31-9), поэтому строки идут сквозным путём стенда между двумя организациями сида.
3. **Полный `e2e:stand` слота 1** — только проверяется, spec страниц других WS не правятся.
