## 1. Инвентарь экранов

### 1.0 Как модуль подключается (O)

- **Вставка:** `O:1897–1899` — `<dc-import name="Касса" db mid open on-opened on-api on-nav on-toast hint-size="100%,640px">`, страница `pg.cash`. В `PAGE_MOD` (`O:2302`) страница привязана к модулю `cash`.
- **Пропсы** (`O:2877–2879`):
  - `db` — `cashView` для актёра;
  - `mid` — id участника персонажа;
  - `open` — диплинк. Форматы (`K:552–561`): `inbox`, `pr:<key>`, `rq:<id>`, `tr:<id>` (вкладка «Входящие»), `sh:<id>` («Смены»), `adv:<id>` («Подотчёт»), `acc:<id>` («Кассы»);
  - `onNav(k,id)` — переходы `users`→`roles`, `review`→приёмка смены по рейсу, `repair`, `spa`, `service`;
  - `onApi(m,args)` — обёртка над `this.run('cash:'+m)`, тихие коды `validation, forbidden, conflict, not_found`;
  - `onToast`.
- **Режим без оболочки** (`K:528`): модуль сам поднимает `createMockAdapter()` с актёром `m-owner` и организацией `t-alta`.
- **Меню:**
  - пункт «Касса» (`account_balance_wallet`, `O:2964`) показывается по `M.can(db, mid, 'cash','view')` у персонажей owner (`O:2988`), manager (`O:2996`) и therapist (`O:3001`);
  - водителю (`O:3000`) и прорабу (`O:3002`) вместо него показывается «Подотчёт» (`cashSelf`, `O:2968`) — только если у участника есть касса вида `advance`;
  - бейдж — `db.cash.badge` (`O:2967`).
- **«Главная · Требует решения»:** `O:4093` раскладывает `db.cash.todo` в карточки. Карточка ведёт на `go('cash', {cashOpen: t.open})`, источники — `C:162–174`. Карточек пять видов:
  - «Касса · сверка», «Касса · согласовать», «Касса · принять»;
  - «Подотчёт · чек», «Подотчёт · срок»;
  - сводная «Касса · входящие».
- **«Данные»:** `O:4194–4196` — наборы «Кассовые операции» (`source: 'Касса · cash.operations'`, колонки «Операция · Касса · Тип · Основание · Сумма») и «Смены кассы» («Смена · Касса · Статус · Посчитано · Расхождение»). Набора «ДДС» нет.
- **Роли:**
  - блок «Касса · остаток и лимиты» в редакторе роли (`O:373–378`, VM `O:3196–3199`): галочки `cash.balance.read`, `cash.advance.self` (у роли с функцией «Водитель» заблокирована во включённом состоянии), поля «Расход без согласования до, ₽», «Возврат без согласования до, ₽», «Выдача под отчёт до, ₽»;
  - область «Касса» в диалоге назначения (`O:2214`, `O:3981–3998`) предлагается только роли с модулем cash. Подсказка: «Только касса «…»: другие кассы по этой роли не видны»;
  - `scopeLabel` — «Касса «…»» (`M:273`);
  - `assign` (`A:416`) отвечает «Область «Касса» подходит только ролям с модулем «Касса»»;
  - `saveRole` (`A:439`): у роли с функцией «Водитель» включается `self`;
  - `rolePermKeys` (`M:317–318`) добавляет `cash.balance.read` и `cash.advance.self`.

### 1.2 Ширины

В макете модуля одна точка перелома — ширина контейнера `cw < 820` (ResizeObserver `K:522`, `K:586`).
- **Узко** (390 и обычно 768 — внутри оболочки контейнер уже 820): одна колонка `minmax(0,1fr)`, `K:602`.
- **Широко** (1440): «Входящие» — `360px + 1fr`, остальные вкладки — `300px + 1fr`.

- **Макеты V:**
  - 1a–1d — 1280 px (только десктоп);
  - 1e — три телефона по 360 px (`V:574`, `V:613`, `V:649`). В основном файле мобильной кассы для кассира нет: там только узкая колонка.
