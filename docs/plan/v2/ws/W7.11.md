# W7.11 Чаты: хранение, состав из ролей, политики хранения и очистки, чаты записей (backend)

Этап 7 · дорожка Б (backend) · шаг 7.1 · размер L · слот 7 · страниц нет.
Зависит от: W7.00 (контракт 0.12.0-stage7, миграция tenant 0060, тег `Chats`, 37 операций), W7.10 (домен: паритет), W4.01 (область `chat` в оценщике). Блокирует: W7.12 (подсказка `chat.changed`), W7.13 (страница).

## 1. Цель

Сервер тега `Chats` поверх схемы `chat` (миграция 0060) в пакете `backend/internal/modules/chats`:

- чаты пяти видов, источники состава и материализованный состав (`chat_members`), пересчёт состава по источникам;
- сообщения с номером в чате без дыр, версии правок, удаление «меткой», важное и подтверждения, опросы (анонимный — `voter_hash`), закрепление, прочтение, ПДн (маска и раскрытие с журналом), одноразовые файлы;
- политики видов в пределах организации (`BOUNDS`), переопределения чата, место чата (пороги 75/90/100 %), очистка вложений с `dryRun`, удержания, журнал, выгрузка заданием;
- задания по сроку (`Service.Sweep`): исчезновение временных, одноразовые файлы через 24 часа, срок хранения вложений и удалённых, напоминание об опросах;
- чаты записей (рейс, объект): порт `RecordChats` — создание по записи, служебные сообщения модулей, архив при закрытии записи;
- события `chat.*.v1` в outbox, аудит чувствительных действий, строки изоляции вместо `pending: W7.11`.
