## Вопросы по умолчанию (Q-W7.26-N)

1. Подтверждение подписи — пароль (`pep_login`), не код из SMS (контракт, D-31).
2. Кнопки «Демо:» не переносятся.
3. Проект задачи не выбирается (системный «ДОК · Документы · маршруты»).
4. Автор действий — запустивший маршрут или `my.can.manage`; решает сервер.
5. Флажок «Сохранить как шаблон папки» — только с `docs.templates.manage`.
6. «Подпись заказчика» — только у документа со связью; имя и телефон вводятся в шаге.
7. Контракт не отдаёт число адресатов ознакомления: «ознакомились: N» вместо «N из M».
8. Выбор участников требует `members.read`; у логиста его нет — применяется шаблон, выбор недоступен. Нужна операция кандидатов маршрута.
9. В `TenantContext` нет `memberId`: «я» ищется по имени среди участников.
10. У `Document` нет идентификатора PDF/A-копии: «Открыть PDF/A-копию» — через `onOpenPdfa`.
