# W2.102 · shell.spec.ts:232 — «Подотчёт» прораба

Вид: frontend. Слот 2. Владелец оболочки — W1.49, страница — W5.33.

## Постановка

Тест «390: нижняя навигация водителя и прораба — как в эталоне (:3028)» красный после W5.32/W5.33: «Подотчёт» прораба открывает `/cash-self` с пустым состоянием «Кассы недоступны».

## Причина

Шаблоны «Водитель» и «Прораб» контракта не содержат `cash.advance.self` (Q-W5.33-7). Пункт меню и маршрут верны (эталон :3028: «Подотчёт»), без права страница пуста; с правом её заголовок — «Мой подотчёт».

## Решение

Менять нужно тест, не меню: перед входом владелец выдаёт право (`grantAdvanceSelf` из `cash-self.helpers.ts`), заголовок ожидается «Мой подотчёт». Файл: `frontend/apps/web/e2e/shell.spec.ts`.
