## Сделано

До W2.44 геоданные снимались только перекодированием холстом (W2.22). Когда холст файл не читает (HEIC в Chromium и Firefox, jsdom, битый файл), уходил исходный файл с GPS. Теперь геоданные не уходят ни по одному пути.

- **`frontend/apps/web/src/routes/core/files/upload/metadata.ts`** (новый) — `stripMetadata(bytes)` / `stripFileMetadata(blob)`: метаданные съёмки вырезаются из байтов без декодера.
  - **JPEG:** уходят APP1 (Exif, XMP), APP13 (Photoshop/IPTC), APP2 `MPF` и всё после EOI основного кадра (вторые кадры MPF со своим Exif); с возврата 1 — COM и все APPn, кроме APP0, APP2 `ICC_PROFILE` и APP14 `Adobe`. Сегменты разбираются по длинам, сжатые данные — с учётом `FF 00` и RSTn. Ориентация сохраняется минимальным Exif из одного тега Orientation.
  - **PNG:** уходят `eXIf`, `tEXt`/`zTXt`/`iTXt` и всё после `IEND`.
  - **WebP:** уходят чанки `EXIF` и `XMP `; флаги VP8X сбрасываются, размер RIFF пересчитывается.
  - **HEIF/HEIC/AVIF:** данные элементов `Exif` и `mime` XMP обнуляются на месте по `iinf`/`iloc` (версии 0–2, способы 0 и 1, смещения 4 и 8 байт). Боксы и `ftyp` не меняются, поэтому сниффинг сервера (`scan.go`) проходит.
  - Неизвестный формат и файл без метаданных возвращаются тем же объектом. У `File` сохраняются имя и время изменения.
  - Ошибка разбора считается дефектом: загрузка падает («Ошибка загрузки»), исходный файл не отправляется.
- **`image.ts`** (новый) — `prepareImage`, `fitSize`, `MAX_SIDE` перенесены из `driver/photos.ts`. Холст сжимает до 1600 px и перекодирует в JPEG 0,85 (D-08, как W2.22), результат проходит контрольное вырезание. Если холст файл не читает, вырезание выполняется из байтов без сжатия.
- **`upload.tsx`** (`modal-upload` W1.24) — файл очищается перед SHA-256 и PUT; в `initiateUpload` уходит размер очищенного файла, имя прежнее. Фото не сжимается: диалог общий, для документов тоже.
- **`driver/photos.ts`** — минимальная правка: `prepareImage` берётся из модуля загрузки, `fitSize`, `MAX_SIDE`, `prepareImage` реэкспортируются (интерфейс для W2.24 тот же).
- **Фикстуры** `metadata.fixtures.test-util.ts` — генерируются кодом, двоичных файлов в репозитории нет. Это JPEG (Exif с GPS IFD и GPSMapDatum-меткой, XMP, ICC, MPF, APP13, кадр после EOI, байты `FF D9` внутри DQT), PNG, WebP и HEIC (iloc v0/v1/v2), `withGps` для настоящего JPEG, `leaks()` — поиск меток.
- **e2e** `driver-today.spec.ts` — новый сценарий. JPEG 4000×3000 с холста страницы + Exif/XMP с GPS: тело PUT без меток, декодируется в 1600×1200. HEIC с GPS (Chromium не декодирует): тело PUT без меток, размер прежний, слоты «Фото · 2 из 5».
