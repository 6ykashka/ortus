# Ортус CRM — комплект для старта разработки v0.2

1 октября 2026 года. Комплект v0.1 (`uploads/ortus-crm-design-v0.1(1)/`: ТЗ, архитектура, API, OpenAPI, UX, сценарии) описывает **что** строим. Документы v0.2 в этой папке описывают, **как начать**: модель данных, каталог прав, ошибки, бэклог, инженерный регламент, качество, решения и дизайн-систему. Прототип — `Ортус CRM.dc.html`, справочник дизайн-системы — `Дизайн-система.dc.html`.

## Расхождения, найденные при подготовке v0.2

- Ключи прав прототипа (`fleet.inspections.create`, `fleet.trips.manage`, `fleet.pool.request`, `fleet.export`, `fleet.settings` и др.) не совпадают с OpenAPI. Канон — OpenAPI; соответствие — `11-permissions.yaml → prototype_renames`.
- В OpenAPI 0.1 схема `Problem.code` — свободная строка. Предложен реестр (`12`).
- В прототипе состояния тенанта: `trial / active / restricted / suspended`. В ТЗ (PLAT-02): `provisioning / trial / active / grace / read_only / suspended / closing / closed`. Канон — ТЗ; `restricted` прототипа соответствует `grace` или `read_only`.
- Exclusion constraint брони не может напрямую вычитать буферы из интервала (выражение не IMMUTABLE), поэтому в схеме отдельное поле `occupied`, которое вычисляет сервис.

## Статус

Все документы v0.2 — проектные предложения. Миграции применены и ограничения проверены на PostgreSQL 16.4 (результаты — `10-data-model.md`, раздел «СУБД»); конкурентные сценарии ещё не прогонялись. Перед использованием — прогон миграций на стенде и ревью backend lead.
