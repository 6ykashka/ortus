### `pre-push` из git worktree: `design-preview --ref` отдаёт 404 (вне владения)

Первые два `git push` хук `pre-push` отклонил. В `test:tools` падал `tools/__tests__/design-preview.test.mjs:163` «отдаёт файл из тега, а не из рабочей копии»: `404 !== 200`. Отдельно этот тест проходит (16/16).

**Причина (проверено).** В хуке из worktree git выставляет `GIT_DIR` (`…/.git/worktrees/<имя>`), а `GIT_WORK_TREE` не выставляет. Тогда git считает корнем рабочей копии текущий каталог. `tools/design-preview.js` (стр. 108) вызывает `git show <ref>:./<путь>` с `cwd: design/`. Путь `./Ortus CRM.dc.html` git ищет от корня репозитория, файла там нет — отсюда 404. Воспроизведение: `$env:GIT_DIR='<…/.git/worktrees/wf_20787d28-e27-54>'; node --test tools/__tests__/design-preview.test.mjs` — `# fail 1`. С `GIT_WORK_TREE=<worktree>` — `# pass 16`.

**Как запушил.** `GIT_WORK_TREE=<корень worktree>` в окружении `git push` (это и есть его рабочая копия). Хук прошёл целиком, `--no-verify` не использовался. Исправить `design-preview.js` (вне владения) — предложение в integratorNotes.
