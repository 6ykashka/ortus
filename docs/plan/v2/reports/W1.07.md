## Сделано

- **`backend/internal/platform/notify/realtime`** (новый пакет; покрытие 92,0 % с integration, 83,5 % unit):
  - **кадры** (`message.go`): `Path`, `Protocol`, `Channel = "ortus_realtime"`, типы и причины `session.ended`, `CloseUnauthorized = 4401`, `ServerMessage`/`ClientMessage` (тест дрейфа с `components/auth/schemas.yaml` и `x-realtime`), `Hint` (адресаты `Accounts ∪ Sessions`, только идентификаторы) с `Validate`, `SessionKey` (SHA-256 — значение cookie никуда не уходит);
  - **билеты** (`tickets.go`): интерфейс `Tickets`, `MemTickets` (хранится только SHA-256, 60 с по `Clock`, одноразовость — погашение удаляет билет даже просроченный, ограничение 100 000 с вытеснением первым истекающего), `TicketResponse` → `authapi.RealtimeTicket` (heartbeat 5…120 с, `expiresAt` в UTC);
  - **хаб** (`hub.go`): соединения по аккаунту, раздача без блокировки производителя — переполнение очереди (32) пропускает подсказку, а `seq` всё равно растёт (клиент видит разрыв и перечитывает всё), `seq` ставит писатель соединения (кадры уходят по порядку), лимит 16 соединений на аккаунт, `Resync`, `Close`;
  - **шлюз** (`gateway.go`, `http.Handler` для `GET /api/v1/realtime`): точный `Origin` из `ALLOWED_ORIGINS` до апгрейда (403 `origin_not_allowed`), подпротокол `ortus.realtime.v1` обязателен (400 `malformed_request`), снятие дедлайнов `http.Server` с перехваченного соединения, первый кадр `auth` ≤ 10 с со строгим разбором → `Redeem` → сессия жива и того же аккаунта, иначе 4401; heartbeat 25 с: `ping`, нет `pong` за 2 интервала → 1008; на каждом такте сверка сессии: нет — `session.ended logout`, истекла по `Clock` — `expired`, затем 1000; подсказка `session.ended` по ключу сессии → кадр и 1000; сверх лимита — 1013; остановка `Hub.Close` — 1001; входящий кадр ≤ 1 КиБ (больше — 1009);
  - **`pg_notify`/`LISTEN`** (`notify.go`): `Notifier.Publish` (пачки ≤ 7900 байт делением адресатов пополам), `EncodeHint`/`DecodeHint` (только поля `Hint`, без хвостов), `Listener` (выделенное соединение, `LISTEN ortus_realtime`, переподключение 100 мс → 5 с, после переподключения — `Resync`), `PoolDialer` (соединение пула закрывается вместе с `LISTEN`), `Fanout` (подсказка `context.changed` инвалидирует кеш прав своей организации, всё — в хаб; `Resync` чистит кеш и хаб);
  - **кеш прав** (`cache.go`): `PolicyCache` — `authz.Source` W1.04 с переиспользованием субъекта и модулей при той же `policy_version` и возрасте < 1 с по своим часам (не `APP_FIXED_NOW`); версия читается на каждой проверке (`VersionMaxAge = 0`) или кешируется ≤ `VersionMaxAge` с немедленной инвалидацией; ошибки не кешируются (проверка падает закрыто); копии срезов; ограничение 10 000 записей. `PGVersions` — `select coalesce((select policy_version from access.policy_state), 0)`;
  - **`policy_version` и ретрансляция** (`policy.go`): `BumpPolicy` — `policy_version + 1` (строка создаётся, если её нет) и `access.policy.bumped.v1` (`policyVersion`, `personIds`, `reason`) в транзакции изменения; `Relay` для `cmd/worker` — `access.policy.bumped.v1` → люди организации → аккаунты членств **этой** организации (`status <> 'invited'`; пустой список — все активные) → `context.changed`; `HintPersons` — тот же путь для `notifications.changed` (W1.10).

## Осталось fixme / открытые вопросы

`fixme` и `t.Skip` нет. Решения по умолчанию, по которым сделано (вынести в `docs/plan/decisions.md`, раздел исполнителей этапа 1 — файл не мой; дублируются в `decisionsNeeded`):

1. **ADR-0015 «предложено» (Q-W1.00-7)** — сделано по варианту 1: WebSocket-шлюз в `cmd/api`, подсказки без данных.
2. **Библиотека** — `github.com/coder/websocket v1.8.15` в `backend/go.mod` (ADR-0015 называет её; интегратор подтверждает или заменяет).
3. **Свежесть версии политики** — `VersionMaxAge = 0`: `policy_version` читается на каждой проверке (одна строка tenant DB), субъект и модули переиспользуются ≤ 1 с при той же версии. Для нагрузки этапа 3 (W3.01) можно включить `VersionMaxAge ≤ 1 с` — инвалидация по `context.changed`.
4. **Часы кеша** — свои (`time.Now`), не `APP_FIXED_NOW`: иначе при фиксированных часах приложения записи не устаревали бы. Отзыв без смены версии (конец периода гранта) виден ≤ 1 с.
5. **Адресаты `context.changed`** — аккаунты членств организации (любой статус, кроме `invited`) у людей из `personIds`; пустой список — все активные участники. Человек сопоставляется с аккаунтом только внутри своей организации.
6. **`session.ended`** — `logout`: сессии нет в хранилище; `expired`: срок по `Clock` шлюза; `revoked`/`membership_ended` публикует владелец команды через `Notifier.Publish` (шлюз доставляет и закрывает). Для окончания членства у аккаунта с другими организациями правильнее `context.changed` — решение W1.06/W1.03.
7. **Переполнение очереди соединения** — подсказка пропускается, разрыв `seq` (не обрыв сокета).
