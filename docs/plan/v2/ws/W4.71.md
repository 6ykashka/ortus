## 10. Риски и решения по умолчанию

- Общие данные стенда меняют другие строки полного прогона (продление пробного «Альты» и т. п.) — сроки и счётчики проверяются по форме и по ответу API, а не литералами MSW.
- Открытая заявка на организацию одна, запланированная версия сетки тоже одна. Перед командой строка закрывает свои хвосты прошлых попыток (ретраи CI). В возврате 1 закрываются только хвосты с меткой `STAND_MARK`, а строки трёх проектов идут по очереди через замок `standLock`, так что прогон без `CI=true` с несколькими воркерами тоже проходит.
- Возврат 2: строки сверяются с ответами, которые читает страница, и в порядке полного `e2e-stand`. Сигнал конца пробного «Альты» берётся из `trial_ending` ответа (раньше идущие строки `platform-org-card` продлевают срок за порог 14 дней). Плитка «Организации» — из `tenantsByStatus`. «Занимают место» — из `listMembers`: путь владельца этапа 1 оставляет приглашение без участия, которого нет в `seats.used` (Q-W4.71-4). Состояния после чужих строк воспроизводятся без правки данных: строка подменяет ответ через `page.route`.
- Харнесс `tools/ci/e2e-stand.mjs` не принимает `--grep`: узкий прогон — локальный скрипт в `.claude/tmp/W4.71/` поверх его экспортов (`stepsFor`, `playwrightEnv`); предложение передачи `--grep` — в integratorNotes.
