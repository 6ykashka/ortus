## Замечания

- Сервер MCP — `@playwright/mcp` из `.mcp.json` по stdio (инструментов `mcp__playwright__*` в сессии нет), браузер Chromium headless, `--isolated`, `--output-dir .playwright-mcp/5204`; приложение — Vite `--mode e2e` на 5204 (`VITE_ADAPTER=mock`), эталон — `tools/design-preview.js design 4104 --offline --ref design-stage-1`.
- Консоль: единственная ошибка — `404 /favicon.ico` (в `index.html` каркаса W0.09 нет иконки; файл вне границ W1.20 — замечание интегратору). Ошибок и предупреждений React нет.
- Сеть: запросы приложения — только `127.0.0.1:5204` (`/api/v1/*` отвечает service worker MSW). Хост `gc.kis.v2.scr.kaspersky-labs.com` — внедрение антивируса машины в страницу, к приложению не относится.
