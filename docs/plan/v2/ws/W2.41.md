## 1. Цель

Ответ владельца 17.10 на D-12 (ADR-0013): категории расходов — справочник тенанта с посевом шести (топливо, мойка, парковка, платная дорога, шиномонтаж и мелкий ремонт, прочее с обязательным комментарием); штрафы — не расход. Контракт и миграция уже есть (W2.52), этот WS:

1. backend: операции справочника `listExpenseCategories` (любой держатель `fleet.expenses.read`, `includeArchived`), `createExpenseCategory` (код `custom_N` или свой, дубль кода или подписи без регистра — 422), `archiveExpenseCategory` (If-Match; «Прочее» и уже архивная — 409; неизвестный код — 404), аудит команд;
2. backend: `createTripExpense` проверяет `kind` по справочнику — неизвестный код 422 «Категория расхода не найдена.», архивная — 422 «Категория в архиве — выберите другую.», категория с `commentRequired` без комментария — 422 «Для категории «{label}» добавьте комментарий» (у «Прочее» — текст W2.40);
3. backend: «Данные» — варианты и подписи поля «Категория» набора «Расходы» читаются из справочника тенанта (с архивными, в порядке каталога), а не из статического списка W2.08 (integratorNotes W2.52, п. 3а);
4. frontend: экран владельца «Категории расходов» (`company-expense-categories`, no-reference) — список, добавление, архив;
5. frontend: форма расхода водителя («Сегодня») и «Приёмка смен» берут категории и подписи из справочника.

## 4. Контракты

Без изменений (`0.6.1-stage2`). Решения по умолчанию в рамках контракта:

- ETag категории — `"rev-<revision>"` (как MSW): у `listExpenseCategories` нет ETag строк и нет чтения одной категории, поэтому клиент берёт If-Match архивации из `ExpenseCategory.revision`, одинаково для mock и стенда (вопрос стюарду — Q-W2.41-1);
- права: чтение — шлюз (`fleet.expenses.read` в любой области), команды — `modules.settings.manage` в области «организация» (шлюз + проверка сервиса);
- `custom_<N>` — следующий свободный номер, повтор при 23505 по PK; подпись — уникальна среди активных (`expense_categories_label_uq`) → 422.

## 5. Экраны

`company-expense-categories` «Категории расходов» — `/t/:tenantId/expense-categories`, страница «Логистики» вне меню (как «Очередь дефектов», «Начисления» W2.21), вход — «Связанные разделы» «Приёмки смен» у держателей `modules.settings.manage`; право страницы — `modules.settings.manage`. Состояния: загрузка (скелетон), ошибка с «Повторить», список активных (подпись, «Комментарий обязателен», «Набор по умолчанию»), «Прочее» без архивации, добавление (название, «Комментарий обязателен»; пусто — ошибка поля, дубль — ошибка сервера под полем), архивация с подтверждением (тост), архив (показать / скрыть), только чтение (нет формы и кнопок), нет права (гейт оболочки), офлайн (тост «нет связи», форма сохраняется). Подписи — без эталона, в `@ortus/texts` (`logisticsManager.expenseCategories`), allowlist `no-reference`.

«Сегодня» водителя: выпадающий список — активные категории справочника в порядке каталога (до загрузки — шесть кодов посева), у категории с `commentRequired` комментарий проверяется до отправки, ошибка — под полем комментария. «Приёмка смен»: подпись расхода — из справочника с архивными (код вне справочника — сам код).
