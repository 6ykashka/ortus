- **Q-W4.31-1** (по умолчанию: участники пространств в Go-сиде не пишутся). Сид домена W4.30 даёт Марине Котовой роль «Руководитель пространства» в «Логистике» и «Редактор» во втором пространстве, Вере Котельниковой — роль пространства. ### Известные ограничения (MVP)

- Снимок запроса по-прежнему держит журнал ознакомлений (до 5 лет), строки таблиц и записи форм всей организации: стоимость запроса растёт с ними линейно. Перед пилотом — грузить журнал и строки только для узла запроса (или лениво).
- Расписание — 09:00 по Москве (`moscow` модуля, UTC+3), не по часовому поясу организации; проверка, сделанная вручную после 09:00, засчитывается за проверку дня.
- Отказ запуска по правам пишется только в журнал правила; владельцам событие не уходит (в эталоне такой строки для БЗ нет; в «Задачах» — событие владельцам) — вопрос ниже.
- Стенд с системными часами: воркер в первую минуту после старта (после 09:00 по Москве) выполняет проверку дня, и страница сида «Как фотографировать машину при осмотре» (срок 30.09.2026) становится «Пора пересмотреть» — в MSW она «Действует», пока не нажать «Проверить сроки сейчас». Это поведение правила, а не расхождение данных; если e2e W4.32 на стенде проверяет исходный статус, харнессу — `WORKER_KB_REVIEW_INTERVAL=0` (интегратор, `tools/ci/e2e-stand.mjs`).
