## 3. Решения по умолчанию

- Права: чтение финансов и начислений — `repairs.finance.read`; начисление — `repairs.crew.accrue`; выплата — `repairs.crew.pay` (на каждый объект начисления); подрядчики — `repairs.subcontractors.manage`; ссылка — `repairs.client_link.manage`. Скрытый объект — 404.
- Q-W6.15-1: сумма начисления. В контракте и схеме нет ставок бригады. Пул акта = сумма акта × доля бригады (по умолчанию 40 %, `Service.CrewSharePct`), делится между работниками по числу принятых отметок с их участием (нет отметок — поровну между активной бригадой), остаток копеек — первому.
- Q-W6.15-2: строк `pending_act` до подписи акта сервис не создаёт (создаёт строки только `accrueByAct`); повторное начисление по тому же акту возвращает уже созданные строки.
- Q-W6.15-3: выплата — предложение вида `payroll` в кассу через порт `PayrollOffers` (адаптер `cmd/api/repairs_cash.go` над `cash.Service.Offer` в той же транзакции); состояние `paid` ставит `Service.MarkPaid` по проведению предложения (потребитель события кассы подключит интегратор).
- Q-W6.15-4: доступ подрядчика хранится строкой `repairs.subcontractors` и событиями шины; выдачу назначения роли «Подрядчик» в модуле доступа делает потребитель события.
- Q-W6.15-5: ссылка кабинета: токен — 32 случайных байта base64url, URL `<PUBLIC_ORIGIN>/c/<токен>`; SMS со ссылкой уходит через необязательный порт `LinkSender` (заглушка `LogCodes` пишет в журнал), `sentAt` ставится только при отправке.
- Q-W6.15-6: сдача объекта отзывает действующую ссылку (строка тенанта), в 410 кабинет уходит и без отзыва по статусу объекта.
- Q-W6.15-7: акты и счета создаются не операциями тега (в контракте их нет) — их пишут сид и последующие шаги; документ без суммы не начисляется (422 `actDocumentId`).

- Q-W6.15-8: состав финансов — договор = сумма объекта, получено = оплаченные счета, расходы = материалы + начисления + оплаченное подрядчикам, маржа план = договор − материалы − вся бригада − договоры подрядчиков.
- Q-W6.15-9: строки изоляции публичных операций — у pproveEstimateByClient строки нет (параметр ersion — число, гость без Idempotency-Key получает 400 до хендлера), всё покрыто isolation_w615_test.go.
