## 1. Цель

После W0.11 в `main` лежит ядро `frontend/packages/domain/src/core/`, на котором без правок ядра строятся модули пилота (W0.12) и все модульные потоки P1:

- **`Clock`**: инжектируемые часы, TZ `Europe/Moscow` при любом TZ хоста, пять демо-«сейчас» (`DEMO`), форматтеры `hhmm/ddmm/ddmmyyyy/ddmmHHMM/plusDaysDdMm`, минуты чатов;
- **`IdGen`** поверх общего `db.seq` (детерминированные `e…`, `R-…`, `T-…`, `KEY-…`);
- **`format`**: `plural`, `pluralN`, `num`, `int`, `rub`, `signRub`, `gb`, `hm`, `shortName`, `maskPhone`, `maskPdn`, `hasPdn`, `emailOk`, `initials`;
- **ошибки**: `ApiError`, 18 кодов прототипа, реестр канонических кодов (12 v0.2 + коды 17/D-34 + клиентские), маппинг в обе стороны, политика `forbidden`/`not_found` (`denyAccess`);
- **доступ**: `unit`, `unitLabel`, `firmsOf`, `scopeCovers`, `scopeLabel` (11 видов), `moduleOn`, `grants`, `can` с правилом **PD-53**, `canAny` (видимость раздела), `canEarnings`, `assertCan`, `rolePermKeys` (+ `cash.balance.read`, `cash.advance.self`);
- **`entries`**: `entryHas` (связь «прораб объекта» по id, не по ФИО), `foremanIdOf`, `relationHas`, `entryKey`, `entryIcon`, `entryPeople`;
- **события**: `createEmitter` (`db.events`, id через `IdGen`, время через `Clock`);
- **контракты модулей**: `DomainModule`, `ModuleCtx`, `CommandFn`, `composeCommands` (реестр без дублей), `TaskPort` (+ тестовый двойник), хуки сида `SEED_STAGES`/`seedStagesFor`/`runSeedHooks` (порядок `api.js:37–45`).

Модули (`modules/**`) и сид (`seed/**`) **не переносятся**: это W0.12 и опережающие дорожки.

## 4. Контракты (публикуются из `@ortus/domain`; меняются только аддитивно)

### 4.1 Доступ и PD-53

```ts
can(db, memberId, mod, verb, unitId?: string | null, obj?: ObjectRef): CanResult
canAny(db, memberId, mod, verb): CanResult      // видимость раздела/меню, не авторизация действия
assertCan(db, memberId, mod, verb, unitId?, obj?): Grant   // throw ApiError(reason, REASON[reason].text)
```

- Порядок проверок как у эталона: модуль подключён (`module_off`/`module_readonly`) → роль разрешает действие (`no_permission`) → объект в области (`no_scope`).
- **PD-53:** грант с объектной областью (`project`, `space`, `page`, `folder`, `doc`, `chat`, `account`) засчитывается **только** при `obj` того же вида и id. Без `obj` такие гранты не дают права. `canAny` учитывает все гранты (для гейта раздела), `canEarnings` объектные гранты не учитывает.
- Расхождение с эталоном (эталон даёт `ok`) — allowlist с PD-53: `createProject` (`m-kotova`, `tasks.settings` через `r-pm @ fleet`), `saveKbPage` (`m-kotelnikova`, `knowledge.create` через `r-kb-editor @ sp-log`), `toggleTaskCheck` (`m-vasiliev`, `tasks.edit` через `r-exec @ fleet`).

### 4.2 Модуль, контекст, задачи, сид

```ts
interface ModuleCtx { getDb(): TenantDb; getActor(): string | null; clock: Clock; ids: IdGen;
  ApiError: typeof ApiError; can: AccessApi; emit: Emit; tasks: TaskPort }
interface DomainModule<S = unknown> { key: ModuleKey; install(db: TenantDb, opts: SeedOpts): void;
  view(db: TenantDb, actor: string, slice: S): S | null; commands(ctx: ModuleCtx): Record<string, CommandFn>;
  methods: readonly string[]; delays: Readonly<Record<string, number>> }
composeCommands(mods, ctx): Record<string, CommandFn>   // дубль имени метода или расхождение methods/commands/delays → Error
interface TaskPort { create(draft: TaskDraft): { id: string }; get(id): TaskSnapshot | undefined;
  update(id, patch: TaskPatch): void; comment(id, c: TaskComment): void; statusName(projectId, cat, preferred): string }
SEED_STAGES = ['normProjects', 'service', 'knowledge', 'docs', 'chats', 'cash']
seedStagesFor('t-alta') → все шесть; seedStagesFor('t-lotos') → ['knowledge', 'docs', 'chats', 'cash']
runSeedHooks(db, hooks, opts)   // вызывает зарегистрированные стадии в этом порядке, пропуская отсутствующие
```

`seed/compose.ts` (интегратор / W0.12) только регистрирует хуки модулей и вызывает `runSeedHooks`.

### 4.3 Часы, id, ошибки

- `Clock { now(): Date }`; `fixedClock(iso)`, `manualClock(iso)` (`set`, `advance`), `systemClock`, `driftClock(baseIso, base = systemClock)` (демо обращений: база + реальный дрейф), `demoClock = fixedClock(DEMO.now)`.
- `DEMO = { now: '2026-10-01T10:30:00+03:00', cashDay: '01.10', kbToday: '01.10.2026', docToday: '01.10.2026', chatNow: 665, svcBase: '2026-10-01T16:24:00+03:00' }`.
- `createIdGen(getHolder)`: `next(prefix, base = 0)` = `prefix + (base + seq++)`, `peek()`.
- `ApiError(code, message, extra?)` с полем `db?`; `PROTOTYPE_CODES` (18); `CANON_CODES` (код → HTTP); `toCanonCode(proto, {op}?)`, `toCanonCodes(proto)`, `toPrototypeCode(canon, {op}?)`; `denyAccess(visible, forbiddenText, notFoundText)` → `ApiError('forbidden' | 'not_found')`.
