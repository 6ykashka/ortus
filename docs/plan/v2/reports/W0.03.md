## Осталось fixme / открытые вопросы

- fixme нет.
- Хуки в этом worktree не установлены (`HUSKY=0`): `husky` пишет `core.hooksPath` в общий для всех worktree `.git/config`, а скил `git-commit` запрещает менять git config. Хуки проверены в одноразовом клоне. После слияния первый `corepack pnpm install` в основном чекауте включит их для всех worktree (путь относительный `.husky/_`; в worktree без `.husky/_` хуки не запускаются).
- Версии (вопрос интегратору): TypeScript 5.9.3 вместо 7.0.2 (`typescript-eslint` 8.71 поддерживает `<6.1`); ESLint 10.12.0 (9 снят с поддержки), поэтому `eslint-plugin-jsx-a11y` (только ≤ 9) не подключён — a11y покрывают axe-тесты; `lint-staged` 16.4.0 (17 требует Node ≥ 22.22.1, на машине 22.19.0).
- `check-icu` из старого WS-01 в v2 никому не назначен — предлагается W0.04 (job CI) или W0.05 (`tools/`).
- `depguard` в strict-режиме запрещает и импорты подпакетов своего же модуля (`internal/modules/fleet/a` → `…/fleet/b`) и `…/modules/*/api` соседей; W0.09 (или первый backend-модуль) добавляет нужные строки allow через интегратора.
- Пакеты-заглушки не имеют своих devDependencies: `tsc` берётся из корня (pnpm кладёт корневой `node_modules/.bin` в PATH). Владельцы пакетов добавляют свои зависимости с точной версией.
