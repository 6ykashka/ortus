## 3. Решения по умолчанию (Q-W6.23-N, в `decisionsNeeded` отчёта)

- Q-W6.23-1: в API нет «базового» значения длительности и паузы по этапам, только действующие. «Базовый план» рисует линию «по договору» от `baseline.dueOn` и серые полосы по расчёту без сдвигов; отклонения этапов считаются от него, а шапка («Прогноз», «+N раб. дней») — по `forecastDueOn` и `delayWd` сервера.
- Q-W6.23-2: в `ScheduleStage` нет принятой доли объёма и заявки снабжения: полоса идущего этапа без деления «принято / на приёмке», «Материала нет на объекте» — только из `issues` сервера (`no_material`).
- Q-W6.23-3: «сегодня» — часы браузера (Москва); в e2e задаётся `page.clock`.
- Q-W6.23-4: перетаскивание — только мышью на ширине ≥ 640 px, как в эталоне; на телефоне — кнопки ± в панели этапа.
