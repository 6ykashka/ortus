## 1. Цель

С 17.10 (c572252) каждый прогон GitHub CI на `main` красный на unit: `frontend/apps/web/src/routes/home/home.page.test.tsx:158` ждёт «Сегодня 14:00», а раннер в UTC рисует «Сегодня 11:00». Из-за этого integration, isolation, build, шарды e2e и e2e-stand на GitHub не запускаются 5 дней.

Причина: `home.page.tsx` берёт пояс браузера (`Intl.DateTimeFormat().resolvedOptions().timeZone`) и передаёт его во все подписи «Главной». Исправление — явный московский пояс домена (`core/clock` `TZ`), как в `company/branding/vm.ts` и `core/calendar`:

1. `@ortus/domain/home` экспортирует `HOME_TIME_ZONE` (= `TZ` ядра).
2. `home.page.tsx` передаёт `HOME_TIME_ZONE` во все форматтеры: время карточек «Требует решения» (источник `fleet` — «Сегодня 14:00», `tenant` — «До 13.10.2026»), «Рейсы сегодня» и «Сегодня в работе» логистики (выбор рейсов дня), шапка (дата, приветствие по часам), «Последние события» (ЧЧ:ММ).
3. Поиск подобного форматирования в источниках «Главной»: `sources/fleet.ts`, `sources/tenant.ts`, `view.ts` берут пояс параметром (`ctx.timeZone`, `plannedWindow.timeZone ?? timeZone`) — исправление в одном месте, у страницы.
