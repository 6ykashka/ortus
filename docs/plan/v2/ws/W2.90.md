## 10. Риски и решения по умолчанию

- Приёмка менеджером (`reviewTrip`) на стенде — 501 до W2.06: на стенде показываем смену в «Приёмке смен», «Принять смену» — на mock.

- `@stand` пути водителя без сида показа (базовый сид CI, «Логистика» выключена) — пропуск с причиной; включать модуль из e2e нельзя: `access-gate @stand` проверяет базовый сид.
- Фото в mock вручную: PUT по билету `storage.example.invalid` браузер не обслуживает (блокер W2.22, патч адаптера у интегратора) — на mock путь водителя показывается прогоном e2e `--headed`.
- Playwright MCP в сессии не подключён — проходка тем же Playwright скриптом.
