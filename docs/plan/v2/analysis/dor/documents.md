## 0. Как модуль подключается

- `CRM:1830` — `<dc-import name="Документы" db mid open on-opened on-api on-nav on-toast hint-size="100%,640px">`. Пропсы описаны в `Д:755`: `db`, `mid` (текущий участник), `open` (id документа для открытия с «Главной», из уведомления или из чата), `onOpened`, `onApi(m, args, ok)`, `onNav(k, id)`, `onToast`.
- `CRM:2868–2870` — обёртка `dx`: `open: s.docSel`; `onNav('repair', id)` открывает объект на вкладке «График», когда предложение правки касается срока (`Д:1286`); `onNav('tasks', id)` открывает задачу маршрута (`Д:991`); `onNav('kb')` открывает «Базу знаний». Команды идут в `api[m]` с префиксом `doc:`, ошибки `validation/forbidden/conflict/not_found/transition` гасятся тихо, без глобального тоста.
- Без `onApi` модуль поднимает свой mock-адаптер и работает от имени `m-owner` (`Д:785`). Это режим самостоятельного открытия файла.
- Меню (`CRM:2964–3002`): пункт «Документы» (`description`) в группе «Общие модули» у владельца и менеджера, у водителя — в группе «Работа» рядом с «Чатами» и «Базой знаний» (`CRM:3000`), у прораба — в «Общих модулях» (`CRM:3002`). Бейдж — `docWait`: сумма `d.my.wait` по документам (`CRM:2965`).
- «Главная · Требует решения» (`CRM:4085–4088`) показывает шесть видов карточек: «Документ · утвердить», «· согласовать», «· ознакомиться», «Документ на доработке», «Упоминание в документе», «Проверить распознавание». Кнопка «Открыть» ведёт в `go('docs', { docSel })`.
- Модуль `docs` в каталоге прототипа (`ortus/models.js:66`) раскладывает глаголы по ключам: view → `docs.read`, `docs.comment`; create → `docs.create`, `docs.convert`; edit → `docs.update`, `docs.suggest`; review → `docs.sign`; export → `docs.export`; settings → `docs.share`, `docs.templates.manage`, `docs.folders.manage`. Ключа `docs.share_external` в этой раскладке нет.
- Установка `installDocs` (`J:512–524`) делает четыре вещи: добавляет роли папок `r-doc-manage` (уровень 5), `r-doc-edit` (4) и `r-doc-read` (1); дописывает глаголы `docs` в роли `r-manager`, `r-driver`, `r-foreman` и `r-admin`; ставит водителю флаг `docsAddressed`; создаёт системный проект задач `pj-docs` «ДОК · Документы · маршруты» с процессом `approval`.

### 1.4 Текст (`Д:191–205`, `Д:258–302`, `Д:534`; `textVM` `Д:1007–1035`, `blockVM` `Д:1036–1056`)

- **Панель инструментов** (`Д:193–200`), видна только в режимах «Правка» и «Предлагать правки». Стиль абзаца: «Обычный», «Заголовок», «Пункт списка», «Название», «Строка «слева | справа»». Кнопки «Полужирный», «Курсив» (подсказка «выделите текст в абзаце»), «Поле CRM…».
- **Комментарий и поиск** (`Д:201–203`): «Комментарий»; поиск «Найти в документе» со счётчиком «N совп.».
- **Навигация** (`Д:260–273`, ширина ≥ 1100): «Навигация» / «Заголовков пока нет». Блок «Поля CRM · N»: строки «ключ · источник», значение и «+» «Вставить в абзац». - **Лист** (`Д:275–302`). Блоки: текст, таблица, мета. Поверх текста видны:
  - курсоры коллег с именем;
  - предложения (зачёркнуто / подчёркнуто);
  - комментарии — жёлтая подложка и счётчик;
  - найденное.

  Абзац правится в textarea. В режиме предложений есть поле «Пояснение к правке, необязательно». Кнопки «Готово» / «Предложить» и «Отмена». Подсказки:

  - «Каждая строка — строка таблицы, ячейки разделяйте « | »…»;
  - «Правку увидят как предложение…».

  Ниже кнопка «+ Абзац». Тост «Таблицу правят в режиме «Правка»» (`Д:1085`).
- **Сравнение версий** (`Д:1012`, `Д:446`): «Сравнение vN с текущей: красным — было, зелёным — добавлено.», «Выйти из сравнения».

### 3.3 Ограничения функций и полей

- Финансовый документ или папка (`sensitivity: finance` у документа или у любой папки пути) закрыт для функции «Водитель» всегда (`J:96–97`). Шаг цепочки «Функция «Водитель»», в контракте — `function_blocked`.
- Финансовый лист таблицы (`sheet.fin`) видят: владелец бизнеса, роли с `finance.read` из блока финансов роли и список `finWho` (`J:138–141`). Остальным сервер отдаёт лист без ячеек (`J:535`). Это `field-policy` («финансы» роли): что даёт `finance.read`, решает Q-15.
- Временные доступы маршрута (`d.tmp`):
  - согласующий без доступа получает «Комментирует» на время шага (`J:587`);
  - ознакомляемый получает «Читает» только утверждённой версии (`onlyV`), доступ сохраняется (`keep`, `J:590`). Сервер такому участнику отдаёт одну версию без комментариев, предложений, журнала и списка доступа (`J:536`).
- Приглашённый (`invited`) видит доступ «после входа» (шаг цепочки `wait`). Заблокированный — «доступ не действует».
