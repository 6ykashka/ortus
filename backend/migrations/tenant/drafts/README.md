# Черновики миграций tenant DB

Здесь лежат заготовки миграций будущих шагов без номера (план v2 §3.5). Файлы этого каталога не встраиваются (`//go:embed tenant/*.sql` не захватывает подкаталоги) и не применяются ни `cmd/migrate`, ни тестами.

Номер выдаёт стюард контракта при открытии контрактного PR шага из блока этапа: tenant — этап 1: 0003–0009, этап 2: 0010–0019, этап 4: 0020–0039, этап 5: 0040–0049, этап 6: 0050–0059, этап 7: 0060–0069; control — 0004+ по тому же принципу. Файл переносится в `tenant/` с номером в том же PR.
