## 7. Решения по умолчанию (вопросы — в отчёт)

1. «По персональному приглашению» — неактивен с подсказкой «Появится позже: персональные приглашения со сроком» (Q-W4.00-forms-10).
2. Ссылки «Поделиться» — `{origin}/forms/{id}`, `{origin}/f/{token}`, iframe `?embed=1` (Q-W4.00-forms-21).
3. Проверка ответа — «Принять» / «Отклонить» в карточке ленты по `FormResponse.my.review` (Q-W4.00-forms-18, no-reference).
4. Действие «задача» — поле «Проект» (контракт требует `projectId`; в эталоне нет) — no-reference.
5. Письмо и HTTP — пояснения «На показе письма не отправляются.» / «На показе запрос не выполняется. В продукте — подписанный вебхук с повтором.» (Q-W4.00-forms-15).
6. Блокировка всех команд вкладки до ответа (Q-72, PD-27).
