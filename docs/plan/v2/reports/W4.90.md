## Осталось fixme / открытые вопросы

- Q-W4.90-1: контракт PublicForms (`Origin`: «Required and checked against the deployment allowlist for … browser public-form submissions/uploads») — сервер у публичных команд `Origin` не проверяет (шлюз пропускает `security: []`, модуль форм заголовок не читает). - Q-W4.90-2: `createCalendarBooking` — строки до хендлера с `pending: W5.20` (первые брони — SPA этапа 5, «запись на несколько ресурсов»); снять pending и добавить положительную строку — W5.20.
- Q-W4.90-3: ключ ответа осмотра `рейс:dep:rev1` (Q-59) — повторный осмотр перед выездом того же рейса после «разрешить выезд» и снятой брони второго ответа и задачи ответа не пишет, блокирующий дефект получает свою задачу W4.11 «Проверить дефект: …». Это поведение W4.24 «как в прототипе»; сквозной spec берёт рейс, выезд которого ещё не записан (`freshTrip`), иначе проходит смену такого рейса через API до приёмки.
