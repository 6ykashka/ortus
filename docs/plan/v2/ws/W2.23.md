## 1. Цель

После W2.23 логист (Котова, «Менеджер логистики» «Москва / Север Логистик», пресет `logistics-ready`) и владелец:

1. Открывают **«Ресурсный пул»** из меню (группа «Логистика», на телефоне — нижняя навигация «Пул») и по URL `/t/:tenantId/pool` (`?trip=` — рейс запроса, ADR-0001). Экран — как `pg.pool`: крошка «Москва / межфирменный ресурсный пул», заголовок, пояснение; колонка карточек водителей и `aside` «Что скрыто в пуле».
2. **Рейс запроса**: `?trip=`, иначе первый по началу окна рейс без водителя в `planned | assigned`, иначе рейс с одобренным исходящим запросом (эталон — всегда Р-211). Каталог `listAvailableDrivers` — на окно этого рейса.
3. **Карточка водителя**: псевдоним, «{квалификации} · {фирма}», чип, «Свободен» → окно, «Условия» → условия; карточки каталога сливаются с исходящими запросами (`listDriverTransfers` `direction=outgoing`, `status=requested,approved,rejected`) по `publicationId`; чип задаёт открытый (`requested`) запрос публикации на любой рейс — он у публикации один (`driver_transfers_open_uq`, второй — 409 «Запрос уже отправлен»), поэтому блокирует «Запросить» и на других рейсах (возврат 2); иначе — последний запрос на выбранный рейс (или без рейса): одобрение или отказ на другом рейсе не мешают (Q-W2.23-1): «Запрос отправлен» / «Временно назначен» / «Отклонён» / «Свободен»; `role=status` «Ожидает решения менеджера фирмы {фирма}. Доступа к водителю пока нет.», «{водитель} назначен на рейс {рейс} до {срок}. Доступ ограничен этим рейсом; …», «Запрос отклонён. Можно запросить другого водителя.». Одобренный водитель уходит из каталога — карточка строится по запросу.
4. «Запросить на рейс {рейс}» — при свободном или отклонённом водителе, если у рейса нет водителя и одобренного запроса, есть право `fleet.driver_transfers.request` на фирму рейса и организация не только для чтения.
5. **Диалог `modal-driver-request`** «Запросить водителя»: «{псевдоним} · {фирма}»; «Рейс» → «{номер} · {название} · {окно}»; «Срок» → пересечение окна рейса и свободного окна (Q-W2.51-10): «Временно, до 18:00 01.10» (с началом, если оно позже начала рейса); «Согласует» → «Менеджер фирмы {фирма}»; «Комментарий для фирмы-владельца» (необязательно; пусто — `reason` «Запрос на рейс {номер}», Q-W2.00-3); пояснение; «Отмена» / «Отправить запрос» (на время отправки недоступна только «Отправить запрос», как в эталоне :2296; «Отмена» закрывает диалог, ответ отменённой отправки не трогает следующий диалог — возврат 2) → `requestDriverTransfer` (`publicationId` карточки, `tripId`, `window`, `Idempotency-Key`), тост «Запрос отправлен фирме {фирма}» (без «· уведомления в демо не отправляются», PD-54). `Idempotency-Key`: то же тело — тот же ключ до окончательного ответа (повтор после «нет связи», 5xx, 429, повторяемых 409); после 2xx и окончательной 4xx — новый: повторный запрос того же водителя на тот же рейс после «Отклонить» создаёт новый запрос (возврат 1). 409 «Запрос уже отправлен», 422 (`window`, `tripId`) и 404 — сообщение в диалоге текстом сервера, список перечитывается.
6. **Входящие запросы** (no-reference, Q-W2.51-2): участнику с `fleet.driver_transfers.approve` — блок над карточками, если есть `requested` к его фирмам (`direction=incoming`): псевдоним, «{фирма-получатель} · рейс {номер}», срок, комментарий запроса, «Комментарий к решению», «Одобрить» / «Отклонить» → `decideDriverTransfer` (`If-Match` свежего `getDriverTransfer`, `Idempotency-Key`); 409 одобрения («У рейса уже есть водитель.», «Рейс уже начат или закрыт.», «Водитель уже назначен в это время.») — тост текстом сервера и перечитывание. Ошибка загрузки входящих — текст в блоке и «Повторить» (возврат 1).
7. Состояния: загрузка (скелетон), ошибка и «Повторить», пусто («В пуле нет свободных водителей на это время», «Нет рейсов без водителя»), нет связи (тост `run`), только чтение (команды недоступны), гейт водителю, раскладка 390 / 1440.

## 5. Решения по умолчанию (вопросы — в отчёт)

1. Рейс запроса — `?trip=` или первый без водителя (эталон фиксирует Р-211).
2. Срок — пересечение окна рейса и свободного окна (Q-W2.51-10); шаблон с началом — no-reference.
3. Тост без «· уведомления в демо не отправляются» (PD-54); демо-кнопки «Одобрить» / «Отклонить» заменены блоком входящих (Q-W2.51-2).
4. Экрана публикации нет (Q-W2.51-2): на стенде водителя публикует владелец через API (Q-W2.07-5).
5. Карточка водителя с открытым или одобренным запросом, которого нет в каталоге (одобренный уходит из каталога), — по запросу: подзаголовок — фирма-источник (квалификаций в `DriverTransfer` нет), строка «Срок» (срок запроса) вместо «Свободен» и «Условия».
