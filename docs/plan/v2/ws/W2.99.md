# W2.99 · Название поставленной машины до окна (Q-W2.75-1, Q-W2.92-2)

Этап 2 · вид backend · слот 3 (Vite 5203, API `127.0.0.1:8103`, эталон 4103, compose `ortus-s3`). Вне реестра §4: постановка интегратора. Решение владельца D-35 (`design/docs/29-temporary-driver-vehicle.md`, макеты 1a–1g), DoR `docs/plan/v2/analysis/dor/s2-20-temporary-driver-vehicle.md`.

## 1. Дефект

После «Поставить машину» (1g) до окна брони водителю `confirmed`, `offerGroupId` и `offerKind: host` заполнены, но `listVehicles` до начала окна отвечает 403 `forbidden_action`: `pool.openVehicle` открывает строку доступа к машине рейса (область resource) с начала окна. Экран водителя показывает «Машина на сегодня» с названием «—». Фронт W2.92 (403 без предложения и при одной поставленной машине — не ошибка) перенесён в ветку без изменений.

## 2. Решение по умолчанию (без людей)

`pool.openVehicle` открывает строку машины рейса с момента назначения или одобрения (`min(now, начало окна)`), если перевод готовит рейс (`transfer.prepare`: запрос с машиной или бронь рейса, предложенная водителю), как строки предложенных машин при согласовании (`openOfferGrant`). Конец строки прежний (конец окна). Перевод без подготовки (запрос 0.6.2 без машины) — строка с начала окна, как раньше: до окна машина закрыта. Видна только машина своего рейса: область resource на одну машину, чужие машины фирмы — 404/403.

## 4. Тесты

1. red: integration `pool` — строка машины рейса перевода с подготовкой начинается в момент одобрения, до окна машина читается (`fleet.vehicles.read`), чужая — нет; перевод без подготовки — с начала окна (прежнее поведение, `TestVehicleGrantFollowsTheTrip`).
2. red: isolation `listVehicles` — временный водитель до окна видит поставленную машину своего рейса, не видит запасную и машины других рейсов.
3. green: правка `settle.go`.
4. e2e: строка Q-W2.75-1 (`@stand`) проверяет название машины на «Моей смене» после «Поставить машину».
