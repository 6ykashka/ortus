## 1. Цель

Контракт, миграции tenant и MSW (без бизнес-логики backend) для работ после показа:

1. **W2.41 — справочник категорий расходов (D-12).** `fleet.expense_categories` с посевом шести кодов `fuel`, `wash`, `parking`, `toll`, `tire_service`, `other` и признаком «комментарий обязателен» (у `other` — всегда). Операции владельца: список, создание, архивация. `TripExpense.kind` и `TripExpenseCreate.kind` — строка-код справочника вместо перечисления; шесть кодов посева остаются валидными (обратная совместимость); подпись категории — из `listExpenseCategories?includeArchived=true` (поля `kindLabel` нет, Q-W2.52-4).
2. **W2.42 — `fleet.vehicle_assignments` (`valid_from`/`valid_to`).** История принадлежности машины фирме: миграция с переносом текущей фирмы каждой машины, `Vehicle.orgUnitSince`, чтение истории и команда перемещения машины.
3. **W2.43 — антифрод фото.** Предупреждение о повторе файла по sha256 (`duplicateWarning` у `File` и у фото осмотра) и время приёма фото сервером (`InspectionPhoto.serverCapturedAt`; у `File` поля нет — момент `completeUpload` есть только у фото осмотра, Q-W2.52-7); индекс поиска повторов, фото осмотра хранят серверное время и предупреждение на момент отправки.
4. **W2.45 — `fleet.checklist_versions.definition` в формате `FormDefinition`.** Колонка, перенос существующих версий (миграция данных), заполнение при вставке без `definition`; `InspectionChecklist.definition`; `FormField.blockingValues` для правила «неисправность блокирует выезд».
5. **W2.46 — поля задачи у `fleet.defects` в `in_review`:** исполнитель, срок (решение — `decision` 0.5.0); команда назначения.
6. **W2.50 — заменители интеграций (D-11):** импорт CSV машин (предпросмотр, применение), выгрузка CSV расходов и рейсов (`exportDataset`, `data.export` + право набора), deeplink навигатора по адресу остановки (`TripStop.navigationAddress`; ссылку по шаблону Яндекс Карт строит клиент, поля `navigationUrl` нет — Q-W2.52-12; без внешнего API).
