## Вопросы (decisionsNeeded)

1. Q-W1.44-1 (технический). Содержимое тенантов грузится только с `fixtures.WithContent()` (набор изоляции). Integration-тесты модулей (`files`, `notify/inbox`, `importer`) грузят каталог без него, потому что сеют свои объекты и проверяют точные списки и счётчики. По умолчанию — опция. Альтернатива — грузить всегда и перевести эти тесты на проверки «содержит / не содержит».
2. Q-W1.44-2 (технический). Строка «a.manager-msk2 → 404» требует `members.manage`, иначе шлюз отвечает 403. По умолчанию `a.manager-msk2` получил вторую роль «Кадры» (`members.read`, `members.manage`) на Москва-2. Актором в YAML он раньше не был, integration-тесты на фикстурах зелёные. Альтернатива — отдельный актор-кадровик.
3. Q-W1.44-3 (технический). Канал `notifications` раннера не добавлен: перепроверку при выдаче выражают http-строки `listMyNotifications`. Проверке адресата при постановке в очередь нужны worker и outbox в цели набора. По умолчанию канал добавляется вместе с подключением `inbox.Consumer` (W1.42).
4. Q-W1.44-4 (технический). Цели набора дан фиктивный `S3_ENDPOINT=http://127.0.0.1:9`, чтобы `getFileDownload` отвечал 200: подпись локальная, в сеть запрос не уходит. Если строка набора дойдёт до операции, которая обращается к хранилищу (`completeUpload`), она получит 503, а не зависание. Сейчас таких строк нет.
