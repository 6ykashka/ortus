# Allowlist `form-fill` (W4.70)

Страницы заполнения формы сотрудником `{origin}/forms/{id}` в эталоне нет (`design-2026-10-19`, разбор
`docs/plan/v2/analysis/dor/forms.md` §6; решение Q-W4.00-forms-19). Рендер формы — общий `FormRender` вкладки
«Предпросмотр» («Формы и опросы.dc.html» dc:114–142) без панели предпросмотра; его сверяет ключ `forms`. Пиксельной и
структурной сверки страницы нет — e2e `e2e/form-fill.spec.ts` и проходка MCP (`docs/plan/evidence/form-fill/`, снимок
«Предпросмотра» эталона рядом).
