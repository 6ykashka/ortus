# W2.78 · Отметка «машина отпущена»: обычная машина временного водителя свободна до приёмки (Q-W2.72-1)

Вид: backend · этап 2 · шаг S2-20 (D-35, правило 6) · вне реестра §4 — постановка задачи оркестратора от 22.10 · слот 5 (API 8105, compose `ortus-s5`); возобновлён 22.10 на слоте 2 (API 8102, compose `ortus-s2`).

## 1. Цель

Закрыть Q-W2.72-1. Частичный уникальный индекс `trips_active_vehicle_uq` (tenant 0002) держит обычную машину временного водителя за рейсом в `returning`/`submitted`/`rework` до приёмки смены: другой рейс её фирмы не переходит в `inspection` по ней. По умолчанию Q-W2.70-9 машина освобождается, когда отправлен осмотр сдачи без блокирующего дефекта (при блокирующем дефекте выезда — когда её фирма решила дефект: «Подтвердить неисправность» снимает машину с рейса, `planned`, `vehicle_id = null`, — это W2.72 уже делает). Нужна отметка рейса «машина отпущена» и условие индекса, которое её учитывает. Машина фирмы рейса и машина другой фирмы без одобренного перевода держатся до приёмки, как раньше (Q-W2.72-13, AC-05, S2-10).

OpenAPI не меняется (отметка — внутреннее поле БД, в DTO не выходит). Миграция tenant 0027:

- `fleet.trips.vehicle_released_at timestamptz` — момент, когда машина рейса отпущена до приёмки; `check (vehicle_released_at is null or vehicle_id is not null)`;

## 10. Риски и решения по умолчанию

- Номер 0027 — по умолчанию следующий свободный; стюард подтверждает или перенумеровывает (goose без out-of-order: 0019 нельзя — ниже применённых 0020+).
- Повторный осмотр сдачи в `rework` после освобождения: машина могла уйти в другой рейс; осмотр по-прежнему принимается (как W2.72), отметка не сбрасывается.
- Исключения W2.72 в `fleet/vehicles`, `fleet/routes`, `fleet/pool` (`busySQL`) считают машину свободной по тому же условию (осмотр сдачи + одобренная обычная машина) — равносильно отметке; перевести их на `vehicle_released_at` может владелец каталогов отдельной правкой.
