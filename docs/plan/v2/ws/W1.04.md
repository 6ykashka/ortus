## 1. Цель

1. **Оценщик `permit()`** (`design/docs/v0.1/02-architecture.md` §5): для контекста, действия, ресурса и времени решение даёт **каждый grant целиком** — действие ∈ роль версии назначения, область покрывает ресурс, параметры гранта (`limit: amount`) допускают ресурс, назначение действует в момент `t`. «Изменять Москва-1» + «читать Самара-2» не дают «изменять Самара-2». Отказ:
   - `function_blocked` (403) — действие закрыто функцией субъекта (`blocked_by_function: [driver]`, AUTH-05, AC-05);
   - `forbidden_action` (403) — нет объекта, или объект виден субъекту (есть право чтения объекта), но действия на нём нет; `owner_only` для не-владельца; правило действия («не автор») не выполнено;
   - `not_found` (404) — объект не виден: «одинаково для чужих и несуществующих ID» (AC-01, `errors.yaml`).
2. **Допуск операции на шлюзе** по `x-permissions` + `x-permissions-mode` + `x-scope`: вид области гранта засчитывается, только если `x-scope` операции его допускает. Таблица `x-scope → виды` покрывает все значения каталога (тест). Шлюз `cmd/api` вызывает оценщик вместо `GrantAuthorizer` W0.09.
3. **`scopeQuery()`**: SQL-предикат из целых разрешающих грантов действия (OR по грантам), до пагинации и агрегации; владелец — `true`, действие закрыто функцией — `false`.
4. **Реестр видов областей** (ADR-0014, вариант 2): явный реестр без `init()`. Вид — ключ каталога, вид `Scope.kind` контракта, «объектный» ли (PD-53), `Covers` и `Predicate`. Виды этапа 1: `tenant`, `unit` (поддерево через `org.unit_closure`), `self`, `project`, `warehouse`, `resource`. Новые виды (`space`, `page`, `account`, `chat`, …) добавляют W4.01, W5.00, W6.00, W7.00 — без правки ядра.
5. **PD-53**: грант объектного вида (проект, склад, ресурс; позже пространство, чат, касса, объект ремонта) засчитывается только при объекте того же вида и id. На шлюзе — только если `x-scope` операции допускает этот вид (объект проверяет хендлер).
6. **Хуки — интерфейсы сразу, реализации для областей пилота:** `ObjectACL` (список доступа объекта; по умолчанию «наследуется»), `GrantParam` (реализация `limit: amount`), `Rule` (реализация `not_author`), `owner_only` (OwnerBinding), `blocked_by_function` (функция `driver`).
7. **Возможности `/me/context`** из оценщика: владелец — действия подключённых модулей; участник — действия действующих грантов с их областью, без закрытых функцией и `owner_only`. **Паритетный тест mock ↔ stand** (критика этапа 0, П-14: у владельца «Альты» 59 против 114) для owner, manager, driver: возможности стенда = пример `getMyContext/<persona>.json`, который отдаёт MSW.
8. **`scopeddb`** — доступ модулей к строкам tenant DB только через предикат области: запрос без `{{scope}}` отклоняется, «чужой» и «несуществующий» идут одним запросом (AC-01).
9. **Часы приложения**: `env.Clock` набора изоляции доходит до `cmd/api` (`APP_FIXED_NOW`, только вне `prod`); периоды назначений и функций сверяются с часами приложения, а не с `now()` tenant DB (Q-W0.09-11).
10. **Фикстуры изоляции** (владелец с шага 1.4): «Москва, Самара, Петербург × 4 фирмы» в A, в B — тёзки Москва и Самара-2 (Q-W0.15-2); руководитель проекта (PD-53), администратор с `owner_only` в роли, оператор платформы (Q-W1.02-7, W1.02), ссылка `tenant:missing` (Q-W1.02-7). AC-10: отзыв роли между началом экспорта и выдачей файла → 403.

### 4.2 Публикует (`backend/internal/platform/authz`)

```go
type Scope struct{ Kind string; Ref uuid.UUID; Descendants bool }
type Grant struct{ AssignmentID, RoleID, Group uuid.UUID; Actions []string; Scope Scope; From time.Time; Until *time.Time; Limit *Amount }
type Subject struct{ TenantID, PersonID uuid.UUID; Owner bool; Functions []string; Grants []Grant }
type Resource struct{ Unit uuid.UUID; UnitPath []uuid.UUID; Objects map[string]uuid.UUID; Persons []uuid.UUID; Author uuid.UUID; Amount *Amount; ReadAction string }
type Columns struct{ Unit string; Objects map[string]string; Persons []string }
type Predicate struct{ SQL string; Args []any }
type Operation struct{ ID string; Permissions []string; Mode, Scope string }

type ScopeKind interface { Key() string; APIKind() string; ObjectBound() bool
    Covers(ctx, Scope, Subject, Resource) (bool, error); Predicate(Scope, Subject, Columns, *Args) string }
type ObjectACL interface { Admit(ctx, Subject, action string, Resource) (Admission, error) } // Inherited | Admitted | Denied
type GrantParam interface { Key() string; Admits(Grant, Resource) bool }               // LimitAmount
type Rule interface { Key() string; Allows(Subject, Resource) bool }                   // NotAuthor
type Source interface { Subject(ctx, tenantctx.TenantContext, at time.Time, withGrants bool) (Subject, error)
    InstalledModules(ctx, tenantctx.TenantContext) ([]string, error) }
type UnitTree interface { Ancestors(ctx, tenantID, unit uuid.UUID) ([]uuid.UUID, error) }

func NewRegistry(kinds ...ScopeKind) (*Registry, error); func PilotKinds() []ScopeKind // unit: Resource.UnitPath из UnitTree
func (e *Evaluator) Permit(ctx, tc, action string, r Resource) error
func (e *Evaluator) Admit(ctx, tc, op Operation) error                       // шлюз
func (e *Evaluator) ScopeQuery(ctx, tc, action string, c Columns, argStart int) (Predicate, error)
func (e *Evaluator) Capabilities(ctx, tc) ([]tenantctx.Grant, error)         // /me/context
func (g Gateway) Permit(ctx, tc, perms []string, mode string) error          // tenantctx.Authorizer
func (g Gateway) Admit(ctx, tc, op Operation) error
func New(src Source, units UnitTree, now func() time.Time) *Evaluator; func DefaultPolicy() Policy; func Installed(keys []string) map[string]bool
func (e *Evaluator) Explain(ctx, tc, action string, r Resource) (Explanation, error) // причины GrantExplanation.mismatch для W1.06
type PGSource struct{ Pools Pools } // Source и UnitTree поверх tenantctx.Pools
```

Фикстуры: новые ссылки `unit:a.{msk3,msk4,smr1,smr3,smr4,spb,spb1…spb4}`, `unit:b.{smr,smr2}`, `project:<t>.<key>`, акторы `a.project-lead`, `a.admin`, `p.operator`, `tenant:missing`; формат ссылок W0.15 не меняется.
