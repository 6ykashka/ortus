## 10. Риски и решения по умолчанию

- «Ответы на осмотр» — ответы формы «Осмотр машины» (по имени, как `RecordInspection` W4.24); видимость — как `listFormResponses` (область формы, свои, объект-рейс или машина, которые участник видит; рейс, которого нет, — с `fleet.trips.read`); ответы об объекте-задаче — только по области формы (fail-closed).
- `recordId` ответа — `{formId}:{responseId}` (ответ адресуется внутри формы), `entityType` `form_response`.
- «Срок» — дата (день по Москве), ячейка `ДД.ММ.ГГГГ`, как «Дата» «Расходов» (в эталоне — `ДД.ММ` строки сида).
- Порядок строк без сортировки — порядок сервера (задачи — ключ проекта и номер, ответы — номер).
- Модули ядра (`tasks`, `forms`) не устанавливаются — их наборы открыты всегда.
