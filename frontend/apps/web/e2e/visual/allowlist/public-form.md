# Allowlist `public-form` (W4.70)

Публичной формы гостя `{origin}/f/{token}` и встраивания `?embed=1` в эталоне нет (`design-2026-10-19`, разбор
`docs/plan/v2/analysis/dor/forms.md` §6; решение Q-W4.00-forms-19). Рендер формы — общий `FormRender` вкладки
«Предпросмотр» («Формы и опросы.dc.html» dc:114–142) без панели предпросмотра; его сверяет ключ `forms`. Пиксельной и
структурной сверки страницы нет — e2e `e2e/public-form.spec.ts` и проходка MCP (`docs/plan/evidence/public-form/`,
снимок «Предпросмотра» эталона рядом).
