  - `backend/internal/api/catalog/{operations,problems,permissions}.gen.go`: 118 операций (`x-permissions`, `x-permissions-mode`, `x-scope`, публичная, изменяющая), 52 кода `errors.yaml` (статус, title), tenant actions каталога прав (всё, кроме модуля `platform`);

- **`backend/internal/platform/`**:
  - `requestid` — эхо `^[A-Za-z0-9._:-]{1,128}$`, иначе UUID v4;
  - `problem` — единственное место маппинга ошибок в `application/problem+json` по `catalog.Problems`; поля схемы `Problem` в её порядке, завершающий `\n`; непредвиденная ошибка → 503 `dependency_unavailable` «Внутренняя ошибка» без текста;
  - `httpx` — `SecurityHeaders` (`Cache-Control: private, no-store`, `nosniff`), `Recover`, `Logging` (slog JSON: `request_id`, метод, путь, статус, `actor_id`, `tenant_id`, `operation`; без заголовков, cookie и тел), `DecodeStrict`, `JSON`;
  - `session` — `Manager` (`Issue`, `Authenticate`, `CheckOrigin`, `CheckCSRF`, `Clear`), хранилище в памяти; `ortus_sid` HttpOnly SameSite=Lax Path=/ (+`Secure` за TLS), `ortus_csrf` double-submit;
