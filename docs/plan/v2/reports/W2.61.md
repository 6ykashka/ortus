## Сделано

Причина дефекта. `TodayPage` ждал `listVehicles` при любом рейсе и при его ошибке вместо смены показывал баннер «Не удалось загрузить машины: …». У временного водителя в продолжении после срока (D09, W2.57) строка роли «Временный водитель» в области `resource` на машину рейса закрыта вместе с окном. Поэтому `listVehicles` отвечает 403 `forbidden_action`, хотя права продолжения (`finishTripRoute`, осмотр сдачи, `returnTrip`, загрузки файлов рейса, `getInspectionChecklist`) у него есть.

Исправление — только в странице (`frontend/apps/web/src/routes/logistics/driver/`):

- `model.ts`:
  - `needsCars(state)` — список машин нужен только до выезда: `planned`, `assigned` (выбор машины), `inspection` (строка брони, пробег машины);
  - `inspectionSub(kind, model, plate)` — подзаголовок осмотра без пустых «модель · номер», если машина неизвестна: «Сравнение с выездом».
- `today.page.tsx`:
  - начатый рейс (и `defect_review`) не ждёт `listVehicles` и не показывает его ошибку;
  - машина и рейс берутся из рейса: `vehicleId` — для чек-листа, осмотра и команд; пробег выезда — из осмотра выезда;
  - название машины для подзаголовка берётся из списка, если он загружен (данные запроса сохраняются и после сбоя перечитывания);
  - до выезда ошибка списка — как раньше: «Не удалось загрузить машины: …» и «Повторить».
- `inspection.tsx` — подзаголовок через `inspectionSub`.
- Backend (надстройка пула) не менялся, решение по умолчанию — §«Открытые вопросы», Q-W2.61-1.

## Осталось fixme / открытые вопросы

`test.fixme` в моих файлах нет. Строка `@known-defect` Q-W2.32-2 снята (теперь `@stand`).

Вопросы (значения по умолчанию — как сделано; в `decisions.md` вносит интегратор):

- **Q-W2.61-1 · машина рейса в продолжении временного водителя (продукт / W2.72).**
  - Как сейчас: в продолжении после срока (D09) сервер не отдаёт машину рейса. Строка роли в области `resource` закрыта с окном — так в W2.57 и в примечании `permissions.yaml` `temporary_driver`. `listVehicles` — 403 (`CARS_NARROW` журни W2.32).
  - По умолчанию сервер не меняется. Экран сдачи от списка не зависит. Название и номер машины в подзаголовке осмотра при сдаче есть, только если список загружался в этой вкладке до срока. После перезагрузки — «Сравнение с выездом». Команды берут `vehicleId` рейса.
  - Альтернатива: продлить строку `resource` машины рейса на продолжение, до приёмки. Тогда в продолжении `listVehicles` — 200 ровно с машиной рейса, а подзаголовок — как в эталоне. Нужна правка надстройки пула (`settle`/`Settle` `VehicleUntil`), примечания `permissions.yaml` (стюард) и ожидания журни `CARS_NARROW` → `[200, …]`. Пересекается с W2.72, который меняет строки `resource` пула под S2-20.
- **Q-W2.61-2 · «Автомобили» временного водителя в продолжении (W2.74).** Экран `driver-cars` в продолжении по-прежнему показывает «Не удалось загрузить машины: Нет права…»: список машин ему не отдаётся. По S2-20 «Автомобили» временного водителя — только предложенные машины, это делает W2.74. W2.61 этот экран не трогал, чтобы не мешать W2.74.
