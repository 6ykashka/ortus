## Сделано

- **`backend/internal/control/tenants/operators`** — новый пакет (каркас сервиса перенесён из `ws/W1.11`: транзакция, `SELECT … FOR UPDATE`, ревизия, `audit.RecordPlatform`, запись `denied`, правила ролей):
  - `rules.go` — проверки команд (причина 5–500 после trim, дни 1–30, имя 1–150), `ParseETag` (`"N"` и `"rev-N"`; пусто — `ErrRevisionRequired`, иное — `ErrRevisionMismatch`), `TenantETag`/`SubscriptionETag`, `Allowed` (роли `owner/admin/billing/support` по `design/docs/17` «Права», «Роли»), `SuspendTo`, `ResumeTo` (по `subscriptions.TenantStateFor`), `CanExtendTrial` (trialing, или grace/read_only с правами источника `trial`; оплаченная и вне жизненного цикла — 409), `NextTrialEnd` (от позднейшего из срока и «сейчас» только у trialing), белый список `details` журнала, курсор журнала, привязанный к оператору и фильтру, `VisibleTargets`.
  - `service.go` — `Service{Control, Now}` на роли `ortus_api`. Порядок проверок: 422 → 428 → оператор (404) → роль (403 + `denied`) → организация под замком (404) → 412 → 409. `Suspend` (материализует производную подписку организации без строки — Q-W1.08-13), `Resume` (по подписке; без строки — `details.fromStatus` последней `tenant.suspended`, иначе `active`), `Rename` (то же имя — без изменений и аудита), `ExtendTrial` (подписка → trialing, права trial выводятся заново, ручные сохраняются, ревизия подписки + 1; организация, следующая подписке, → `trial`; `suspended` остаётся). Действия аудита: `tenant.suspended`, `tenant.resumed`, `tenant.renamed` (цель `tenant`), `subscription.trial_extended` (цель `subscription`, `target_id` — организация; `details` `days`, `trialEndsAt`, `fromStatus`, `toStatus`).
  - `subscription.go` — чтение и запись подписки в хранении W1.08 внутри транзакции команды (одна строка `subscriptions`, права версиями, ревизия = `max(entitlements.version)`): у `store.go` W1.08 запись не экспортирована.
  - `journal.go` — `AuditEvents`: `platform_audit` новые сверху, фильтр типов целей по роли до пагинации, фильтр организации (её `tenant`- и `subscription`-строки), имена актора и цели (текущие), `details` — только скаляры из белого списка.
  - `keys.go` — `Keys`: `idem.Store` над control 0005 `idempotency_keys` (пространство тенант + actor + операция, `uuid.Nil` → null, `nulls not distinct`), захват, повтор, освобождение, протухшие ключи.
  - `server.go` — `Server{*platformhttp.Server; Commands}`: `SuspendPlatformTenant`, `ResumePlatformTenant`, `ExtendPlatformTrial`, `ListPlatformAuditEvents`, `UpdatePlatformTenant` (только переименование; `status` в теле — 422). Ответы: `Tenant` + `ETag "N"`, `Subscription` + `ETag "rev-N"`, `Idempotency-Replayed: false`, `Cache-Control: private, no-store`, `X-Request-Id`.

`fixme`, `t.Skip` нет. Решения по умолчанию, по которым сделано (в `decisions.md` не вносились — файл интегратора; продублированы в `decisionsNeeded`):

1. **Путь пакета** — `backend/internal/control/tenants/operators` по постановке W1.48; в карточке W1.11 плана v2 «Владеет» — `control/operators/`.
2. **Возобновление без строки подписки** (организация приостановлена до W1.48) — состояние из `details.fromStatus` последней `tenant.suspended`, иначе `active`. Своя приостановка материализует подписку (Q-W1.08-13), поэтому для новых приостановок вопрос закрыт.
3. **Возобновление в trial с истёкшим сроком**, если фоновый цикл W1.08 ещё не прошёл (в dev `SUBSCRIPTION_SWEEP_INTERVAL` не задан): организация уходит в `trial`, ближайший цикл переводит её в `grace`.
4. **Продление из производной grace/read_only** (строки подписки нет): `subscriptions.Derive` даёт права источника `plan` — считается оплаченной, 409. Линия trial определяется по источникам неручных прав (`trial`).
5. **`updatePlatformTenant` со `status`** — 422 `validation_failed` (поле `status`): приостановка и возобновление — свои операции. Описание операции в контракте («Rename, suspend or resume a tenant») и `TenantPatch.status` остались от 0.1 — правка описания за стюардом.
6. **ETag**: организация — `"N"` (как `getPlatformTenant` W1.02), подписка — `"rev-N"` (как W1.08); `If-Match` принимает обе формы. MSW везде `"rev-N"` — Q-W1.08-9 остаётся у стюарда.
7. **Идемпотентность**: `operators.Keys` хранит ключи всех identity- и platform-операций (через `idem.TenantStores.Platform`); у операций `/platform/…` `tenant_id` = null по комментарию control 0005, организация входит в `request_hash` через путь. Ответ сохраняется после коммита команды, не в её транзакции: при падении процесса между ними повтор выполнит команду снова и получит 412 по `If-Match`.
8. **Журнал**: `target.name` — текущее имя организации, имя на момент действия не хранится; `details` — белый список `days`, `trialEndsAt`, `periodEndsAt`, `graceEndsAt`, `quotaBytes`, `fromStatus`, `toStatus`, `planKey`, `at`, `permission` (у `tenant.create` скрыты `ownerEmail`, `requestHash`, у отказов провиженера — тексты ошибок); строки целей вне перечисления контракта не показываются; `tenant.renamed` хранит `from`/`to`, но в ответ они не попадают.
9. **Роли**: чтение журнала — все роли; `platform.tenants.manage` — `owner`, `admin`; `platform.billing.manage` — `owner`, `admin`, `billing`. В прототипе роли не ограничивают действий (демо-оператор — владелец) — отличие для W1.25.
10. **`state_reason`** при продлении, которое меняет состояние организации, = причина продления.
