## 1. Цель

Ответ владельца 17.10 по D-29: «fleet.defects в статусе in_review хранит те же поля, что задача (исполнитель, срок, решение), чтобы на 4.1 стать ссылкой на задачу». Колонки и контракт — W2.52; здесь:

1. **Команда `assignInspectionDefect`** (модуль `fleet/inspections`): менеджер с `fleet.inspections.review` над фирмой машины (или владелец) назначает исполнителя и срок решения дефекта `in_review`. Порядок ответов — как у `decideInspectionDefect`: невидимый дефект — 404, видимый без права — 403, не `in_review` — 409 `invalid_transition` «Дефект уже решён.» (до If-Match), If-Match — 428/412; исполнитель — живой профиль с активным членством и `fleet.inspections.review` над фирмой машины, иначе один и тот же 422 «Сотрудник не найден.»; срок в прошлом — 422 «Срок решения уже прошёл.»; комментарий > 2000 — 422. Переназначение заменяет оба поля, `revision + 1`, аудит `fleet.defect.assign`, событие `fleet.defect.assigned.v1`, входящее `fleet.defect.assigned` исполнителю (себе не шлётся; право `fleet.inspections.review` на фирму машины — перепроверяется при чтении).
2. **Чтение**: `listInspectionDefects`, `getInspectionDefect`, дефекты в `getInspection`/`listInspections`, ответ `decideInspectionDefect` отдают `assigneeMemberId`, `assigneeDisplayName`, `dueAt`, `assignedByMemberId`, `assignedAt`.
3. **Решение** — по-прежнему `decideInspectionDefect`; поля задачи после решения остаются (история для шага 4.1).
4. **Страница очереди** (`routes/logistics/manager/defects/`, минимальная правка): на карточке — «Исполнитель: {имя} · срок {дата} в {время}» (или «Исполнитель не назначен»), на вкладке «На проверке» — выбор исполнителя, срок и «Назначить».

## 10. Риски и решения по умолчанию

- `DefectAssignment.comment` колонки не имеет (0017): уходит текстом уведомления исполнителю (`body`) и признаком в аудите; при назначении себе не сохраняется.
- Исполнитель — тот, у кого есть `fleet.inspections.review` над фирмой машины сейчас (живой профиль, активное членство); владелец организации проходит.
- Срок — не раньше «сейчас» (часы приложения), верхней границы нет.
- Страница: срок вводится по московскому времени (как показываются времена страницы); список исполнителей — активные участники из `listMembers` (без `members.read` список пуст — форма назначения не показывается, исполнитель и срок видны).
