### 0.3 Стенд: проверить, пересоздать, поднять

Все команды выполняются из корня репозитория `D:\work\test26042026_Kirill_3.0` в PowerShell. Сначала:

```powershell
$env:COREPACK_ENABLE_DOWNLOAD_PROMPT='0'; [Console]::OutputEncoding=[Text.Encoding]::UTF8
```

Env-файл стенда — `.claude\tmp\demo\stand-s0.env`; логи и PID процессов — `.claude\tmp\demo\` (`api.log`, `worker.log`, `vite.log`, `reference.log`, `mock.log`, `procs.json`).

**Проверить, что всё живо:**

```powershell
node docs/demo/stand-procs.mjs status
curl.exe --noproxy "*" -s http://127.0.0.1:8100/readyz
```

Ожидается: пять строк «работает (pid …)» — api, worker, vite, reference, mock — и `ok`/200 от `/readyz`. Контейнеры: `docker ps --filter name=ortus-` → `ortus-postgres-1`, `ortus-minio-1`, `ortus-mailpit-1`, `ortus-otel-collector-1`.

**Пересоздать базу и сид показа — обязательно в 11:50 (до репетиции) и в 12:40 (до показа):**

```powershell
node docs/demo/stand-procs.mjs reseed --env .claude\tmp\demo\stand-s0.env
```

Команда работает около минуты: останавливает cmd/api и cmd/worker, затем `down -v` → `up` → `bucket` → `migrate` → `seed demo`, затем снова поднимает cmd/api и cmd/worker. Vite, эталон и mock продолжают работать. В выводе должна быть строка «demo alta (t_alta): «Логистика» включена, Марина Котова — «Менеджер логистики» в «Север Логистик»», а в конце — «✔ api» и «✔ worker».

Почему это обязательно:

- путь одноразовый: после приёмки Р-208 уже «Принят»;
- окна рейсов считаются от часа сида: Р-208 начинается за час до него и длится 4 часа, Р-211 начинается через 5 часов после Р-208. Сид в 12:40 даёт Р-208 с 11:00 до 15:00;
- бронь держится 30 минут: с брони до «Выехать на маршрут» должно пройти меньше 30 минут.

**Поднять всё с нуля** (после перезагрузки ПК или если Docker был остановлен). Docker Desktop должен быть запущен:

```powershell
node deploy/compose/stand.mjs init --slot 0 --force --env .claude\tmp\demo\stand-s0.env   # только если файла нет
foreach ($s in @(@('up'),@('bucket'),@('migrate'),@('seed','demo'))) { node deploy/compose/stand.mjs @s --env .claude\tmp\demo\stand-s0.env; if ($LASTEXITCODE -ne 0) { break } }
node docs/demo/stand-procs.mjs start --env .claude\tmp\demo\stand-s0.env
```

`start` собирает cmd/api и cmd/worker (`go build`), запускает их вместе с Vite (адаптер http, `--mode e2e`), эталоном (4173) и mock (5180) в фоне и ждёт ответа каждого. Окно PowerShell после этого можно закрыть. Запасной вариант — `node docs/demo/demo-stand.mjs --slot 0 --serve --env .claude\tmp\demo\stand-s0.env` (W2.90): то же самое, но процессы живут, пока открыто окно, а `Ctrl+C` их останавливает.

## Режим mock (без сервера)

Mock уже запущен на http://127.0.0.1:5180. Вручную в отдельном окне:

```powershell
$env:VITE_ADAPTER='mock'; node frontend/apps/web/scripts/dev.mjs --mode e2e --host 127.0.0.1 --port 5180 --strictPort
```

(это то же, что `corepack pnpm run dev` с `VITE_ADAPTER=mock` и `--mode e2e`). Или фоном: `node docs/demo/stand-procs.mjs start --only mock --env .claude\tmp\demo\stand-s0.env`.

- Состояние mock живёт во вкладке. «Логистику» владелец включает на «Модули и место» → «Подключить», либо пресетом `logistics-ready`.
- **Только в mock:** карточки «Пробный период: осталось 12 дней» и «3 сотрудника без роли» на «Главной», начисление 4 500 ₽ сразу после приёмки (на стенде — 0 ₽ до «Изменить»).
- **В mock вручную фото не загружаются**: браузер не обслуживает адрес хранилища mock, это блокер W2.22. Путь водителя в mock показываем прогоном e2e в видимом браузере (около 20 с: водитель → логист → «Смена принята»):

  ```powershell
  $env:E2E_MODE='mock'; $env:E2E_BASE_URL='http://127.0.0.1:5180'; $env:REFERENCE_PORT='4173'; $env:ORTUS_SLOT='0'
  corepack pnpm --filter @ortus/web exec playwright test e2e/journeys/stage2/driver-shift.spec.ts --grep "@mock" --project=mobile-390 --headed
  ```

## Если сломалось

| Симптом | Что делать |
|---|---|
| Страница не открывается, «Не удалось загрузить…» | `node docs/demo/stand-procs.mjs status`. Если процесс «не запущен» — `node docs/demo/stand-procs.mjs start --env .claude\tmp\demo\stand-s0.env` (запускает только недостающие). |

| Фото висит в «Загрузка …» | cmd/worker: `stop --only worker`, затем `start --only worker --env …`. Лог — `worker.log`. |
| Vite завис или страница белая | `stop --only vite`, затем `start --only vite --env …` (около 5 с). Лог — `vite.log`. |
| Нет Р-208, рейс сдан или принят, бронь истекла | `node docs/demo/stand-procs.mjs reseed --env .claude\tmp\demo\stand-s0.env` (около минуты); пока он идёт — эталон. |
