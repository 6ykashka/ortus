## Причина

Рейс сида Р-208 «Северный маршрут» (водитель Илья Васильев, `planned`) по сиду (`backend/cmd/seed/fleet_trips.go`) стоит в окне «час до часа прогона сида + 4 ч», то есть окно включает «сейчас». `driverTrip` берёт первым по окну именно его (так же показывает его «Моя смена», `pickTrip`), отменить рейс API нет. Смены ГАЗели прошлых строк (`apiShift` Ахмедова, Васильева на новых рейсах) идут внутри этого окна, их брони `consumed` сокращаются до фактического времени смены. `apiDeparture` бронировал ГАЗель на всё окно Р-208: пересечение с `consumed` → `409 reservation_overlap «Машина уже недоступна»`. Поэтому красная только после других смен ГАЗели на том же стенде: [mobile-390] на свежем стенде проходит, [tablet-768] и [desktop-1440] после mobile — нет.

Доказательство (диагностика в `apiDeparture` на слоте 3): водительский рейс Р-208 `planned`, окно 19:00–23:00Z, брони ГАЗели `consumed` 20:20:13–20:20:20Z, 20:20:51–20:21:04Z, 20:23:32–20:23:39Z; в БД стенда `fleet.trips` — Р-208 `planned` с водителем, без машины. Бэкенд (`reservations/reserve.go`): бронь может быть короче окна рейса (окно внутри окна рейса).

Не причины (проверены): `trips_active_vehicle_uq` (нет рейсов в `inspection…rework` с ГАЗелью), статус машины (`available`), уборка `closeTrip`/`release` в строках-источниках (рейсы закрыты `accepted`).
