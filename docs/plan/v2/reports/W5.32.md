## Вопросы (значения по умолчанию применены)

- **Q-W5.32-1.** Предпросмотр доступа для терминала считается как для кассы точки (`previewCashAccountAccess` не принимает `drawerAccountId`).
- **Q-W5.32-2.** В `CashOperation` нет номера «K-301»: страница показывает «K-» и 5 знаков хвоста ID. Просьба: поле `number`.
- **Q-W5.32-3.** В `CashAccount` нет срока отчёта подотчёта: строка «Срок отчёта» и чипы «Отчёт сегодня» не выводятся.
- **Q-W5.32-4.** В `CashProposal` нет `sub`; в `CashApprovalRequest` нет списка «Согласуют»: вторая строка — подпись источника, строки «Согласуют» нет.
- **Q-W5.32-5.** Источник предложения: кнопки «Открыть источник» нет (в контракте нет `nav`).
- **Q-W5.32-6.** В `closeCashShift` нет «Оставить размен» — поле показано только для чтения (размен кассы); «Касса в ролях» — только глаголы из `listRoles`, без назначений и лимитов.
- **Q-W5.32-7.** В mock `/me/context` Морозовой нет `cash.*` — кассир не может открыть страницу; ограниченные права проверены подменой ответа в Vitest. Нужен preset или `cash.*` в сиде ролей.
- **Q-W5.32-8.** В `TenantContext` нет id участника: «не автор» определяется по `Member.userId` (нужен `members.read`), иначе сервер отвечает `self_approval`.
