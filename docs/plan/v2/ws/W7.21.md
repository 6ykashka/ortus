## 4. Решения (значения по умолчанию)

- PD-53: глаголы области дают только роли с территориальной областью (эталон терял `chat`, `account`).
- PD-60: назначение со сроком `until` раньше даты часов не действует; дата `DocOpts.today` обязательна. Утечка финансового листа через `versions[].sheets` закрыта в `docsView`.
- Организация в поле `tenant` — по `db.tenantId`, а не `tenants[0]`.
- Q-W4.00-documents-18: проект `pj-docs` «ДОК · Документы · маршруты» с процессом «С согласованием» создаёт `installDocs`.
- Открытые вопросы — `Q-W7.21-1…3` в отчёте (раздел «Осталось»).

## 5. Критерии готовности

1. Все функции A–G, I–L перенесены; паритет с `documents.js` на каждом участнике «Альты» и «Лотоса», каждом документе и папке.
2. Расхождения с эталоном перечислены в §4 и проверены явными тестами.
3. `corepack pnpm run lint`, `typecheck`, `test` зелёные; покрытие `@ortus/domain` не ниже порогов 90 %.
4. Красный коммит с тестами отдельно, затем реализация.
