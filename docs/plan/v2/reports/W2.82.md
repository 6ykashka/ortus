## Сделано

- `tools/design-preview.js`: источник `--ref` больше не зависит от `GIT_DIR` и cwd вызывающего.
  Дочерний git запускается без переменных локального репозитория (`git rev-parse --local-env-vars`,
  запасной список — тот же набор; сравнение имён без учёта регистра — окружение Windows), корень и
  префикс каталога эталона считаются один раз (`git rev-parse --show-toplevel --show-prefix` из `<dir>`),
  файл читается `git -C <top> show <ref>:<prefix><rel>` — путь от корня репозитория. Каталог вне git — 404.
- `tools/__tests__/design-preview.test.mjs`: набор «сервер --ref при заданном GIT_DIR (хук pre-push из
  worktree)» — `GIT_DIR` = `git rev-parse --absolute-git-dir` на время набора, файл из тега → 200 и
  байт-в-байт, нет файла → 404.
- Коммиты:
  - `641b8fff` — docs(w2.82): бриф — design-preview --ref под pre-push из worktree
  - `557f7ff6` — test(w2.82): red — design-preview --ref при заданном GIT_DIR отдаёт файл из тега
  - `48faa22b` — fix(w2.82): design-preview --ref читает путь от корня репозитория без GIT_DIR вызывающего
