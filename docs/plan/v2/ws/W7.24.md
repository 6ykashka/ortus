## 1. Цель

Девять операций тега `Docs`, которые W7.23 оставил с ответом 501: `startDocRoute`, `decideDocRoute`, `requestDocSignCode`, `confirmDocSign`, `ackDocument`, `closeDocAck`, `resumeDocRoute`, `cancelDocRoute` (чтение `getDocRoute` уже есть).

- **Маршрут**: до 6 шагов «Согласовать / Утвердить / Ознакомить / Подпись заказчика», режимы «все сразу / по очереди / достаточно одного», срок шага в рабочих днях. Запуск закрывает версию для правки (статус `in_route`, текущей версии даётся имя «На согласование»), создаёт зеркальную задачу и временные доступы, шлёт уведомления; `dryRun` отвечает «Что произойдёт» и ничего не меняет. Автор не согласует и не утверждает свой документ (409 `separation_of_duties_conflict`, правило выключаемое).
- **Решения**: только участник текущего шага (403 «Сейчас решение ждут: …»); возврат — с комментарием (422 «Напишите, что доработать»), статус `returned`, правка открыта автору; «Отправить снова» — только после новой версии, шаг с возврата начинается заново; отмена и досрочное завершение ознакомления — автор или владелец бизнеса.
- **Зеркальная задача (Q-W4.00-documents-3)**: порт `RouteTasks` модуля `docs`, реализация — новый файл `tasks/doc_route_port.go` (как `forms_port.go`): задача «Согласовать: …» с `doc_route`, статус и исполнитель следуют за маршрутом, системные комментарии; проект по умолчанию — системный «ДОК · Документы · маршруты» с процессом «С согласованием» (Q-W4.00-documents-18), выбранный проект — с проверкой `tasks.create`.
- **Подпись (D-31)**: порт `Signer` — повторное подтверждение входом (пароль или одноразовый код второго фактора) и код по SMS через порт доставки; без провайдера — 503 `dependency_unavailable`. Вызов кода → вызов подписи; три неверных ввода — 429 `rate_limited`; после подписи статус `approved` (`signed` — у шага заказчика), поля CRM замораживаются, в очередь ставится задание PDF/A-копии с данными листа согласования.
- **Ознакомление**: адресаты шага берутся из аудитории на момент шага (без автора и заблокированных), им выдаётся «Читает» только утверждённой версии с флагом «оставить»; отметка хранит версию, время, устройство; шаг закрывается, когда отметились все.
- **Ожидания**: `my.wait` — виды `approve`, `sign`, `ack` для участника текущего шага (вместе с уже имеющимися `returned`, `mention`, `ocr`).
