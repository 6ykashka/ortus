## 1. Цель

По DoR `tasks.md` §6 и Р-27 источник «Главной» для задач и бейдж меню входили в W4.12, но W4.12 вынес их из объёма (Q-W4.12-9), и работу никто не взял. Записи allowlist `home.md:17`, `:26`, `:27` (`expires: stage-4`) истекают. Сделать:

- «Требует решения» (homeVM `:4081–4084`): мои задачи в статусах «Новая» и «На проверке», первые три; срочная — тон danger, иначе neutral; иконка `task_alt` / `rate_review`, чип «Задача» / «На проверке», заголовок «{номер} · {тема}», текст «Срок {ДД.ММ}» и « · создана из ответа формы» у задачи правила формы; «Открыть» — карточка задачи (`/tasks?task=`, Р-20), у заявки воронки — «Заявки» `?project=&task=`.
- «Сегодня в работе» (`:4113`): карточка «Задачи» — «Новые», «В работе», «На проверке» по категориям статусов; переход — «Задачи».
- Бейдж пункта «Задачи» — мои задачи в первом статусе категории «К выполнению» (Р-27).

## 4. Контракт (`0.11.1-stage4`)

- `DecisionItem.kind`: `tasks.task_new` (задача в статусе категории «К выполнению») и `tasks.task_review` (статус проверки процесса); `moduleKey: tasks`, `object` — задача; `params` — `taskKey`, `title`, `dueAt?`, `projectId`, `fromForm?` (`true` — задача правила формы), `funnel?` (`true` — заявка воронки). Срочная (`priority urgent`) — `danger`, иначе `neutral`. Не больше трёх карточек на участника.
- `getMyTaskSummary` (`GET /api/v1/me/task-summary?tenantId=`, тег Home, `x-scope: identity`): `TaskSummary { tenantId, new, inProgress, review, myNew, generatedAt }` — счётчики карточки «Задачи» по задачам, которые участник видит (`tasks.read` с объектом-проектом и областью «своё»), и бейдж.

## 5. Правила (значения по умолчанию — `decisionsNeeded`)

- «Новые» — статус категории «К выполнению» (и первая стадия «Новая» воронки «Заявки», как эталон считает `L-31` владельца).
- «На проверке» — статус категории «В работе», не первый в процессе этой категории, из которого свой переход (не «Из любого») ведёт в «Готово» («Принять», «Согласовать»); остальные статусы «В работе» — «В работе». Стадии воронки «Замер», «Смета», «Договор» в «В работе» и «На проверке» не входят.
- Бейдж — мои задачи в первом статусе категории «К выполнению» проектов с процессом (воронка — своя доска без пункта меню; у владельца в эталоне бейджа «Задач» нет).
- Источник задач — источник ядра (модуль `tasks` всегда установлен, `CoreKeys` W1.08).
