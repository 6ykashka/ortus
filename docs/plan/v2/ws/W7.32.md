# W7.32 Страница «Обращения» (очередь, низкие оценки, звонок, карточка)

Этап 7 · шаг 7.3 · дорожка Ф · размер L · слот 8 · вид `frontend`, режим mock (MSW, контракт 0.12.0-stage7).
Зависит от: W7.00 (контракт тега Service и сценарный сервер `msw/service`), W7.30 (домен «Обращения», уже в `main`). Параллельно: W7.31 (backend), W7.33 (портал клиента).

## 1. Цель

Страница «Обращения» (`/t/:tenantId/service`, ключ `service`) по `design/Обращения.dc.html` (тег `design-2026-10-19`), разбор — `docs/plan/v2/analysis/dor/service.md` §1.1:

- очередь: шапка, навигация по направлениям и очередям (≥ 860 боковая, < 860 чипы), поиск и фильтры «Тип», «Канал», таблица со сроками, пустая очередь, сноска;
- «Низкие оценки»: «Просмотрено», «Открыть жалобу»;
- панель «Обращение по звонку» (встроенная, не диалог);
- карточка: действия по статусам, «Итог решения», «Перенести в другое направление», сроки, лента, поле ответа и заметка, шаблоны, компенсация, закрытое обращение, боковая колонка (исполнитель, приоритет, клиент и показ телефона, связано, «Кто видит» и вывод сотруднику, связанные задачи, «После решения»);
- состояния: загрузка, ошибка, нет доступа, «Обращения не настроены», нет связи.

Деньги и макеты вариантов 1a–1e (портал, настройка, отчёт) — вне карточки (W7.33, кандидаты W7.34–W7.36).

## 2. Границы файлов

Пишу только в `frontend/apps/web/src/routes/service/**` (код, CSS, тексты, Vitest), `frontend/apps/web/e2e/service*.spec.ts`, `e2e/visual/service*.spec.ts`, `e2e/visual/allowlist/service.md`, этот бриф, отчёт `docs/plan/v2/reports/W7.32.md`, `docs/plan/evidence/service/`.
Не трогаю: `api/**`, `msw/service`, домен, `packages/texts`, `package.json`, меню (`nav/modules/service.ts`), `design/`, `status.md`, `decisions.md`.

## 3. Правила и решения по умолчанию

- Права кнопок — по контракту: «Отвечать» = участник в `direction.team` (или владелец), «Решать» — право `service.requests.resolve`, «Заводить» — `service.requests.create`, компенсация — `service.compensation.manage`, показ телефона — `direction.canContacts`. Сервер проверяет с объектом-направлением (PD-53); отказ показывается в панели ошибкой.
- Исполнитель — `assigneeId`, имя для показа; очередь «Мои» — на сервере.
- Компенсация в ответе: `postServiceMessage` + `setServiceCompensation` (контракт разделил то, что в эталоне было одним `svcReply`).
- Подписи и тексты — дословно из эталона; расхождения с контрактом — Q-W7.32-N в `decisionsNeeded`.
- Сроки в карточке и очереди — готовые `head`/`sla` сервера (`label`, `text`, `until`), цвет по `state`.
