## Осталось fixme / открытые вопросы

1. **`memberId`** — id карточки `people.person_profiles` (как `principalId`, примеры, сид W1.04); членство control — по `memberships.person_profile_id`.
2. **`Role.description` не хранится** — колонки нет (tenant 0001): ответ `""`, длина проверяется. Колонка `access.roles.description` — миграция стюарда.
3. **`builtIn`** = `kind = 'system'`; шаблонные роли правятся и удаляются, как свои.
4. **Правка роли** создаёт новую версию и переводит на неё неснятые назначения (права держателей меняются сразу, как в прототипе), `policy_version + 1` при смене прав; переименование — новая ревизия без новой `policy_version`.
5. **Делегирование в редакторе ролей** — участник добавляет только права своих действующих грантов (любая область), снимать может любые; владелец — любые ключи каталога; `owner_only` — только владелец.

7. **Видимость назначения и гранта** — по «якорю»: подразделение области; для `tenant` — организация; для `self` и объектных — дом принципала (группа без дома — организация).
8. **Состояние назначения** — `dormant` как есть, закончившееся — `expired`, ещё не начавшееся — `active` (в контракте нет `scheduled`); в «Почему доступно» не начавшееся — `expired` (ближайшая причина enum).
