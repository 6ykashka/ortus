# W7.25 Страницы «Документы» (список, папки, карточка, доступ)

Этап 7 · дорожка Ф · шаг 7.2 · размер L (по разбору — XL, см. §5) · слот 4 (Vite 5204, Storybook 7204, API 8104, эталон 4104, `ortus-s4`) · вид `frontend`.
Зависит от: W7.00 (контракт `0.12.0-stage7`: тег Docs, экраны `docs-list`, `docs-doc`, `modal-doc-share`, `docs-folders`; MSW Docs уже в `adapter/msw/docs`). Backend документов — W7.23a/b, ещё не в main, поэтому страницы живут на MSW; режим stand — `test.fixme` с причиной.

## 1. Цель

Страница `docs` («Документы», маршрут `/t/:tenantId/docs`, ключ меню `docs`) по эталону `Документы.dc.html` (design-2026-10-19, разбор `analysis/dor/documents.md` §1.1–§1.9):

- **список** (`docs-list`): заголовок и подзаголовок, пять плиток создания, «Ждут меня · N», поиск, папка, отборы «Все · Мои · Поделились со мной · На маршруте» (+ «Архив»), таблица (≥ 900) и карточки (< 900), пустые состояния, пояснение; диалоги «Новый документ» (вкладки Текст, Таблица, PDF, Из шаблона, Скан; `createDocument`, загрузка файлов `initiateUpload`/`completeUpload` с `purpose: document`), «Перенести в другую папку» (`moveDocument` с `dryRun`), «Новая папка» (`docs-folders`, no-reference);
- **карточка** (`docs-doc`, `?doc=<id>`): оболочка (назад, крошки, переименование на месте, «Сохранено на сервере · vN», чип статуса, меню «…», баннеры состояний, подвал движка), окно документа без редактора (Q-W4.00-documents-1: «Редактор подключается», просмотр и поля CRM), вкладки «Обсуждение» (комментарии, ответы, закрытие, упоминание), «Версии» (сохранить, назвать, восстановить, журнал), у таблицы «Данные» (`syncDocDataset`, защищённые диапазоны), у PDF «Распознавание» / «Инструменты» (слова под вопросом `reviewOcrWord`, «Преобразовать» и задания `createDocJob` / `getDocJob` / `retryDocJob`);
- **«Поделиться»** (`modal-doc-share`, правая панель 480 px): кто вы, добавить, режим «Как у папки и свои» / «Только выбранные», записи с уровнями, внешняя ссылка (срок ≤ 30 дней, PIN, водяной знак), «Что изменится» (`setDocShares` с `dryRun`), «Откуда доступ» (цепочка `my.chain`).

Не входит (другие WS): полоса маршрута, «На согласование», «Утвердить · ПЭП», ознакомление — W7.26; операции правки блоков — движок (D-32); публичная страница ссылки — W7.23/W7.28.
