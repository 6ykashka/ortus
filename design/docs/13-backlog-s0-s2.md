# 13. Бэклог S0–S2 — версия 0.2

Черновик от 1 октября 2026 года. Истории сгруппированы по эпикам и ссылаются на требования ТЗ (`01`) и критерии приёмки (AC). Размер — относительный (S ≈ до 2 дней, M ≈ 3–5, L ≈ больше недели и подлежит разбиению). Календарную оценку делает команда после S0.

## Готовность истории (Definition of Ready)

- Есть ID требования и измеримый критерий приёмки (Given–When–Then или AC-xx).
- Операции API описаны в OpenAPI: DTO, ошибки, `x-permissions`, `x-scope`, примеры.
- Права есть в `11-permissions.yaml`; затронутые таблицы — в модели данных.
- Для экрана указаны состояния: обычное, пусто, загрузка, ошибка, нет права, конфликт, офлайн.
- Негативный сценарий доступа сформулирован (чужая фирма, чужой тенант, функция водителя).
- Зависимости от других историй сняты или явно указаны.

## Готово (Definition of Done)

- Код прошёл review; изменения authz, миграций и финансов — с вторым ревьюером из security/backend lead.
- Unit + integration тесты; негативные тесты доступа добавлены в общий набор изоляции.
- Контракт: сгенерированный клиент и сервер собираются, Spectral без ошибок, нет дрейфа codegen.
- Миграция применяется и откатывается (expand/contract) на двух tenant DB разных версий.
- Логи без секретов и restricted-полей; метрики и трасса есть.
- UI: клавиатура, видимый фокус, подписи, контраст; проверены 390 / 768 / 1440 px.
- Обновлены документация и changelog контракта; демо на стенде dev.

## Не входит в S0–S2

Формы-конструктор, задачи-канбан, база знаний, календарь недели, SPA, касса, склад, ремонт, внешние интеграции, оплата подписки онлайн, оптимизация маршрутов. Прототип уже показывает их UX; реализация — S3+.
