## 1. Цель

1. **cmd/api на стенде e2e не виснет (Q-W1.23-20).** Сейчас `startApi` запускает cmd/api с `stdio: ['ignore', 'pipe', 'pipe']` и перекачивает pipe в файл через `stream.pipe`, а Playwright идёт через `spawnSync`: цикл событий родителя стоит, pipe никто не читает, после заполнения буфера (≈ 64 КиБ на Linux, меньше на Windows) cmd/api блокируется на записи лога запроса — стенд виснет до таймаута job. Решение: лог cmd/api — прямо в файл (`openSync(st.apiLog, 'w')`, `spawn(apiBin, [], { stdio: ['ignore', fd, fd] })`), родитель pipe не держит. Путь лога печатается при старте и при любом падении после старта (с последними строками лога).
2. **Почта на стенде e2e (Q-W1.23-21, Q-W1.41-7).** Шаг `up` поднимает `postgres` и `mailpit`; cmd/api получает `SMTP_HOST=127.0.0.1`, `SMTP_PORT` слота (из env-файла стенда), `PUBLIC_ORIGIN=http://127.0.0.1:<Vite слота>` (тот же origin, что `appURL` харнесса — ссылка из письма открывается в контексте теста); Playwright — `E2E_MAILPIT_URL=http://127.0.0.1:<MAILPIT_UI_PORT слота>` (API Mailpit `/api/v1/messages`) и хост Mailpit в `E2E_ALLOW_HOSTS` (если тест откроет письмо в браузере). `inviteMember` на стенде — 201 и письмо в Mailpit, а не 503.
3. Официальный прогон `node tools/ci/e2e-stand.mjs --slot 15` — все `@stand`-spec main зелёные, без зависаний; стенд снят `down -v`.

## 4. Контракты

Контракт API не меняется (`contractPr: —`). Внутренний интерфейс `tools/ci/e2e-stand.mjs`:

```js
/** Дочерний процесс с stdout/stderr прямо в файл: родитель pipe не держит, spawnSync родителя не блокирует ребёнка. */
export function startLogged(cmd, args, { logFile, cwd, env }) // → { child, exit: Promise<number> }
export function apiEnv(standEnv, slot)            // + SMTP_HOST=127.0.0.1, SMTP_PORT слота, PUBLIC_ORIGIN
export function mailpitURL(standEnv, slot)        // http://127.0.0.1:<MAILPIT_UI_PORT>
export function playwrightEnv(baseEnv, slot, jsonFile, standEnv = {}) // + E2E_MAILPIT_URL, E2E_ALLOW_HOSTS
```

Шаг `up`: `stand.mjs up postgres mailpit --env <файл>`.
