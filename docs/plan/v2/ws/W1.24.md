## 1. Цель

После W1.24 владелец организации в режимах `mock` и `stand`:

- на странице **«Модули и место»** (`/t/:tenantId/modules`, эталон `design-stage-1` «Ортус CRM.dc.html» `:205–281`, `omVM :3100–3137`, анализ `02-company.md` §5) видит карточку статуса подписки (пробный период / ограничен / действует — по `TenantContext.tenantState`), три отраслевых модуля из `listModuleCatalog` с чипом состояния, зависимостями и строкой о ролях, 12 базовых модулей с «Использует: …», карточку «Место организации» (`getStorageUsage`, `getStorageBreakdown`) с полосой `meter` «Занятое место», разбивкой по группам эталона и выбором «Лимит места»;
- подключает модуль через диалог «Подключить «{name}»?» (`setModuleInstallation`, `If-Match`), отключает через диалог «Отключить «{name}»?» с текстом модуля: «Затронет сейчас» — из `previewModuleDeactivation.activeItems` (пусто — «Активных процессов нет»), «Что произойдёт» — тексты модуля эталона 14.10 и пункт меню D-23 «Отключены · только чтение»; флажок «Понимаю последствия для текущей работы»;
- меняет лимит места (`requestStorageChange` quote → commit) через диалоги «Изменить лимит на {gb} ГБ?» / «Новый лимит меньше занятого места»; после смены лимита перечитываются место, разбивка и `/me/context` (Q-W1.20-18: баннер «Место организации заполнено.» у сотрудников);
- на странице **«Хранилище»** (`/t/:tenantId/storage`, no-reference B-6 №5) видит занято / резерв / лимит, разбивку по группам эталона и по модулям, ожидающее уменьшение (`pendingQuotaBytes`) и расчёт смены квоты с ценой;
- на странице **«Файлы»** (`/t/:tenantId/files`, эталон `:1858–1868`, `filesVM :4219–4231`, анализ `06-…files` §8) видит место организации, список файлов `listFiles` с родительским объектом, чипом состояния и размером; «Открыть» получает короткую ссылку `getFileDownload` (проверка доступа к родителю на сервере) и открывает её; пустой список — «Доступных файлов нет».

Компонент **«Загрузка файла»** (`modal-upload`, no-reference): сессия загрузки `initiateUpload → PUT по билету → completeUpload → опрос getFile` (состояние проверки `quarantined → ready | rejected` — у файла; `getUploadSession` после `completeUpload` отдаёт только `completed`) внутри диалога `UploadDialog` (отдельного хука нет, §7), с полосой прогресса передачи, отменой (`abortUpload`) и повтором — в каталоге «Файлов», для потребителей этапа 2 (фото осмотра W2.04).

Демо-кнопки «Демо: завершить пробный период», «Демо: открыть как оператор» не переносятся (PD-54): ограничение организации задаёт оператор (W1.25), в e2e — пресет `trial-ended` сценарного сервера.
