## 1. Цель

После W1.21 все единицы `@ortus/ui`, которые `src/contract.ts` (`OWNERS`) закрепил за W1.21, заменены реализацией на React Aria Components (PD-13) и токенах `--ox-*`, без единого литерала цвета:

- «11 компонентов» карточки — группы старого WS-12 без шести компонентов S0-05: `IconButton`; поля `TextInput`, `NumberInput`, `MoneyInput`, `DateInput`, `Select`, `Textarea`; выбор `Checkbox`, `Switch`, `RadioGroup` + `Radio`; `AccessGate`; `ConfirmDialog`; `Sheet`; `Toast`; `EmptyState`; `Skeleton`; `Tabs`; `Meter`;
- плюс единицы, которые W0.10 записал за W1.21 в `OWNERS`: `VisuallyHidden`, `Nav`, `ScopeSelect`;
- плюс `DataTable` (`src/domain/DataTable`, заглушка W0.10 с `@stub Owner: W1.21`).

Каждая единица: тесты Vitest + Testing Library + axe написаны до реализации (red-коммит отдельно), истории Storybook `Core/<Name>` (`Domain/DataTable`) с русскими именами, визуал сверен с `Дизайн-система.dc.html` (канон визуала — витрина, Q-W0.10-1; отличия CRM — CSS-переменные). Баррель `src/index.ts` — только генератором `scripts/gen-barrel.mjs`. Страничные WS (W1.20, W1.22…W1.25) собирают экраны из этих компонентов.

## 6. Тесты, которые пишутся первыми

Компонентные (`src/core/<Name>/<Name>.test.tsx`, Testing Library по ролям и подписям, axe serious/critical = 0 в каждом файле):

- IconButton: имя из `label`; бейдж «3» виден и `aria-hidden`; `badge: 0` не рисуется; нажатие; axe.
- VisuallyHidden: текст доступен, стиль clip.
- Поля: `Field` + `TextInput` связывает подпись (`getByLabelText`); `unit` поля виден в `Field`; ошибка → `aria-invalid` и `aria-describedby`; `NumberInput` показывает «48 210», `inputmode="numeric"`, ввод «48300» → `onChange(48300)`, ↑ прибавляет `step` в пределах `max`; `MoneyInput` 325000 → «3 250,00», «₽», ввод «1250» → `onChange(125000)`, пусто → `null`; `DateInput` `type="date"`; `Select` — `combobox` с опциями «Топливо», «Мойка», «Парковка» и `onChange`; `Textarea` `rows`; без `Field` — рамка и единица; axe.
- `format.ts` (unit): `formatMoney`, `parseMoney`, `formatInteger`, `parseNumber` — NBSP, запятая, минус, мусор → `null`.
- Checkbox: `getByRole('checkbox', {name})`, клик → `onChange(true)`, `indeterminate` на input, `disabled`, описание; axe.
- Switch: `role="switch"`, имя из `label` при `labelHidden`, клик и Space переключают, `checked && disabled`; axe.
- RadioGroup/Radio: `radiogroup` «Уровень топлива», ровно один `checked`, клик и стрелка → `onChange`, `disabled`; axe.
- AccessGate: четыре причины → чип и `h1`; кнопка только при `action`; axe.
- ConfirmDialog: `dialog` с именем из заголовка, `aria-modal`; секции и пункты; без флажка `ack` главная кнопка недоступна; `busy` → «Выполняем…», обе кнопки недоступны; «Отмена» → `onClose`; Esc; axe.
- Sheet: `dialog` «Все разделы», кнопка «Закрыть» → `onClose`; axe.
- Toast: `role` по тону, `aria-live`, автоскрытие через 4200 мс (fake timers) и сброс при смене текста, действие; axe.
- EmptyState, Skeleton, Meter, ScopeSelect: роли и атрибуты (`aria-busy`, `aria-hidden`, `role="meter"` с `aria-value*`, danger сверх лимита, `combobox` «Область просмотра»); axe.
- Tabs: `tablist` с именем, `aria-selected`, клик и ArrowRight → `onChange`, счётчик, `aria-controls` → `tabpanel` с содержимым; axe.
- Nav: три режима, `aria-current="page"`, бейдж и «план», подписи в rail доступны, «Ещё»; axe.
- DataTable: `th scope="col"`, строки, `aria-sort` и `onSort`, `onRow` по кнопке строки, loading/empty/error, карточки на узком экране (`matchMedia` мок), `scroll` без карточек; axe.

Пакетные: `stubs.test.tsx` и `stories.test.ts` — по маркеру `@stub` (заглушек ровно столько, сколько каталогов с маркером; у каждой реализованной единицы, кроме `Icon` и `VisuallyHidden`, есть истории `Core/<Name>` или `Domain/<Name>`); `contract-types.typetest.tsx` — `@ts-expect-error` для обязательных пропсов (`Toast.onDismiss`, `Meter.label`, `Tabs['aria-label']`, `AccessGate.reason`).
