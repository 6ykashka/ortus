# W2.61 · «Моя смена» временного водителя после срока: сдача на экране без `listVehicles`

Этап 2, подволна 2e (план v2 §4, строка W2.61; отчёт W2.32, Q-W2.32-2). Вид — frontend. Размер S. Слот 7: Vite 5207, Storybook 7207, API 8107, эталон 4107 (`E2E_OWN_REFERENCE=1`, `REFERENCE_REF=design-stage-2`), compose `ortus-s7`.

## 1. Цель

Исправить дефект журни W2.32 (AC-06, Q-W2.32-2). После срока окна перевода у начатого рейса (продолжение D09, Q-W2.07-1, W2.57) у роли «Временный водитель» нет машины рейса в области `resource`. `listVehicles` отвечает 403 `forbidden_action`, и «Моя смена» (`driver-today`) целиком падает: «Не удалось загрузить машины: Нет права на это действие…». Сдать смену можно только командами API.

После исправления экран начатого рейса не зависит от `listVehicles`. Машину и рейс экран берёт из рейса (`TripPlan.vehicleId`, осмотр выезда), а сбой списка машин не ломает карточку рейса. На экране проходят «Завершить рейс», осмотр при сдаче с пятью фото и «Сдать машину».

## 5. Экраны и состояния

`driver-today` (`/t/{tenantId}/today`, h1 «Моя смена», водитель):

- Список машин нужен только до выезда: «Выберите машину» (`planned`/`assigned`) и осмотр перед выездом (`inspection`: строка брони, пробег машины). В этих состояниях сбой `listVehicles` по-прежнему показывает «Не удалось загрузить машины: …» и «Повторить».
- Начатый рейс (`on_route`, `returning`, `rework`, `submitted`, `accepted`) и `defect_review`: экран не ждёт `listVehicles` и не показывает его ошибку. Карточка рейса, «Маршрут», «Завершить рейс», расходы, осмотр при сдаче, «Сдать машину», «Ожидает приёмки менеджером» работают без списка.
- Подзаголовок осмотра при сдаче: с машиной — как в эталоне, «{модель} · {номер} · сравнение с выездом»; машина неизвестна (продолжение после перезагрузки) — «Сравнение с выездом» без пустых « · ».

## 10. Риски и решения по умолчанию

1. **Машина рейса в продолжении — не с сервера.** Строку `resource` роли продолжение не продлевает: это решение W2.57, оно записано в контракте. W2.72 (S2-20) меняет строки `resource` пула. По умолчанию сервер не меняю: в продолжении `listVehicles` остаётся 403, ожидание `CARS_NARROW` журни прежнее. Название машины берётся из списка, если он загружен в этой вкладке (данные запроса остаются и после сбоя перечитывания). После перезагрузки подзаголовок — «Сравнение с выездом». Вопрос — в decisionsNeeded.
2. В продолжении запрос `listVehicles` уходит и получает 403. Экран его не показывает, повторов нет (`retry: false`).
3. Экран W2.74 (выбор машины временного водителя) затрагивает только состояния до выезда. Правило `needsCars` его не ограничивает.
