## Вопросы и решения по умолчанию (Q-W5.21-N)

1. Нет справочника клиентов: клиент — из названия календарной брони, форма записи предлагает клиентов визитов недели.
2. Две кнопки владельца эталона = `completeAppointment` с `overrides` (факт = остаток), разные причины.
3. «Остатки кабинета» показаны, «Движения склада» — после W5.11.
4. Нехватка по контракту — 409 без частичного списания (эталон списывал часть).
5. Специалист не видит услуги и техкарту: `spa.services.read` ему не выдаётся.
6. Ключ `spa.appointments.perform` не выдаётся ни одним действием роли: специалист не может «Завершить процедуру» (в эталоне может). Нужно решение стюарда каталога.
7. Цены услуг эталон не задаёт — демо: 3 200 / 6 500 / 2 000 ₽.
8. Подразделение новой услуги — подразделение первой услуги или кабинета.
