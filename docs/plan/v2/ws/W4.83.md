## 1. Цель

Контракт PublicForms (`api/openapi/components/common/parameters.yaml#/Origin`): «Required and checked against the deployment allowlist for … browser public-form submissions/uploads. Never accept wildcard». Шлюз пропускает операции `security: []`, модуль форм заголовок не читал (Q-W4.90-1, срок «до конца этапа 4»). Код приводится к контракту: гостевые команды с чужим `Origin` получают отказ и ничего не пишут.

## 5. Поведение

| Запрос гостя | Ответ |
|---|---|
| `Origin` из списка разрешённых | как раньше |
| `Origin` вне списка (чужой сайт, `null`, пустой, другой порт или схема) | 403 `origin_not_allowed`, ответ и файл не пишутся, тело не называет форму и организацию |
| без `Origin` | как раньше: по Fetch браузер шлёт `Origin` с каждым POST, запрос без него не браузерный, а контракт требует заголовок только у браузерной отправки |

- Проверяются операции PublicForms, которые объявляют параметр `Origin`: `submitPublicForm`, `initiatePublicUpload`, `completePublicUpload`, `getPublicUploadStatus`. `getPublicForm` (GET без параметра) не проверяется.
- Список разрешённых = `ALLOWED_ORIGINS` (SPA, в том числе iframe `?embed=1`: документ iframe открыт с origin SPA) ∪ `PUBLIC_ORIGIN` ∪ новая необязательная `FORMS_PUBLIC_ORIGINS` (через запятую — сайты, которые шлют гостевую форму со своего origin). Совпадение точное, `*` и origin с путём останавливают старт.
- Проверка — первой в хендлере модуля (`forms.PublicServer`), до тела, nonce и идемпотентности.

## 10. Риски и решения по умолчанию

- Q-W4.83-1: запрос без `Origin` принимается (не браузерный клиент). Альтернатива — требовать заголовок всегда — решение людей.
- Q-W4.83-2: `getPublicUploadStatus` проверяется наравне с загрузками (объявляет `Origin`, часть загрузки гостя).
- Демо-стенд и прод: если гостевую форму шлют со стороннего сайта напрямую (не iframe), его origin нужно добавить в `FORMS_PUBLIC_ORIGINS`.
