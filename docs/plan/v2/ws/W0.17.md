## 1. Цель

После W0.17 в `main`:

1. **П-1.** Job `e2e-stand` в `pipeline.mjs` и `ci.yml`: compose `postgres` → `migrate` → `seed` → `cmd/api` → Vite и Playwright `@stand` (`me-context.spec.ts`). Порты берутся по слоту. Стенд останавливается с удалением томов в `finally` скрипта, а в CI ещё и шагом `if: always()`. Браузерный путь `/me/context` проверяется в CI.
2. **П-4.** В конвейер добавлены `test:plan` (`docs/plan/scripts`), `test:adr` (`docs/adr`), `test:load` (`backend/test/load`) — через корневой `test`; `check-decisions` (`renumber-decisions --check`), `allowlist-lint`, `mcp:check` (без сети: initialize + tools/list) — в job `unit`; `storybook:build` `@ortus/ui` и `check-k6` (Docker) — в job `build`.
3. **Гейт `renumber-decisions --check` зелёный.** Ссылки на решения комплекта (D-23 «меню владельца по состоянию модуля») в `docs/plan/analysis/01–03` отличаются от старых номеров плана по контексту строки: явная пометка «комплекта» или тема решения из allowlist `KIT_DECISIONS`.
4. **П-5.** `corepack pnpm run stand` = `init` (если нет `.env`) → проверка портов → `up --wait` → `migrate` → `seed`; `corepack pnpm run stand:down` = `down -v`.
5. **П-6.** `stand.mjs up` (и `stand`) перед `docker compose up` проверяет, свободны ли опубликованные порты выбранных сервисов на `127.0.0.1`. Порты, которые уже держит сам проект, не считаются занятыми. Если порт занят, выводится понятная ошибка с именем переменной, сервисом и подсказкой, и команда завершается с кодом 3. Слоты расширены до 0…20. База MinIO и OTLP для слотов ≥ 1 перенесена так, чтобы порты слотов 0…20 не попадали на 10000/11001, занятые на машине разработчика, и на порты §3.6.
6. **actionlint через Docker** без remote: шаг `lint/actionlint` (`rhysd/actionlint:1.7.12`) прогоняется локально на изменённом `ci.yml`.

## 4. Контракты (публикуются)

```text
node deploy/compose/stand.mjs all [--slot N] [--force]     init (если нет .env или --force) → up --wait → migrate → seed
node deploy/compose/stand.mjs up [--profile p ...] [svc]   перед up — проверка портов (код 3, если порт занят)
node deploy/compose/stand.mjs init --slot N                N = 0…20
corepack pnpm run stand [-- --slot N]  /  stand:down       all  /  down -v
node tools/ci/e2e-stand.mjs [--slot N] [--keep]            стенд (только postgres) → migrate → seed → cmd/api → playwright @stand → down -v
node tools/ci/e2e-stand.mjs --down [--slot N]              остановка (шаг always в CI)
```

Порты стенда: слот 0 — стандартные порты скелета. Слот N ≥ 1 — `база_слота + 100 × N`, где `база_слота` совпадает с портом слота 0, кроме `MINIO_PORT` 19000, `MINIO_CONSOLE_PORT` 19001, `OTEL_GRPC_PORT` 14317, `OTEL_HTTP_PORT` 14318. Старые базы давали 10000/10001 на слоте 10, 11001 на слоте 20 и 5217/5218, 6117/6118 (Vite и проверяющий слотов 17–18) на слотах 9 и 18.

Слот `e2e-stand`: `--slot`, иначе `ORTUS_SLOT`, иначе в CI 0. Локально без слота шаг конвейера пропускается с причиной: слот 0 — общий стенд интегратора, его тома скрипт не удаляет. Приложение: Vite `5200 + N`, API `8100 + N`, эталон `4100 + N`; `APP_ENV=e2e`, `ALLOWED_ORIGINS=http://127.0.0.1:<vite>,http://localhost:<vite>`. Итог Playwright (JSON-отчёт) должен содержать ≥ 1 пройденный тест, 0 пропущенных и 0 упавших: проверка не может молча пропустить `@stand`.
