# W2.94 · visual/driver-offer: тайм-аут 2,0 мин на строку в CI

Этап 2 · вид frontend · слот 4 (свой эталон 4104, `E2E_OWN_REFERENCE=1`). Карточки в §4 нет — постановка интегратора по прогону GitHub 40281422068.

## 1. Цель

mock-шарды 6/20, 13/20, 20/20 красные: `e2e/visual/driver-offer.visual.spec.ts:48` и `:59` (W2.74), 2,0 мин × 3 попытки на проект. Локально строка — 8 с. Установить причину и исправить.

## 2. Причина

CI задаёт `REFERENCE_REF: design-stage-1` (W2.70, Q-W2.70-15). В снимке design-stage-1 файла `Временный водитель - варианты.dc.html` нет (он появился в design-2026-10-19b). `reference(FILE)` открывает несуществующую страницу, `waitForReferenceReady` ждёт `.sc-host` до тайм-аута теста (120 с). Локально эталон читает рабочую копию `design/`, где файл есть.

## 3. Границы файлов

`frontend/apps/web/e2e/visual/driver-offer.visual.spec.ts` (и `e2e/driver-offer.helpers.ts`, если понадобится); новые файлы запуска собственного эталона в том же каталоге: `e2e/visual/own-reference.ts` и `e2e/visual/own-reference.spec.ts` (добавлены в возврате 1, чтобы выделить запуск `design-preview` и покрыть его красным тестом); свои `ws/W2.94.md`, `reports/W2.94.md`. Фикстуры `e2e/fixtures/**` не трогаем (общие).

## 4. Решение

Если файла нет в списке `referenceFiles` общего эталона, спек поднимает собственный `design-preview` на снимке `design-2026-10-19b` (один на воркер, останавливается с воркером) и открывает макет там. Если файл есть — прежний путь `reference(FILE)`.
