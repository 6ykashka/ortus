# Политика обработки персональных данных (черновик)

Черновик для юриста. Скобки `[…]` — реквизиты, которых в проекте нет. Не публиковать до ответов Q-W3.04-1…Q-W3.04-3.

## 1. Общие положения

1.1. Политика описывает, как `[полное наименование оператора, ИНН, ОГРН, адрес]` (далее Оператор, сервис «Ортус CRM») обрабатывает персональные данные пользователей сервиса.

1.2. Политика относится к данным, для которых Оператор сам определяет цели и способы обработки: данные аккаунтов входа (раздел 3). Данные, которые организации-клиенты вносят в свои рабочие области, Оператор обрабатывает по их поручению (раздел 8), цели и состав определяет клиент.

1.3. Основание: Федеральный закон от 27.07.2006 № 152-ФЗ «О персональных данных». `[Перечень ссылок на актуальные редакции подтверждает юрист.]`

## 2. Термины

Персональные данные, оператор, обработка, поручение, субъект: как в 152-ФЗ. Аккаунт: запись, по которой человек входит в сервис через провайдера идентификации. Организация (тенант): клиент Оператора со своей рабочей областью.

## 3. Какие данные Оператор обрабатывает как оператор

| Данные                                                   | Цель                                          | Основание                         |
| -------------------------------------------------------- | --------------------------------------------- | --------------------------------- |
| Идентификатор у провайдера входа, email, отображаемое имя | вход, сопоставление приглашений, интерфейс    | согласие, договор (пользовательское соглашение) |
| Сведения о сессиях (время входа, провайдер, идентификатор сессии в виде хеша) | безопасность, предотвращение подмены сессии   | законный интерес Оператора `[юрист]` |
| Технические журналы (IP-адрес, User-Agent, идентификатор запроса) | безопасность, расследование инцидентов        | законный интерес `[юрист]`        |
| Журнал действий операторов поддержки                    | подотчётность доступа к данным клиентов       | законный интерес, договор         |

Источник полного перечня по полям: [data-map.md](data-map.md), раздел 1.

## 4. Чего Оператор не собирает

Специальные категории (здоровье, расовая и национальная принадлежность, политические и религиозные взгляды), биометрию, паспортные данные, СНИЛС, геопозицию водителей и клиентов. Метаданные местоположения в фотографиях (EXIF) удаляются на устройстве до загрузки. Сведения о противопоказаниях клиентов SPA сервис не хранит: фиксируется только отметка «клиент подтвердил отсутствие противопоказаний».

## 5. Принципы и меры

5.1. Обработка ограничена целями, данные не избыточны, хранятся не дольше, чем нужно для цели.

5.2. Базы данных, хранилище файлов, резервные копии и журналы с персональными данными находятся на территории Российской Федерации (российское облако, ADR 0006).

5.3. Меры защиты: шифрование хранилища и резервных копий, TLS на всех соединениях, разграничение доступа по ролям и областям, изоляция данных организаций (отдельная база у каждой), токены и секреты в защищённом хранилище, аудит доступа, доступ поддержки только по временному разрешению организации (`support_grants`, не более 60 минут, без права читать начисления), удаление локальных данных на устройстве при выходе.

5.4. Работники Оператора допускаются к данным по необходимости, подписывают обязательство о неразглашении. `[Приказы и перечень лиц: заполняет Оператор.]`

## 6. Сроки хранения и удаление

| Данные                              | Срок                                                                                          |
| ----------------------------------- | --------------------------------------------------------------------------------------------- |
| Аккаунт                             | пока пользователь пользуется сервисом; удаление по запросу `[срок исполнения — юрист, не более 30 дней]` |
| Сессии                              | 12 часов; запись входа OIDC — 10 минут                                                         |
| Технические журналы                 | `[срок — Q-W3.04-4]`                                                                           |
| Журнал действий поддержки           | `[не менее 3 лет — Q-W3.04-4]`                                                                 |
| После расторжения договора с организацией | read_only 30 дней с выгрузкой; удаление из рабочих баз на 90-й день; резервные копии 30 дней; полное удаление не позднее 120 дней |

Данные удаляются или обезличиваются при достижении цели, отзыве согласия (если оно было основанием), по требованию субъекта в случаях, предусмотренных законом.

## 7. Права субъекта

Субъект вправе получить сведения об обработке, требовать уточнения, блокирования и удаления, отозвать согласие, обратиться в Роскомнадзор или в суд. Запросы: `[email для запросов]`; ответ в сроки 152-ФЗ `[юрист подтверждает]`. Если данные внесены организацией-клиентом, запрос направляется ей, Оператор помогает исполнить его (раздел 8).

## 8. Обработка по поручению организаций

Данные сотрудников, водителей и контрагентов организации Оператор обрабатывает только по её поручению ([processing-agreement-draft.md](processing-agreement-draft.md)), не использует для своих целей, не передаёт третьим лицам, кроме субподрядчиков из перечня в поручении (облако, почтовая доставка).

## 9. Передача третьим лицам

Субподрядчики Оператора (хостинг и объектное хранилище в РФ, провайдер доставки писем, позже провайдер SMS/мессенджеров) получают данные на основании договора с условиями защиты. Трансграничная передача не планируется. `[Перечень с реквизитами заполняется после выбора провайдера, W3.00, D-31.]`

## 10. Cookie

Только необходимые: сессия `ortus_sid` и защитный токен (CSRF). Аналитика и реклама не используются. `[Юрист: нужен ли баннер при необходимых cookie.]`
