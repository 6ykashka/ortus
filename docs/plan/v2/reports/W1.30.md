- **Экрана «Структура» (`company-structure`, S1-08) в main нет** (Q-W1.23-16: в `screens.yaml` он у W1.23, но в задаче W1.23 его не было). Поэтому часть критерия «владелец **сам** настраивает структуру» в интерфейсе не выполнима. В J-1 регион, фирма и подразделение создаются командами `createOrgUnit` из браузерной сессии владельца: те же cookie, CSRF и `Idempotency-Key`. Роль, приглашение, принятие, меню и отзыв проходят через интерфейс. Нужен WS экрана «Структура» (и `company-people-import`, S1-10); после него шаг J-1 переводится на экран.
- **AC-10 «выдача файла 403» на стенде этапа 1 сквозь стек не проверить.** Виды родителей файлов — только объекты логистики (`files.FleetParents()`, tenant 0002), а данных логистики в Go-сиде нет (W2.02+). Без родителя загрузить файл нельзя. Строка A-4 проверяет повторную проверку права на каждой выдаче: после отзыва роли каждая следующая выдача — 403. Выдача файла после отзыва закрыта integration `TestAC10DownloadAfterRevoke` (W1.09). Сквозная строка с файлом — W2.x, когда в сиде появятся рейсы. Экспорт — этап 4 (П-8).
- Job `e2e-stand` на GitHub с новыми строками не запускалась: ветка не запушена, вливает интегратор.
