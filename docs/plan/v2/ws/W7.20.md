# W7.20 Табличный движок документов (P1d docs-sheet)

Этап 7 · опережающая дорожка Д · шаг 7.2 · размер M · вид `domain`, страниц и backend нет.
Зависит от: W0.11 (ядро домена v2; движок чистый и ядра не использует). Блокирует: W7.22 (маршрут документа), W7.23/W7.24 (страницы «Таблицы»).

## 1. Цель

Перенести табличный движок документов из прототипа 19.10 (`design/ortus/documents.js:237–402`, docs/24, B §3.3 блок H, §5.3 P1d) в `@ortus/domain`: ссылки и диапазоны, лексер, парсер, вычисление листа с 20 функциями RU/EN, форматирование, сетка просмотра, импорт CSV.

## 2. Границы файлов

Пишу только в `frontend/packages/domain/src/modules/docs/sheet/**`, этот бриф и `docs/plan/v2/reports/W7.20.md`.
Не трогаю: `modules/index.ts`, `seed/compose.ts`, `package.json`, `src/core/**`, `design/`. Подключение движка в баррель — строка у интегратора (integratorNotes отчёта). Сид `fuelSheets()` и данные документов — W7.21 (docs-core).

## 3. Входы

- `design/ortus/documents.js` (тег `design-2026-10-19`), строки 237–402; только чтение.
- `docs/plan/v2/analysis/B-domain-modules.md` §3.3 (блок H, примеры и риски), §5.3.

## 4. Контракты

Чистые функции без состояния, часов, случайных чисел и БД: `colName`, `parseKey`, `keyOf`, `rangeKeys`, `inRange`, `FN_LIST`, `FN_SIG`, `upperOut`, `lex`, `parse`, `parseFormula`, `checkFormula`, `sheetCompute`, `valErr`, `fmtVal`, `rawOf`, `gridOf`, `csvCells`. Ошибки вычисления — `{err:'#ДЕЛ/0!' | '#ЗНАЧ!' | '#ИМЯ?' | '#ЦИКЛ!'}`; ошибки разбора — `Error` с текстом эталона. OpenAPI не затрагивается.

## 5. Экраны

Нет (вид `domain`).

## 6. Тесты, которые пишутся первыми

Табличные Vitest-тесты рядом с кодом: `refs.test.ts`, `syntax.test.ts`, `eval.test.ts`, `format.test.ts`, `index.test.ts` (экспорт-лист) и `parity.test.ts` (сверка с эталоном 19.10: корпус формул, 600 случайных выражений, форматы × значения, сетка, сид «Расход топлива»).

## 7. Шаги TDD

Единицы по порядку, на каждую `test(w7.20)` (красный, на заглушке) и `feat(w7.20)` (зелёный): ссылки и список функций → лексер и парсер → вычисление → форматирование, сетка, CSV → публичный вход; паритет.

## 8. Проверка

`corepack pnpm --filter @ortus/domain exec vitest run --coverage` (порог 90 % на `src/modules/**`), `corepack pnpm run lint`, `typecheck`, `test`. Go и Docker не затрагиваются.

Все функции блока H перенесены; тексты ошибок дословно; паритет с эталоном зелёный; покрытие ≥ 90 %; lint, typecheck, test зелёные; отчёт по `orchestration.md` §5.
