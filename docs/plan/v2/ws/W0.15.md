## 1. Цель

После W0.15 в `main` есть работающий в CI скелет набора изоляции (`15-quality-security.md` «Isolation suite»):

1. **Фикстуры** «два тенанта, две фирмы, пользователь с двумя ролями, водитель» — на testcontainers и миграциях W0.06: control DB и две tenant DB, данные пишутся SQL под `ortus_migrator`, API читает под `ortus_api`.
2. **Формат строки матрицы** `backend/test/isolation/<module>.yaml`: эндпоинт × актор × объект → ожидаемый статус, плюс идентификаторы, которых в ответе быть не должно.
3. **Генератор** `isogen`: YAML → `backend/test/isolation/<module>_test.go` (тег `isolation`), проверка дрейфа в обычном `go test ./...`.
4. **Раннер** строк: запрос через `http.Handler` цели, проверка статуса, Problem Details, утечки идентификаторов и «чужой ID = несуществующий ID» для 404 (AC-01).
5. **Пример строк** для `GET /api/v1/me/context` — `pending: W0.09`: без хендлера принимается 501 или ответ шлюза, совпавший со строкой; с тегом `isolation_pending` строки проверяют настоящие ожидания и **красные** до W0.09.
6. **Запуск:** `corepack pnpm run test:isolation` = `go -C backend test -tags isolation -count=1 ./test/isolation/...` — та же команда, что у job `isolation` в CI (W0.04, `tools/ci/pipeline.mjs`: шаг включается сам при появлении Go-файлов в `backend/test/isolation`).

## 4. Контракты (публикуются)

### 4.1 Формат `isolation/<module>.yaml`

```yaml
module: me                      # = имя файла; [a-z][a-z0-9]*(_[a-z0-9]+)*; не main/target/fixtures/suite
endpoints:
  - op: getMyContext            # operationId из OpenAPI; уникален в файле
    method: GET                 # GET | POST | PUT | PATCH | DELETE
    path: /api/v1/me/context    # /api/v1/…; {param} → ссылка на фикстуру в rows[].params
    channel: http               # http (пока единственный); data, export, search, files, notifications, realtime, audit — по мере появления
    pending: W0.09              # необязательно: хендлера ещё нет → 501 или ответ шлюза, совпавший со строкой
    rows:
      - actor: b.owner          # ключ актора фикстур или anonymous
        params: {}              # имя параметра пути → ссылка вида <вид>:<ключ>
        status: 200             # 200 201 204 401 403 404 409
        present: [tenant:b]     # идентификаторы, которые обязаны быть в теле
        absent: [tenant:a]      # идентификаторы, которых в теле быть не должно
        note: …                 # необязательно
```

Проверки генератора (ошибка — ненулевой код и путь `файл: endpoints[i].rows[j]: …`): неизвестные поля, модуль ≠ имени файла, повтор `op`, недопустимые метод, канал, статус, `pending`; параметр пути без значения или лишний; неизвестный актор или ссылка; повтор строки (актор + параметры); у эндпоинта нет ни одной негативной строки (статус 401/403/404 или непустой `absent`).

### 4.2 Ссылки на фикстуры

`tenant:a|b`, `unit:<t>.<unit>`, `role:<t>.<role>`, `group:<t>.<group>`, `account:<actor>`, `person:<actor>@<t>`, `membership:<actor>@<t>`. Идентификаторы — UUID v5 (`NameSpaceURL`, имя `ortus:isolation:<вид>:<ключ>`), стабильные между прогонами.

### 4.4 Цель набора (`matrix.Target`)

```go
type Target struct {
	Handler      http.Handler                                  // API целиком (cmd/api), запросы через httptest
	Authenticate func(r *http.Request, a fixtures.Actor) error // dev-сессия актора (W0.09)
}
type Env struct {
	World  *fixtures.World
	Clock  func() time.Time    // test.Now: фиксированное «сейчас»
	Getenv func(string) string // CONTROL_DB_URL, TENANT_DB_URL (роль ortus_api), MIGRATOR_DB_URL, APP_ENV=test, AUTH_PROVIDER=dev
}
```

До W0.09 `target_test.go` (`@stub Owner: W0.09`) возвращает `matrix.NotImplemented()`: любой запрос → 501 `application/problem+json`, `code: not_implemented`.

Правило `pending`-строки (`Suite.checkPending`, без строгого режима):

| Ответ цели | Итог |
|---|---|
| 501 | проходит (обработчика нет) |
| совпал с ожиданиями строки: статус, Problem, `present`/`absent`, AC-01 | проходит. Обычно это ответ шлюза W0.09 до хендлера: аноним → 401, чужой тенант → 404, нет права → 403 |
| 2xx на положительную строку (ожидается 2xx) | падает с подсказкой «хендлер есть — снять `pending: <WS>` и `go generate`» |
| любой другой | падает: нарушения строки с пометкой `pending <WS>` (без подсказки снять `pending`) |
