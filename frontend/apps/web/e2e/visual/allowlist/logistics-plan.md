# Allowlist `logistics-plan` (W2.20)

Формы «Планирование рейса» нет в прототипе (B-6, `docs/plan/v2/design-requests.md` `logistics-plan`, S2-13): в
эталоне рейсы Р-208 и Р-211 — данные сида. Пиксельной и структурной сверки нет; e2e (`e2e/logistics-plan.spec.ts`)
обязательны. Форма — состояние страницы `fleet` (`/t/:tenantId/fleet?plan=new`, ADR-0001), отдельного `PageKey` и
пункта меню нет. Подписи без эталона — `routes/logistics/manager/plan/texts.ts`; «Погрузка», «Выгрузка», «Объём»,
«Масса», «Водитель», «Груз» — слова эталона (`fleetVM` :3274–3287).
