## 4. Контракты

Контракт API не меняется. Публикуются:

- формат раздела «Вопросы исполнителей этапа 0»: колонки `ID | Вопрос | По умолчанию до решения | Где действует | Подтверждает | Вид`, `Вид ∈ {продукт, технический}`. Раздел стоит в блоке `renumber:off`, потому что в нём встречаются номера комплекта (например, D-23 комплекта).
