# W7.26 Маршрут, подпись, ознакомление (страница `docs-route`)

Этап 7 · дорожка Ф · шаг 7.2 · размер M · слот 1 (Vite 5201, Storybook 7201, API 8101, эталон 4101, `ortus-s1`) · вид `frontend`.
Зависит от: W7.00 (контракт `0.12.0-stage7`: тег Docs, экран `docs-route`, MSW Docs в `adapter/msw/docs`). Backend маршрута — W7.24 (ещё не в main), поэтому страница живёт на MSW; режим stand — `test.fixme` с причиной.

## 1. Цель

Блок «Маршрут документа» (экран `docs-route`, эталон `Документы.dc.html` design-2026-10-19, разбор `analysis/dor/documents.md` §1.8, §1.9: полоса маршрута, «На согласование», «Утвердить · ПЭП», ознакомление):

- **полоса маршрута** (`getDocRoute`): заголовок «Маршрут · vN» / «Маршрут завершён · vN», чипы шагов «N · Согласовать / Утвердить / Ознакомить / Подпись заказчика» с подписями, строка «Шаг N «…» · до ДД.ММ. Ждут: …», ссылка на задачу, возврат («X вернул(а) vN на доработку: «…»», «Отправить снова»), моё решение (комментарий, «Согласовать vN», «Утвердить · ПЭП», «Вернуть на доработку», `decideDocRoute`), ознакомление («Ознакомлен» на компьютере, липкая кнопка 54 px на телефоне после «Прочитано до конца», `ackDocument`), «Завершить ознакомление · N из M» (`closeDocAck`), «Отменить маршрут» (`cancelDocRoute`), «Лист согласования · vN» с «Открыть PDF/A-копию»;
- **«На согласование»** (`startDocRoute`, `listDocRouteTemplates`): модалка с шагами (срок, порядок «Все сразу / По очереди / Достаточно одного», участники, аудитория ознакомления, подпись заказчика при связи с объектом), правилами, «Что произойдёт» (`dryRun`), черновиком листа согласования, ошибками формы дословно, «Сохранить маршрут как шаблон папки»;
- **«Утвердить · ПЭП»** (`requestDocSignCode`, `confirmDocSign`): подтверждение повторным входом в Ортус (ADR/Q-W4.00-documents-2), попытки, ошибки `sign_code_invalid`, `rate_limited`, `dependency_unavailable`;
- состояния: загрузка, ошибка, нет связи, нет маршрута, нет доступа.

Как подключается: компонент `DocRoutePanel` (`routes/docs/route/`) встраивает карточка документа W7.25; для самостоятельной проверки страница `docs` (`?doc=<id>`) — заглушка `@stub Owner: W7.25`, которую владелец заменяет файлом целиком и вставляет `DocRoutePanel` в карточку (одна строка у интегратора).

## 5. Решения по умолчанию (в отчёте — Q-W7.26-N)

| # | Вопрос | По умолчанию |
|---|---|---|
| 1 | Эталон подписывает кодом из SMS; контракт: утверждающий подтверждает повторным входом (`pep_login`), SMS — только заказчику (D-31, порт без провайдера) | Диалог «Утвердить · ПЭП» просит пароль (и код приложения, если у участника он включён); подписи эталона сохранены, текст про SMS заменён |
| 2 | Кнопки «Демо: согласовать за …», «Демо: заказчик подписал по SMS» — только прототип | Не переносятся: контракта нет, заказчик подписывает по ссылке |
| 3 | Проект задачи | Не выбирается: сервер берёт системный «ДОК · Документы · маршруты» (Q-W4.00-documents-18); в «Что произойдёт» это указано |
| 4 | Кто «автор» для «Отменить маршрут», «Завершить ознакомление» | Запустивший маршрут или `my.can.manage`; окончательно решает сервер (403) |
| 5 | «Сохранить маршрут как шаблон папки» | Флажок виден только с `docs.templates.manage` (Q-W4.00-documents расхождение §3.1) |
| 6 | Подпись заказчика | Шаг доступен, только если у документа есть связь с объектом; имя и телефон заказчика вводятся в шаге |
