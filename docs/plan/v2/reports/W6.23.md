## Решения по умолчанию (Q-W6.23-N)

1. В API нет базовых длительностей/пауз по этапам: «Базовый план» — линия «по договору» от `baseline.dueOn` и расчёт без сдвигов; шапка — по `forecastDueOn`/`delayWd` сервера.
2. Нет принятой доли объёма и заявки снабжения: полоса идущего этапа без деления; «Материала нет» — из `issues` сервера.
3. «Сегодня» — часы браузера (Москва).
4. Перетаскивание — мышью при ширине ≥ 640; на телефоне — кнопки ±.
5. В контракте нет признака вехи: веха — последний этап без последователей.
6. Пауза правится только у связи, определяющей начало этапа (сервер применяет `lagDays` к `bind`).
7. Форма «Новый базовый план» и пустой график — без эталона.
8. Имя заказчика в «Уведомим…» не склоняется («заказчика — меняется дата сдачи»).
