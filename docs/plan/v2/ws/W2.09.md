## 1. Цель

1. **Пакет `modules/home`** — реестр источников «Требует решения» (план v2 §3.5: модули регистрируют провайдеры) и сервис операции `getMyDecisionQueue` (`GET /api/v1/me/decisions?tenantId=…&limit=…`, `x-scope: identity`):
   - `tenantId` — активное членство личности, иначе 404 `not_found` (как входящие W1.10; приостановленная организация — тоже 404, как MSW);
   - `limit` 1…50, по умолчанию 8; вне диапазона — 400 `malformed_request` (как MSW);
   - источник модуля спрашивается, только когда модуль установлен и не отключён (`active`, `read_only`, `draining`); ядро (модуль без ключа) — всегда; источник сам проверяет право и область участника (PD-53);
   - сортировка по тону (`danger → warn → info → neutral`), затем по порядку регистрации источников и порядку карточек внутри источника; `total` — до `limit`; `generatedAt` — часы приложения.
2. **Источник логистики `modules/home/fleet`** (карточка: блокирующие дефекты, смены на приёмке):
   - `fleet.blocking_defect` (danger) — дефекты `in_review` с рейсом, область `fleet.inspections.review` над подразделением машины; `params`: `tripNumber`, `zone`, `description`, `driverName`; `object` — рейс; `occurredAt` — время отчёта;
   - `fleet.trip_review` (warn) — рейсы `submitted`, область `fleet.trips.review` над подразделением рейса; `params`: `tripNumber`, `driverName`; `occurredAt` — `returned_at`;
   - `fleet.trip_without_driver` (info) — рейсы `planned` без водителя при модуле `active`, область `fleet.routes.manage`; `params`: `tripNumber`, `title`, `cargo`, `startsAt` (+ `poolRequest`, `poolHome` при запросе пула `requested`), как MSW W2.00.
3. **Подключение в `cmd/api`** отдельным файлом `cmd/api/home.go` (+ тест): реестр с источником логистики, состояния модулей из `modulesreg.Service`, справочник членств; в `main.go` — одна строка `Home: …`.
4. **Строки изоляции** — `backend/test/isolation/home.yaml` (`pending: W2.09` до хендлера, затем снять).
