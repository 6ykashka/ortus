# W2.92 · «Моя смена» временного водителя до окна без предложенных машин (Q-W2.75-1)

Этап 2 · вид frontend · слот 2 (Vite 5202, Storybook 7202, API `127.0.0.1:8102`, эталон 4102, compose `ortus-s2`). Вне реестра §4: постановка интегратора 26.10. Решение владельца D-35 (`design/docs/29-temporary-driver-vehicle.md`, макеты 1a–1g), DoR `docs/plan/v2/analysis/dor/s2-20-temporary-driver-vehicle.md`.

## 1. Дефект

До окна рейса временный водитель без предложенных машин получает от `listVehicles` 403 `forbidden_action` (узкая роль, строк машин нет). «Моя смена» показывает «Не удалось загрузить машины: …» вместо «Машину ещё не поставили» (1c, 1g). Журни W2.75 `temporary-driver-vehicle.spec.ts` держит строку в `test.fixme` + `@known-defect`; после «Поставить машину» экран водителя на стенде не проверяется.

## 2. Решение по умолчанию

Фронт: на рейсе чужой фирмы (временный водитель) отказ `forbidden_action` списка машин — не ошибка, а пустой список: «Моя смена» и «Автомобили» показывают «Машину ещё не поставили». Любая другая ошибка и 403 у обычного водителя остаются ошибкой. Backend (`listVehicles`) не меняется — вариант «пустой список вместо 403» не выбран: он ослабил бы единое правило отказа без строк (Q-W2.92-1 для интегратора).
