## 10. Риски и решения по умолчанию

- Docker общий: перед стендом `docker version`, один свой compose `ortus-s2`, сразу `down -v`.
- `pnpm -r run test` запускает пакеты параллельно, и каждый Vitest берёт воркеры на все ядра: переподписка CPU — главная причина тайм-аутов. Корневой `package.json` не мой: число воркеров ограничивается в конфигах пакетов только при подтверждённой пользе, иначе — предложение в `integratorNotes`.
