## 5. Матрица и сценарии

Проекты (`devices-*`): два Android (Chrome: текущая и предыдущая ОС), два iPhone (Safari: текущая и предыдущая iOS, ширина 390), масштаб 200 %. На каждом телефоне:

1. профиль устройства: viewport, касание, `pointer: coarse`, геолокация не запрошена и не выдана;
2. камера: `input[type=file]` с `accept="image/*"` и `capture="environment"`; кадр камеры 4032×3024 с геоданными → PUT — JPEG ≤ 1600 px без геоданных; пять ракурсов — «Фото · 5 из 5»;
3. сбой загрузки → «Ошибка загрузки», тост «Загрузка прервалась. Повторите попытку.», «Повторить» → загружено;
4. офлайн: фото «На устройстве · ждёт связи», выезд недоступен, расход «Сохранить на устройстве», баннер «(ожидают отправки: 1)»; связь → «Связь восстановлена.», «— принято сервером»;
5. медленная сеть (задержка ответов API, медленный PUT хранилища, троттлинг Chromium): «Загрузка N%», путь до выезда проходит, повторное нажатие не шлёт вторую команду;
6. путь водителя целиком: бронь → осмотр → выезд → расход → «Завершить рейс» → сдача → «Ожидает приёмки менеджером»;
7. установка PWA: манифест `standalone`, иконки 192/512, `apple-touch-icon`, `theme-color`.

Масштаб 200 %: путь водителя без горизонтальной прокрутки, команды панели действия видимы и нажимаются, axe без serious/critical.

## 10. Риски и решения по умолчанию

- WebKit в CI не ставится (`e2e:install` — только Chromium, W0.05): по умолчанию iPhone-проекты — Chromium с профилем iPhone (viewport, DPR 3, UA, касание); настоящий Safari — полевой тест и `E2E_DEVICES_WEBKIT=1` (вопрос интегратору: ставить ли WebKit в CI).
- Fake media есть только в Chromium: камера на WebKit — кадр холста. Приложение снимает через `input capture` (не `getUserMedia`), поэтому кадр всё равно отдаётся выбором файла.
- В режиме `mock` ответы API даёт service worker MSW — троттлинг сети браузера их не замедляет; медленная сеть = глобальная задержка сценария + медленный PUT хранилища + троттлинг Chromium для загрузки модулей.
- Масштаб 200 % эмулируется как масштаб браузера: CSS-ширина вдвое меньше при DPR 2.
- Время прогона CI растёт на 5 проектов — набор устройств компактный (один путь на пункт).
