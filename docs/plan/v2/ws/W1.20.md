Этап 1 · подволна 1a · дорожка Ф · шаг плана 27: 1.10 · истории S1-27…S1-30 · размер L · слот 4 (Vite 5204, Storybook 7204, API 8104, свой эталон 4104, compose `ortus-s4`).
Зависит от: W0.10 (`@ortus/tokens`, `@ortus/ui`), W0.13 (MSW-сценарный сервер, режим `mock`), W0.14 (`@ortus/texts`); каркас `apps/web` — W0.09.
Блокирует: W1.22 (вход, панель входящих в слоте шапки), W1.23, W1.24, W1.25 (страницы встают в слот оболочки), W2.2x.

## 1. Цель

После W1.20 приложение `frontend/apps/web` в режимах `mock` (MSW W0.13) и `stand` (cmd/api W0.09) открывается по URL-схеме ADR-0001 и показывает оболочку эталона `design-stage-1` («Ортус CRM.dc.html» `:94–203`, `:2165–2174`, `:2274–2291`; анализ `01-shell.md` §4, §9–§13, §16):

- **шапка**: знак и короткое имя, «пространство бизнеса» / «управление платформой», организация, область (текст или `select` «Область просмотра» у владельца), пилюля «Нет связи», кнопка «Уведомления[: N новых]» со слотом панели W1.22, кнопка «Профиль» с поповером; тёмная шапка оператора;
- **переключатель бизнеса** (S1-07, `no-reference` — B-6): при нескольких организациях название организации — кнопка со списком в порядке `Intl.Collator('ru')` (Q-W0.09-10); выбор вызывает `selectTenant`, инвалидирует `/me/context` и переводит на стартовую страницу выбранной организации;
- **меню из `/me/context`** по манифестам модулей `packages/domain/src/nav/modules/<m>.ts` и генерируемому реестру: правило D-23 (подключённый модуль — своя группа, отключённый с историей — пункт в «Отключены · только чтение», не подключавшийся — нет), механизм бейджей, рабочие места сотрудников (водитель, массажист, прораб);
- **AccessGate**: модуль не подключён, модуль отключён, нет права, вне области, только чтение (страница рендерится с признаком `readOnly` и баннером);
- **адаптив** 390 / 768 / 1440: нижняя навигация и лист «Все разделы» < 640, рейл 68 px 640–1079, боковая панель 244 px ≥ 1080; один DOM, переключение CSS;
- **глобальные состояния**: загрузка (скелетон), ошибка загрузки, нет входа, офлайн (пилюля, баннер, тост), баннеры организации (пробный период завершён, модуль отключён, место заполнено);
- **хук команд** `useRun()` — `run(key, fn, okText?, {quiet})` с «тихими» кодами (A §2): тост успеха только после ответа сервера, ошибки — текстом `@ortus/texts` по `Problem.code`, `offline` — тоном warn, коды из `quiet` не тостятся и пробрасываются вызывающему.

Демо-панель, «Путь проверки», кнопки «Демо: …» и `DemoOnly` **не переносятся** (PD-54): персонаж в e2e — dev-вход `?persona=`.
