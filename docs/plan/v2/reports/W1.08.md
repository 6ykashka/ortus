## Сделано

- **`backend/internal/modules/modulesreg`** — реестр модулей организации:
  - доверенные манифесты `fleet`, `spa`, `repairs` из каталога прав (имя модуля, `depends_on`, права в порядке каталога с подписью, видами областей контракта и чувствительностью) = пример `setModuleInstallation/ok` (manifestDto MSW W0.13). Таблица каталога — текстом (`catalog_data.go`), сверка с `api/permissions.yaml` — `cmd/api/modules_catalog_test.go` (модулям depguard запрещает YAML). Ядро (`tasks`, `forms`, `calendar`, `knowledge`, `files`, `data`, `inventory`, `cash`) подключено всегда. Ключ `module_key` — ключ контракта, синонимы каталога `logistics`, `repair` читаются (фикстуры W1.04);
  - `Availability` — `TenantContext.modules` как `moduleAvailability` генератора W0.07 и MSW: `available` / `permission_denied` / `not_installed`, организация `read_only` или `grace` → `plan_expired`, модуль `read_only` → `disabled` (меню «Отключены · только чтение», D-23), `draining` → `finish_only`, `disabled` → `none`;
  - `Service`: каталог, установка с `If-Match` (ETag `"rev-N"`, принимается и `"N"`), отключение — `draining`, если провайдер активности видит начатые процессы, иначе сразу `read_only` (`history_read`) или `disabled` (`owner_export`); ядро — 422, неизвестный модуль — 404; повтор желаемого состояния — без записи. `draining` завершается сам: чтение состояния (каталог, гейт, `/me/context`) переводит модуль в итог, когда начатых процессов не осталось (от имени сервиса, с аудитом, гонка двух реплик — `ErrConflict` и перечитывание);
  - предпросмотр отключения: начатые рейсы логистики (`on_route`, `returning`, `submitted`, `rework` — `finish_allowed`; `assigned`, `inspection`, `defect_review` — `closed`), не больше 50 + `hiddenCount`; пустой список — «Активных процессов нет». Провайдеры — явный реестр (`NewRegistry`, `DefaultRegistry`, `FleetTrips`), без `init()`;
  - настройки модулей (`getModuleSettings`, `updateModuleSettings`): `fleet`, `spa` (подключённые), `forms`, `tasks` (ядро); значения по умолчанию — как MSW; документ целиком, проверка типа, обязательных полей, диапазонов, зоны IANA, `moduleKey` = путь;
  - `Gate` — гейт модуля шлюза: теги `Fleet`, `Earnings` → `fleet`, `Spa` → `spa`, `Repairs` → `repairs`; не подключён или `disabled` → 403 `module_not_installed`; `read_only` → изменения 403 `module_read_only`; `draining` → открыты чтение и завершение начатой работы (`returnTrip`, `createTripExpense`, `reviewTrip`, `reviewTripExpense`, `setTripEarnings`, `releaseReservation`, `completeAppointment`, `recordAppointmentPerformance`);
  - `Server` — strict server тега Modules (6 операций); `PGStore` — `modules.installations`, `access.policy_state.policy_version + 1` при смене состояния, `audit.events` (`modules.module.enable|disable|drained`, `modules.settings.update`) в одной транзакции.
- **`backend/internal/control/subscriptions`** — подписка организации в control DB:
  - одна строка `subscriptions` на организацию (`trial|active|grace|ended` ↔ `trialing|active|grace|read_only`, конец периода — `upper(period)`); права — `entitlements`, каждое изменение пишет полный набор новой версией, ревизия = наибольшая `entitlements.version`; ручное право скрывает право тарифа того же ключа (unique `(tenant_id, feature_key, version)`);
  - организация без строки — производный trial 14 дней от `tenants.state_changed_at`, тариф заявки `tenant.create` (иначе `start`), права пробного тарифа как `createPlatformTenant` MSW (места по тарифу, 100 ГиБ);
  - `Update` оператора: `If-Match`, причина 5–500, `past_due`/`cancelled`/`cancelAtPeriodEnd` → 422 (D-33), ручные права только `manual` со сроком и основанием; `tenants.state` следует подписке (`TenantStateFor`), кроме `suspended`, `provisioning`, `closing`, `closed`; `platform_audit` `subscription.updated` (оператор, причина, `fromStatus`/`toStatus`);
  - жизненный цикл (PLAT-05): trial или оплаченный период кончился → `grace` на 7 дней → `read_only`; `Advance` (все шаги, накопившиеся к «сейчас», за один проход, `for update skip locked`), `platform_audit` от системы (`subscription.trial_ended|period_ended|grace_ended`); `Run` — фоновый цикл по тикам.
  - **`subshttp`**: `PlatformServer` (встраивает реестр W1.02, переопределяет `getPlatformSubscription`, `updatePlatformSubscription`), `BillingServer` (`getTenantSubscription`; операции места — 501 до W1.09, база подставляется конструктором; `requestSubscriptionChange` — 501, W4.60 по D-33). ## Осталось fixme / открытые вопросы

`fixme` и `t.Skip` нет. Решения по умолчанию, по которым сделано (вынести в `docs/plan/decisions.md`, раздел исполнителей этапа 1 — файл не мой; дублируются в `decisionsNeeded`):

1. **Схема подписки (технический, стюарду).** control 0001 не хранит ревизию, `cancelAtPeriodEnd`, отдельные `past_due`/`cancelled`, конец grace и конец периода одновременно. По умолчанию: одна строка `subscriptions` на организацию, ревизия = наибольшая `entitlements.version`, `past_due`/`cancelled`/`cancelAtPeriodEnd=true` → 422 (D-33). Предложение: control-миграция (резерв 0006+) — `subscriptions.revision`, `status` по контракту, `grace_ends_at`, `cancel_at_period_end`, уникальность «одна текущая подписка».
2. **Ручное право скрывает право тарифа того же ключа** (unique `(tenant_id, feature_key, version)`): в ответе одно значение на ключ, MSW показывает оба. Вернуть оба — та же миграция (версия набора отдельно от версии права).
3. **grace — только чтение** (как шлюз W0.09 и MSW: `tenant_read_only`). По 02-architecture §11 в grace работа продолжается — вопрос владельцу продукта; переключение — одна строка `tenantctx.Resolve` (W1.02).
4. **Конец trial → grace 7 дней → read_only** (PLAT-05). Прототип ставит «Ограничен» сразу; в интерфейсе неотличимо (grace тоже только чтение, баннер — по `tenantState.status`).
5. **Trial без строки подписки**: 14 дней от `tenants.state_changed_at`, тариф — `planKey` заявки `tenant.create`, иначе `start`; квота 100 ГиБ, места по тарифу (как MSW; design §11 — 5 ГиБ, гипотеза). Строка пишется первым изменением (оператор или жизненный цикл).
6. **`requestSubscriptionChange` — 501 до W4.60** (D-33); положительная строка владельца в `authz.yaml` снята (тег Billing смонтирован, без `If-Match`/`Idempotency-Key` строгий сервер отвечает 400 до хендлера), `pending: W4.60`.
7. **Гейт модуля стоит до проверки права** (как MSW `authorize`): не подключённый модуль даёт 403 `module_not_installed` и участнику без права.
8. **Завершающие операции в draining** — список `modulesreg.finishOnly`; что объект — начатый процесс, проверяет хендлер модуля (W2.05, W5.20).
9. **Ключ `module_key`** — ключ контракта (`fleet`, `spa`, `repairs`); синонимы каталога читаются. `authz.installKeys` (W1.04) уже понимает оба — комментарий «until W1.08 fixes one» можно заменить на «ключ контракта; logistics — синоним фикстур».
10. **ETag** — `"rev-N"` (MSW); `If-Match` принимает и `"N"` (как `platformhttp` W1.02, у него ETag `"N"` — расхождение форматов между тегами, вопрос стюарду).
11. **Жизненный цикл в фоне `cmd/api`**: `SUBSCRIPTION_SWEEP_INTERVAL` (Go duration, `0` — выключен); по умолчанию 1m в `prod`, выключен в dev/e2e: стенд держит состояние сида 01.10.2026 (trial «Альты» кончается 13.10, по часам машины — уже прошёл). Часы — `APP_FIXED_NOW` вне prod.
12. **`storageWriteStatus`** читается из `files.usage` (W1.09 — владелец места); нет строки — `allowed`.
13. **Сид «Карго Сити»**: MSW `past_due` хранится как `grace` без срока (не кончается сама; решение 3 W1.00 — «Снять ограничение» возвращает grace).
