  - плагин Vite `pwa()` (`plugin.ts`): теги index.html (манифест, theme-color, apple-touch-icon, значок вкладки), маршруты dev-сервера, при сборке — манифест, иконки и `dist/sw.js` со списком предкэша (все файлы сборки без карт исходников);
  - регистрация (`register.ts`) — только production-сборка без MSW (в mock область «/» у `/mockServiceWorker.js`);
  - хранилище устройства (`store.ts`): IndexedDB `ortus-device` (иначе память), ключи `<вид>:<организация>:<пользователь>`, `clearDeviceData(userId)` при выходе, `navigator.storage.persist()`;
  - статус очереди для оболочки (`status.ts`): число ожидающих и «идёт отправка» по организации.
- **Очередь отправки** (`routes/logistics/driver/outbox/`):
  - `queue.ts` — элементы «расход» и «сдача» (одна на рейс, новая заменяет прежнюю), статусы `local` (ожидает) / `sending` (отправляется) / `error` (ошибка с текстом сервера), отправлено — элемент снят, событие `sent`; отправка по порядку, одна за раз; сбой сети — снова «ожидает» без тоста; ошибка сервера — тост «{операция}: {сообщение}»; «Повторить» и повтор при появлении связи — **тот же Idempotency-Key** (расход — ключ элемента, сдача — ключи осмотра и сдачи; принятый осмотр повторно не отправляется); фото элементов — Blob на устройстве, загружаются перед командой; переживает перезапуск;
  - `drafts.ts` — черновик осмотра и его фото на устройстве: восстановление после перезапуска (готовые фото — «Загружено», не дошедшие — «На устройстве · ждёт связи»), черновики других шагов и старше 7 дней удаляются;
  - `hooks.ts` — очередь области устройства (одна на приложение, отправка на событие `online` и без открытой страницы), тосты «{операция} — принято сервером», `useDeviceDraft`;
  - `parts.tsx` — карточка «Сдача сохранена на устройстве» (чип «Ожидает отправки» / «Отправляется…» / «Ошибка отправки: …», «Повторить»), строка расхода «Локальный черновик» с чипом «На устройстве» / «Отправляется» / «Ошибка».
