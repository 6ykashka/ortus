# Архитектурные решения (ADR)

Решения проекта «Ортус CRM». Новый ADR — копия [TEMPLATE.md](TEMPLATE.md) с номером, следующим за последним, файл `NNNN-<slug>.md` (slug латиницей через дефис). Пока решение не принято людьми, у него статус «предложено», а агенты работают по рекомендации из раздела «Решение» (план v2 §2). Принятое решение меняет статус на «принято» и строку в `docs/plan/decisions.md`; пересмотр — новым ADR со статусом «заменено NNNN» у старого.

Номер ADR не совпадает с номером решения: ADR-0001 — URL-схема (решение плана PD-25), ADR-0002…0013 — решения комплекта D-01…D-12 (номер ADR = номер D + 1), ADR-0014 — области оценщика (F8, PD-53; W0.08), ADR-0015 — канал реального времени (PD-58; W1.00).
