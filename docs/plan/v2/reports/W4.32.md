## Осталось fixme / открытые вопросы

`fixme`: две строки `@stand` — до W4.31. Вопросы (значения по умолчанию — как сделано; внести в `docs/plan/decisions.md` — файл интегратора):

1. **Q-W4.32-1 · «Обновлено» карточки (технический, MSW W4.04).** У страниц с одной датой MSW `spaceDto.lastUpdate` берёт страницу по названию («Журнал осмотров машин»), эталон — первую по порядку сида («Регламент приёмки смены»).
