## 3. Что делаю

1. **Публикация и каталог.** `usualVehicleId` — активная машина домашней фирмы, видимая публикующему (иначе один 422 `usualVehicleId`/`vehicle`); каталог `?tripId=` — `usualVehicle` с `fit` (LOG-05: масса, объём, длина, температура) и `freeForWindow`; невидимый рейс — 404.
2. **Запрос с машиной.** `vehicle { mode, hostVehicleId }`: порядок проверок контракта (422 `tripId`, `vehicle.hostVehicleId`, `vehicle.mode`/`usual_vehicle`; 404 «Машина не найдена.»; 409 `vehicle_incompatible` с причинами, `reservation_overlap`). Броней до одобрения нет.
3. **Решение.** `reject` без причины — 422 `comment` до остальных проверок; `approve_driver_only` — только при запрошенной обычной машине (иначе 422 `decision`/`usual_vehicle`). Одобрение одной транзакцией: назначение, grant, брони предложения (`offer_group_id`, `offered_to`, `offer_kind`): две машины — `hold` до `choose_until` = начало окна − 30 мин; одна — сразу `confirmed`, рейс `assigned` с машиной; «Только водителя» при `home` — броней нет. Перепроверка комплекта под блокировками машин — 409 целиком (Q-W2.70-11). Одобрение после срока — только машина фирмы рейса (Q-W2.71-5). События `fleet.reservation.held|confirmed.v1` с `offerGroupId`, уведомление водителю.
4. **Доступ до окна (Q-W2.71-3).** С одобрения S2-20: назначение роли в области self — с момента одобрения; строки области resource — на каждую предложенную машину. Надстройка пула до окна открывает только рейс, его брони и выбор (`AccessPrepare`); остальное — с окна, как W2.57.
5. **`chooseReservation`.** Права `choose` (self: бронь предложена актору, рейс его) или `manage` над фирмой рейса; порядок 403 → 404 «Бронь не найдена.» → 409 `offer_closed`. Под блокировкой рейса, машин и группы: `hold → confirmed`, остальные — `released` (`chosen` / `manager`), рейс получает машину; закрываются строки resource снятых машин; идемпотентно (Idempotency-Key); конкурентно — ровно одна подтверждённая (тест `-tags concurrency`). До выбора `startTrip` и осмотр выезда по брони предложения — 409 «Сначала выберите машину.»; подтверждённая бронь осматривается сразу: осмотр выезда переводит `assigned → inspection`.
6. **Срок выбора.** Воркер (задача пула) по `choose_until`: подтвердить машину фирмы рейса (`chosenAt = chooseUntil`), снять обычную (`deadline`), уведомить её фирму. Ленивое истечение `sched` и чтения машин не освобождают бронь предложения до досчёта (Q-W2.71-14).
7. **Правила 6, 8, 9, 10.** Осмотры и дефекты обычной машины — в области её фирмы (как сейчас: по фирме машины); обычная машина освобождается при осмотре сдачи без блокирующего дефекта (Q-W2.70-9). Смена машины после выбора — логист (`assignTripVehicle`, `releaseReservation` подтверждённой — причина `manager`, `chosen_at` очищается, Q-W2.71-13). Свой водитель — `alternativeVehicleId`: две брони предложения на рейс, рейс `planned` до выбора. Расходы — без изменений.
8. **Временный водитель:** `POST /fleet/reservations` на рейс перевода — 403; список машин — только предложенные (строки resource).
9. **Конец перевода до старта** — брони предложения снимаются (`transfer_ended`).
10. **«Требует решения»:** `fleet.vehicle_choice_pending` (за 15 минут до срока, пока выбора нет) и `fleet.trip_without_vehicle` (одобренный запрос S2-20, рейс без машины и без живых броней).
