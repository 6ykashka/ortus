## 2. Сводка

- Домен — четыре страницы владельца в группе меню «Компания»: «Модули и место» (`modules`), «Пользователи и роли» (`users`), «Подписка и места» (`billing`), «Оформление» (`branding`) — `Ортус CRM.dc.html:2978`. Иконки: `extension`, `group`, `workspace_premium`, `palette`.
- Видит только персона `owner` (`navForBase` строит группу «Компания» только для `persona === 'owner'`, `:2975–2990`). Для owner на этих страницах `gateVM` всегда возвращает «нет шлюза» (`:3056`). В прототипе нет проверки ключей прав для этих страниц — доступ определяется персоной.
- Каталог прав (`docs/11-permissions.yaml:26–35`): `modules.read`, `modules.manage` (owner_only), `billing.read` (sensitive), `billing.manage` (owner_only); `members.invite`, `roles.manage`, `roles.assign` (`:17–22`); `branding.manage` — только владелец, `branding.read` — все (`docs/18-branding.md:83`).
- Две организации с отдельными «БД» в mock-адаптере: `t-alta` «Альта Групп» (владелец Дарья Зимина, trial, 10 участников) и `t-lotos` «SPA «Лотос»» (Ирина Белова, active, 23 участника) — `ortus/mock-data.js:94–95, 42–82`; общий только `platform` (control DB) — `ortus/api.js:43–45`.
- Все четыре страницы существуют в обеих организациях; персонажи демо-панели: `owner` (Альта) и `owner@t-lotos` (Лотос) — `Ортус CRM.dc.html:36–46`.
- Модули: три отраслевых (`logistics`, `spa`, `repair`) с зависимостями от 12 базовых (14.10: + «Документы», «Обращения», «Чаты»; «Внутренняя касса» → «Касса»; `ortus/models.js:24–75`). Отключение переводит модуль в `history: true` («только чтение»), `ortus/api.js:285–289`; в меню владельца он остаётся одним пунктом в группе «Отключены · только чтение» (D-23, 01 §9.1), диалог отключения говорит об этом отдельным пунктом.
- 14.10: роли и назначения. Список ролей компании содержит роли всех модулей (23 в сиде «Альты»: 5 прежних, 4 проектных шаблона, роли обращений, пространств, документов, чатов, «Кассир салона»). Назначение получило области «Касса» (`{ type: 'account', id }`, выдаётся в диалоге «Назначить роль») и «Проект» (`{ type: 'project', id }`, выдаётся в модуле «Задачи и проекты»); редактор роли — блок «Касса · остаток и лимиты». Объектные области в оценщике — по PD-53 (§6.12).
- Место организации: `quotaGb`/`usedGb` тенанта, разбивка `db.storage.breakdown`; лимит выбирается из 25/50/100/250/500 ГБ; уменьшение ниже занятого — диалог с подтверждением (`:2684–2709`).
- Пробный период: `t.status === 'trial'` → карточка с остатком дней, демо-кнопка завершения → `setTenantStatus('t-alta','restricted')` (`:2710–2722`). В `restricted/suspended` — баннер, кнопки «Подключить» и «Изменить лимит» заблокированы, `assertActive` в API.
- Пользователи: вкладки «Люди», «Группы», «Роли», «Проверка доступа» (`:3141`). Назначение = роль + область (организация/регион/фирма) + срок; приглашение = имя + почта + роль + область с проверкой мест.
- Роли: `system` (нередактируемая), `template`, `custom`; редактор — переключатель модуля + чекбоксы действий из манифеста; отдельный «Финансовые разрешения» блок, заблокированный для функции «Водитель» (`:3168–3216`).
- Места: занимает каждый участник со статусом `active` или `invited`; `blocked` и карточки без входа — бесплатно (`ortus/api.js:56–58`, `docs/17-users-and-billing.md:30–46`).
- Тарифы: версия сетки `priceBook.current` (v2: Старт 10/3 900, Команда 25/8 900, Бизнес 50/15 900, Сеть 100/27 900, Безлимит); сроки 1/4/8/12 мес со скидкой 0/5/10/20% (`ortus/mock-data.js:100–110`). Заявка владельца → оператор подтверждает; одна открытая заявка на организацию.
- Оформление: название (1–60), короткое имя (≤16), логотип/знак (PNG/SVG/JPG/WebP ≤1 МБ), акцент из 8 цветов палитры или HEX с автокоррекцией до контраста 4.5:1, термины в 4 формах, меню (название/иконка/порядок/скрытие, 5 пунктов нельзя скрыть), «Работает на Ортус», предпросмотр (приложение/публичная форма/письмо), версии (`:3675–3743`, `docs/18-branding.md`).
- Значимые изменения проходят через общий диалог `confirm` с разделами последствий и опциональной галочкой-подтверждением (`:2643`, `:3969–3977`).
- Все команды идут через `this.run(key, fn, okToast, {quiet})` → `busy`, тост успеха/ошибки, подмена `db` ответом сервера (`:2419–2434`).

## 4. Общий каркас, релевантный домену

### 4.1 Брейкпоинты и раскладка (`:2801–2819`)

- `W = frame !== 'auto' ? min(frame, w) : w`; `mobile = W < 640`; `rail = !mobile && W < 1080`; `showLabels = !mobile && !rail`.
- Боковая панель: ширина `244px` (sidebar ≥1080) / `68px` (rail 640–1079); `background:#F8F9F6;border-right:1px solid #DCE2D9` (`:150`). Пункт: `min-height:40px;border-radius:8px`, активный `bg var(--ox-accent-soft)`, `fg var(--ox-accent)`, `font-weight:600`, `aria-current="page"`; hover `#EBEFE9` (`:155`, `:3024`).
- Нижняя навигация `<nav aria-label="Навигация">` при `mobile`: первые 3 пункта плоского списка + «Ещё» (`menu`), кнопка `min-height:60px`, иконка 24px с `FILL 1` у активного (`:2165–2174`, `:3027–3030`). Для owner: «Главная», «Модули» (замена «Модули и место»), «Люди» (замена «Пользователи и роли»), «Ещё». «Подписка и места» и «Оформление» на телефоне доступны только через лист «Все разделы» (`:2274–2282`).
- `<main id="ox-main">`: контейнер `max-width: 1320px` (owner), `padding: '24px 28px 40px'` / mobile `'16px 14px 28px'`, `gap:16px` (`:172–173`, `:2819`). Прокрутка — у `main` (`overflow-y:auto`), при `setPage` `scrollTop = 0` (`:2454`).
- Внутри страниц раскладка — flex-wrap с `flex: N 1 Xpx`, таблиц нет; на 390 колонки складываются в одну.
- Демо-панель: «Ширина» → `frame` 397/768/1440: рамка с радиусом 22px (390) / 12px (`:2815–2816`).

## 9. Инварианты и правила

1. Три отдельных действия: подключить модуль → разрешить роли → выбрать область при назначении; подключение не выдаёт прав (`README.md:11`; тексты `:210, 2650, 3210`).
2. Отключённый модуль остаётся читаемым: `history: true`, статус «Отключён · только чтение»; начатые смены можно завершить (`ortus/api.js:176–182, 285–289`).
3. В `restricted/suspended` новые операции запрещены: `assertActive` в `setStorageQuota`; кнопки «Подключить» и «Изменить лимит» заблокированы `restricted` (`:3117, 3134`).
4. Уменьшение лимита не удаляет файлы; при `usedGb >= quotaGb` — баннер и запрет новых загрузок (`:277, 3096`; `ortus/api.js:974`).
5. Системная роль (`kind==='system'`) не редактируется (поле имени disabled, нет редактора; сервер `forbidden`); нельзя снять роль с последнего владельца (`last_owner`) (`ortus/api.js:424, 436`).
6. Функция «Водитель» (`member.function==='driver'`, `role.professional==='driver'`) несовместима с `finance.read/manage` — блок в редакторе, конфликт в назначении, `role_conflict` на сервере; `canEarnings` → `driver_block` (`ortus/models.js:298–306`; `ortus/api.js:417–418, 438–441`).
7. Финансовые права не включаются переключателем модуля и действуют только в области назначения (`:369`).
8. Место занимает `active` или `invited`; `blocked` и карточки без аккаунта — нет; приглашение занимает место сразу; при `seatsUsed >= seatsLimit` приглашение закрыто (`ortus/api.js:56–58, 297–298`; `docs/17-users-and-billing.md:30–46`).
9. Одна открытая заявка на тариф на организацию (`request_pending`/`conflict`); тариф с `seats < seatsUsed` недоступен (`tier_below_usage`) (`ortus/api.js:319–322`; `docs/17:153`).
10. Скидка считается от помесячной цены, округление до рубля; подписка фиксирует `price_version` (`docs/17:60–63`; `:3572–3577`).
11. Оформление действует на весь бизнес; цвета статусов не меняются; статус всегда иконка + текст (`:1300`, `README.md:41`; `docs/18:33`).
12. Акцент с контрастом < 4.5:1 затемняется шагами 4% к чёрному; производные: hover −18% к чёрному, soft 86% к белому, tint 93% к белому; UI использует только `--ox-accent*` (`:2329–2330`; `docs/18:41–43`).
